**除錯選單的提醒**
- 「跳一天」不會換季（可以用來看「冬末」）；要換季請睡一覺，或用「跳到下一季」。
- 成年、老年轉變：用「跳到次成年期最後一天」或「跳到老年前一天」，接著「跳一天」，再**睡一覺**。
- 強制觸發的事件會在目前的區域發生；苔原的事件要先走到苔原（森林北部 →「前往苔原」）。

## G. 1.7 驗收（2026-10-08 實作完成）
- [ ] **一天的節奏**：不狩獵、只探索與採集的一天，到傍晚會累到想休息；但不會每做兩件事就得休息。
- [ ] **傷勢有份量**：被打成重傷後，要幾天的休養（吃飽、睡在巢穴或好睡處）才恢復到能再冒險，你會因此改變接下來幾天的計畫。
- [ ] **大型獵物各有打法**：獵北美馴鹿、白尾鹿、駝鹿時，最好的追擊方式不同（馴鹿、駝鹿適合跟隨，白尾鹿適合短衝），你說得出為什麼。
- [ ] **戰鬥看得懂**：輸掉或差點死掉的戰鬥，能從畫面與紀錄說出是哪裡出了問題。
- [ ] **1.6 驗收：兩隻狼長得不一樣**：照直覺玩兩隻狼到成年，比較兩張成年卡片的能力上限與體型描述（不要用除錯跳過次成年期）。
- [ ] **1.6 驗收：記得大火**：其中一局經歷森林大火，試玩後還記得從哪裡燒起、怎麼逃、結果如何。

## H. 1.7 的畫面與新素材（2026-10-08）
- [ ] **太累不能狩獵**：體力 < 10 時，目擊獵物、追蹤獵物線索、獵物靠近的按鈕灰掉並寫「（太累了，追不動）」；頂部的「體力不支」圖示（垂頭吐舌的狼頭）與滑鼠提示；體力 0 時戰鬥選項的因素欄「體力不足」。
- [ ] **重傷的新說明**：重傷卡片寫「血量回不到七成、睡覺才癒合、挨餓不會好」；傷勢圖示的滑鼠提示「約 N 晚痊癒（好好休養會更快）」；帶傷去打架或狩獵時「帶著重傷硬撐，傷口又裂開了…」。
- [ ] **追擊方式的提示**：追擊選項的因素欄「牠跑得久，適合慢慢跟著耗」「長距離跟隨容易跟丟」「短衝追不上牠」；感知 55 以上時，觀察後的獵物狀態多一句跑法（「牠的步伐穩，看起來能跑很久。」）；駝鹿搏鬥的「體型巨大」只顯示不扣分。
- [ ] **焦黑地形**：大火燃燒中與焦黑期，探索、狩獵、遭遇畫面的地形背景是燒黑的（溪谷、深林、林緣、倒木、空地）。
- [ ] **冬季森林**：冬天森林東、南、西三區的主畫面是雪景；狩獵、探索畫面的四種地形也是冬季版；空地有自己的背景。
- [ ] **成年狼的新外貌**：成年後頭像、狩獵、進食、睡覺的姿勢換成更深的炭灰、體型更厚；戰鬥時的威嚇、撲咬、閃避、受傷、示弱也是成年（老年也是老年）的樣子。
- [ ] **圍攻狼獾的事件圖**：放大成 112×56，兩隻苔原狼包夾狼獾。
