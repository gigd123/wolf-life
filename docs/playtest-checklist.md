## ★ 下次試玩（2026-10-29 整理，約 40 分鐘）

最近改了很多手感相關的東西，時間不多就照順序看前幾項，玩到哪算哪。有問題在項目下面寫一行就好。除錯選單的按鈕寫在【】裡。

1. - [ ] **小跑貼近鹿群（約 5 分鐘）**：用小跑直接衝到鹿旁邊，鹿應該會跑（貼到 1 格內一定察覺）；改用潛行慢慢靠近，還是可以不被發現。會不會覺得潛行變得太難、或小跑還是太容易？
2. - [ ] **咬住小獵物（約 5 分鐘）**：追到、咬住雪兔或小河狸後，應該很少因為「喘不過氣」只能鬆口；牠還是可能掙脫。咬住小獵物的感覺合理嗎？
3. - [ ] **一天的節奏（約 10 分鐘）**：清晨、黃昏比較容易遇到鹿；白天在有鹿的地方探索常空手，紀錄寫「白天牠們多半臥在隱蔽處」；白天探索、移動比較累（夏天更累），白天休息體力回得快。有沒有自然發現晨昏比較好獵？白天會不會覺得什麼都做不好？
4. - [ ] **威嚇（約 5 分鐘）**：對黑狼、灰熊、美洲獅選「威嚇」，結果有三種：嚇退、僵持（牠低吼逼近一步但不咬，可以再威嚇或先試探）、激怒（牠撲上來）。看得懂為什麼是這個結果嗎？還像賭博嗎？【黑狼直接互動】【黑狼現身（範圍）】
5. - [ ] **黑狼不會一直出來（約 5 分鐘）**：威嚇成功嚇退黑狼後，留在原地，不應該馬上又被同一隻黑狼要你離開（之後約一天半內不會有黑狼的事件）。被黑狼趕過一次，成年後牠再出來就可以選「對峙」。還沒到時機時，被趕的訊息會寫「你還太年輕」。【撞上黑狼一家】
6. - [ ] **牧場（約 7 分鐘）**：在牧場探索，白天常看到「牛群就在柵欄那頭，但有人看著」，夜裡、晨昏比較有機會；空手時寫牧場的情境（羊關進棚裡、牛群走遠）；在牧場吃東西時灰熊不會來搶。冬季的屋舍與畜欄不會再出現奇怪的字。【牧場開放】【牧場注意 +20】

## M. 牧場（Phase 4a，2026-10-23 實作完成）

主遊戲已經打開：約七成的局在 2～3 歲出現（換季卡片先寫線索，下一季才開放）。快速看：除錯選單「牧場開放」→ 走到紀錄寫的那兩區之一 →「前往牧場」。「牧場注意 +20」可以把警戒拉高；「牧場巡查」「牧場預警」「牧場追獵」「牧場吃到一半被打斷」直接觸發。SPEC 在 Phase 4a，設計原則是「節制才划算」。

- [ ] **看懂警戒**：牧場邊緣「換個方式探索 → 望向柵欄裡」；注意拉高後探索時的痕跡會換（蹄印、狗叫 → 獵犬的足跡、槍聲 →「牠們在找你」）。不看數字，猜得出現在去安不安全嗎？
- [ ] **人的反應**：巡查多半只是被吆喝著趕走，偶爾挨一槍（不會死）；注意 70 以上先跳預警，之後才可能被人帶著獵犬追（可能被打死；被狗追上時選「轉身咬退一隻」或「掙脫逃跑」，騎馬的人越來越近）。換到別的地圖就甩掉。危險來得有沒有預兆？被打死時覺得是自己的選擇嗎？
- [ ] **吃到一半被打斷**：在牧場吃殘骸時巡查過來，「趴低不動」「叼一段肉就跑」「丟下獵物離開」三種選擇有沒有意思？
- [ ] **節制才划算**：偶爾去（餓了、警戒還低才去）應該比從不去好過，常去會受傷、反而比較餓（模擬：偶爾去的老年挨餓最少）。玩起來是這樣嗎？牧場出現後會不會想換個地方住，或乾脆不去？

## K6. 所有狩獵改成戰術場景（Phase 2i 第 5～7 步，2026-10-25 實作完成）

除了田鼠、地松鼠的小撲（還有悄悄叼走猞猁的雪兔、鮭魚洄流），看到「狩獵」都進戰術地圖，選單式的狩獵畫面不會再出現。快速看：除錯選單「獵物靠近」；夏季在森林東部、丘陵草地、開闊草原探索找幼鹿的足跡（躲在草裡的）；除錯選單牧場那一列的「開放」後到放牧地、屋舍與畜欄探索找牛、羊。

## K7. 一天的節奏（Phase 2j：晨昏出獵、白天休息，2026-10-26 實作完成）

白天的鹿多半臥著（比較難遇到、新鮮足跡少）；白天探索、移動比較累（夏天更累）；白天休息體力回得比較快。不是規定白天不能動：兔子、旱獺白天照樣找得到，已經找到的足跡照樣追。

- [ ] **沒有提示也發現**：玩幾天後，有沒有自己發現清晨、黃昏比較容易遇到鹿？
- [ ] **白天空手的提示**：白天在有鹿的地方探索空手時，紀錄寫「白天牠們多半臥在隱蔽處反芻，清晨和黃昏才比較會出來」。看得懂、不嫌煩嗎？
- [ ] **白天不會「什麼都做不好」**：白天想探索新區域、找兔子或旱獺、追足跡時，覺得合理還是被限制？
- [ ] **休息到黃昏**：吃飽了、體力不滿時，「休息到黃昏」有沒有變成自然的選擇？
- [ ] **夏天**：夏天白天出門明顯比較累（探索、移動 × 1.3），會不會太重？

## P2. 離群母狼與配對（Phase 3 第 2 步，2026-10-30 實作完成）

成年後才有。快速看：除錯選單「離群的母狼」直接遇上（一半機會牠正在吃東西）、「母狼的關係 +4」（加兩次就成為伴侶）。正常玩：秋冬在巢穴附近每天黃昏「嚎叫」、偶爾「標記地盤」，幾天內可能聞到陌生母狼的氣味（寫牠往哪一區去了），走過去探索就會遇上。

- [ ] **找得到牠嗎**：秋冬認真找（每天嚎叫、標記），大約一個秋冬就會遇到；不找的話一兩年才碰到一次。徵兆寫的方向看得懂嗎？
- [ ] **認識牠**：走近、跟著、牠在吃東西時「過去一起吃」或「把獵物搶過來」、你在吃的時候「讓牠一起吃」。大約一週會成為伴侶；搶牠的食物、在牠面前示弱、太久（7 天）沒去找牠，牠會走掉。這個節奏合理嗎？會不會太快？
- [ ] **嚎叫**：嚎叫後牠可能循聲找來；嚎叫的那天也比較容易撞上黑狼一家。
- [ ] **伴侶字卡**：成為伴侶時的字卡；苔原狼只剩一隻母狼、你們很友善時，換季時牠可能留下來跟你（另一種字卡）。

## P4. 領域與鄰群（Phase 3 第 4 步，2026-10-30 實作完成）

## K8. 2026-10-29 QA 的修正（`docs/proposals/qa-2026-10-29.md`）

- [ ] **小跑貼近**：戰術地圖上小跑、衝刺貼到獵物 1 格內一定察覺；2～4 格內的腳步聲不受密林、黃昏打折；潛行不出聲。只有「從遠處小跑貼上去」的打法變難，潛近、伏擊、猛追不受影響。順便再看一次潛近鹿群的難度（2026-10-30 驗收覺得「有點偏容易」，是這次修正之前測的）。

- [ ] **威嚇三段**：嚇退／僵持（不扣血、還在對峙、下一次威嚇 +8%，但更容易激怒）／激怒。試探看出牠「動搖」時比較不會激怒。按鈕上的機率與因素看得懂嗎（「你沒退讓」）？
- [ ] **黑狼的冷卻**：任何黑狼事件後約一天半內不再有；贏過牠之後不會再單獨出來要你離開，遇到的是遠遠戒備的狼群。
- [ ] **灰熊搶食**：牧場、苔原北部吃東西時灰熊不會來；森林照舊。
- [ ] **牧場探索**：「有人看著」（白天多、夜裡少、注意越高越多）；牧場自己的空手句子；牛、羊一開始就認識（學到的知識不再出現 animal_unknown 的字）。
