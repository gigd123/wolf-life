# 試玩驗證清單

2026-10-04 整理，對應 `progress.md` 的「1.5／1.6 驗收」與「待使用者目視確認」。測到的項目直接在這份檔案打勾（`- [x]`），有問題的在項目下面寫一行說明（截圖放 `bug 截圖/`），下次開工時 Claude Code 會讀這份檔案，把結果整理回 `progress.md`。

**除錯選單的提醒**
- 「跳一天」不會換季（可以用來看「冬末」）；要換季請睡一覺，或用「跳到下一季」。
- 成年、老年轉變：用「跳到次成年期最後一天」或「跳到老年前一天」，接著「跳一天」，再**睡一覺**。
- 強制觸發的事件會在目前的區域發生；苔原的事件要先走到苔原（森林北部 →「前往苔原」）。

## B. 2026-10-04 的新改動（最優先）

### B1. 換季改到睡覺時
- [ ] 一季的天數到了以後，頂部顯示「冬末」這類季末字樣（不是「冬 D11」）。用「跳一天」跳到第 10 天之後確認。
- [ ] 季末時睡一覺：睡醒後才換季，跳出換季字卡；關掉後頂部、背景都是新季節。
- [ ] 季末時那一覺不會被灰熊驚醒，也沒有灰熊路過、狼嚎、暴雨開始（多試幾次，尤其在野外勉強過夜）。
- [ ] 季末過了一整天還沒睡：短暫休息或「休息到…」也會換季。
- [ ] 換季那一覺不另外跳「今天：速度 ▲」的睡覺結算淡入。
- [ ] 大火或暴風雪進行中（含徵兆）的季末睡覺不換季，等事件結束後的下一覺才換。
- [ ] 成年或老年的那一季：睡醒後先出成年／老年卡片，最後才是換季字卡。

### B2. 換季字卡的成長回顧
- [x] 吃得好的一季：字卡最下面「這一季，你又變得比以前強壯一些：」加上各能力 ▲N（含圖示），數字看起來合理（次成年期每項大約 ▲3～6）。
- [ ] 常挨餓的一季：「這一季你常常挨餓，身體沒什麼長進：」或「這一季你瘦了，身體沒什麼長進。」
- [ ] 老年：有衰退時「這一季，你的身體有些地方不如從前了：」並列出 ▼。
- [x] 字卡文字加上回顧後，長度是否還放得下（冬季的條件句多時最長）。
- [x] 每晚睡覺的成長感覺沒有變少（每晚的成長率 ×1.3，其中 20% 留到換季發放）。

### B3. 灰熊改版
用除錯選單「強制觸發遭遇（灰熊）」「母熊」，或在搶食時遇到灰熊：
- [ ] 交鋒時多了「騷擾」；選項最多 6 個（撲咬、猛撲、閃避、騷擾、撤退、放棄獵物），排版是否放得下。
- [ ] 騷擾的命中率在中等到高（成年狼約 55%、巔峰約 70%），「你被打中率」比撲咬低很多。
- [ ] 灰熊的狀態描述隨騷擾變化：「牠還精力充沛…」→「牠喘著粗氣，揮掌慢了下來。」→「牠的動作越來越沉，好像快撐不住了。」
- [ ] 被灰熊打中一掌就是重傷、兩掌就瀕危；手感上是「閃得掉，但一掌很痛」。
- [ ] 把牠耗到離開時的句子「灰熊累得喘不過氣，轉身走開了。」
- [ ] 母熊明顯比一般灰熊難纏（撐得更久、打得更重）。
- [ ] 整體感覺：單狼對灰熊勝算很低，但不是完全沒希望。

### B4. 強狼
- [x] 實力明顯比黑狼或苔原狼強時，威嚇的因素欄出現「牠看得出打不過你」，威嚇成功率變高（可以用除錯選單調高力量、技巧後「陌生灰狼直接互動」）。
- [ ] 實力壓倒性時，黑狼交鋒一兩回合就示弱。
- [ ] 第一次獨自擊退成年灰熊：跳「那頭灰熊」卡片，有成長與「能力的巔峰上限也提高了」兩行；第二次不會再跳。
- [ ] 一生回顧多一行「N 歲那年，你獨自趕走了一頭成年灰熊。」
- [ ] 第一次打贏黑狼（沒受重傷）後，技巧真的明顯提升（約 +4）。
