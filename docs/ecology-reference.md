# 生態參考與系統對應

> 參考資料，不是實作規格。實作一律以 SPEC.md 為準；這份用來理解設計背後的生態依據，以及之後各階段可以延伸的方向。

## 三個影響最大的發現

1. **其他狼群是野狼最大的死因。** 研究中 14～65% 的狼死於其他狼，91% 的死亡發生在距離領域邊界 3.2 公里內。這給了獨居狼天然的地理張力：邊界獵物多，但最危險。
2. **狼是「飽餐一頓、長期耐餓」的動物。** 胃可容納 7～9 公斤食物，兩週不進食也不會明顯虛弱。SPEC.md 的飽餐－耐餓模型就是依此設計。
3. **野生狼群是家庭，不是階級。** 嚴格階級與爭奪頭狼的說法，主要來自觀察圈養、彼此無血緣的狼。野生狼群由一對配偶和子女組成，很少接納外來的成年狼，入侵者通常會被殺死。

## 現行設計對照

| 設計項目 | 生態事實 | 建議 |
| --- | --- | --- |
| 開局年齡 | 離群年齡 5 個月～5 歲，平均 11～24 個月；原因是性成熟、食物競爭與繁殖 | 8 個月屬於偏早的離群，「意外」的說法合理 |
| 首次繁殖 | 野生狼最早約 2 歲繁殖 | 與次成年期 2 季、成年後第一個冬季交配相符 |
| 大型獵物 | 曾有單狼成功獵殺野牛、駝鹿；單狼或成對狼的人均成功率反而較高 | 單狼「極危險但可能」 |
| 狼群規模 | 平均 5～11 隻；成年 1～2、年輕 3～6、幼狼 1～3 | 狼群上限的參考 |
| 挑戰頭狼 | 狼群很少接納外來成年狼，被接受的多為 1～3 歲 | 可改為取代失去配偶的繁殖狼、或與離群母狼另組新狼群；挑戰作為少見事件 |
| 老年被挑戰 | 子女通常離群自立，而非奪位 | 可改為「子女陸續離群」與「體力衰退無法領獵」 |
| 配偶 | 多為終生單一配偶；配偶死亡後很快另尋新伴；公狼數量多於母狼 | 喪偶是重要人生事件；母狼稀缺增加求偶難度 |
| 繁殖 | 暮冬發情，懷孕 62～75 天，每胎平均 5～6 隻，胎數隨獵物豐富增加 | 冬末交配、春季生產；胎數與狩獵成果連動 |
| 巢穴 | 窩通常在水源 500 公尺內，利用岩縫、河岸，或擴建狐狸、獾的舊洞 | 築巢條件加入「靠近水源」；狐狸洞可作為探索發現 |
| 夜間 | 狼的夜視是犬科最好的；狼群攻擊熊會拖到夜晚 | 深夜對狼有利 |
| 食物 | 會吃藍莓、越橘、花楸果，也吃昆蟲、蛙類、鳥蛋、腐肉 | 可加入春季鳥蛋與食腐 |

## 可延伸的系統

### 領域與其他狼群（Phase 2 以後）

- 世界中存在 AI 狼群，以氣味標記和狼嚎宣示領域；氣味標記約 2～3 週後過期。
- 領域邊界獵物較多，但遭遇其他狼群的風險最高。
- 成年後玩家建立自己的領域，需要定期巡視和標記。
- 參考數字：狼群每天移動約 25 公里，約一半時間待在核心領域。

### 狼嚎

- 獨居時嚎叫可能吸引離群母狼，也可能暴露位置；在他人領域中嚎叫非常危險。
- 狼群時嚎叫用來集結成員、警告入侵者，暴風雨中用來找同伴。
- 雨天或吃飽時，其他狼不會回應嚎叫。

### 食腐

- 狼在上風處 2～3 公里外就能聞到腐肉。
- 風險低、營養中等，但可能遇到原主人回來；靠近牧場的腐肉可能是毒餌。

### 陷阱與毒餌（Phase 4）

- 牧場周邊可能有腳踏陷阱；感知高或有相關知識的狼較容易察覺。
- 毒餌在夏末秋初最危險，年輕狼特別容易誤食。
- 獵人會模仿狼嚎引誘，冬季和交配季最常見。
- 曾被陷阱傷過的狼會學會避開。

## 狩獵

| 生態事實 | 遊戲規則參考 |
| --- | --- |
| 狼通常追 1～2 公里就放棄，最長紀錄 21 公里 | 追擊超過 2～3 回合時成功率逐回合下降 |
| 會把獵物驅趕到崎嶇冰面、懸崖、山溝、斜坡、陡峭河岸 | 「驅趕」依地形決定，山地和溪流效果最好 |
| 獵物站定不動時，狼可能放棄；野牛常站定面對狼群 | 獵物反應「站定」 |
| 馬鹿奔跑比狼更容易疲憊 | 「保持跟隨」對馬鹿特別有效 |
| 成群獵物會先被打散，再隔離落單個體 | 群獵的「打散群體」階段 |
| 一隻狼在前方吸引注意，另一隻從後方偷襲 | 群獵的「誘敵＋伏擊」 |
| 狼很少抓到躲藏的野兔或鳥 | 野兔躲藏後成功率明顯下降 |
| 狼的腳掌適合雪地 | 冬季深雪中追擊鹿類有加成 |

## 競爭動物

| 動物 | 生態事實 | 遊戲規則參考 |
| --- | --- | --- |
| 灰熊（棕熊） | 單狼不敵；狼群多半為了屍體和灰熊對峙、互相試探，很少致命衝突；狼群守窩時多能擊退；雙方都會殺對方幼獸 | 單狼遭遇以撤退為主；狼群主動獵殺灰熊勝算低、傷亡高 |
| 黑熊 | 與狼的棲地重疊較少；多半避開大型狼群；和狼群衝突時常喪命，幼熊特別容易受威脅 | 遭遇率低，5～10 隻的狼群可以獵殺 |
| 美洲獅 | 一對一佔優勢；面對狼群時傾向逃到樹上或岩石區；狼常搶走美洲獅的獵物（參考資料中約四成美洲獅獵物最後落入狼口）；冬季衝突最多；被殺的狼多半是落單的狼 | 搶食與驅逐為主要互動；地形與季節影響最大 |
| 野豬 | 皮厚、有獠牙，單狼或兩隻狼居於劣勢，曾有 2 隻狼被 4 頭野豬反追的紀錄；狼群合作與消耗戰才能獵殺 | 單狼或少數狼可能被反過來驅趕 |
| 郊狼 | 狼佔優勢，冬季常殺郊狼；郊狼成群時可能追狼，但沒有殺死狼的紀錄 | 威脅性低，不會直接造成死亡 |

## 牧場（Phase 4）

- 家畜以牛、羊為主。牛常被從後方攻擊；羊一次可能被殺死多隻，但更容易引來人類。
- 野生獵物充足時狼很少攻擊家畜：獵物短缺時，牧場的吸引力上升。
- 損失多發生在夏季放牧期。
- 護衛犬可能戴尖刺項圈；獨居狼偶爾會把放牧犬當成同伴。
- 獵犬組成：視覺獵犬追上並拖慢狼，較重的獵犬再趕來搏鬥。

## 外觀與性別參考

- 北美雄狼平均約 27～45 公斤；雌狼輕約 2.2～4.5 公斤，前額與吻部較窄、腿較短、肩部較不厚實。
- 老狼的尾端、鼻子和前額灰毛較多，可作為老年期外觀變化。

## 資料來源

- 中文維基百科「狼」條目。條目寫幼狼「通常在夏季出生」，但北美灰狼一般在春季（約 4～5 月）出生，遊戲採春季。
- 美洲獅部分來自 2022 年的科普文章；野豬與熊的部分來自網路整理。案例可作為設計方向，但不宜當成精確的生物學結論或平衡數值。
