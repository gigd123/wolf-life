# 生態參考與系統對應

> 參考資料，不是實作規格。實作一律以 SPEC.md 為準；這份用來理解設計背後的生態依據，以及之後各階段可以延伸的方向。

## 三個影響最大的發現

1. **其他狼群是野狼最大的死因。** 研究中 14～65% 的狼死於其他狼，91% 的死亡發生在距離領域邊界 3.2 公里內。這給了獨居狼天然的地理張力：邊界獵物多，但最危險。
2. **狼是「飽餐一頓、長期耐餓」的動物。** 胃可容納 7～9 公斤食物，兩週不進食也不會明顯虛弱。SPEC.md 的飽餐－耐餓模型就是依此設計。
3. **野生狼群是家庭，不是階級。** 嚴格階級與爭奪頭狼的說法，主要來自觀察圈養、彼此無血緣的狼。野生狼群由一對配偶和子女組成，很少接納外來的成年狼，入侵者通常會被殺死。

## 可延伸的系統

### 領域與其他狼群（Phase 2 以後）

- 世界中存在 AI 狼群，以氣味標記和狼嚎宣示領域；氣味標記約 2～3 週後過期。
- 領域邊界獵物較多，但遭遇其他狼群的風險最高。
- 成年後玩家建立自己的領域，需要定期巡視和標記。
- 參考數字：狼群每天移動約 25 公里，約一半時間待在核心領域。

### 狼嚎

- 獨居時嚎叫可能吸引離群母狼，也可能暴露位置；在他人領域中嚎叫非常危險。
- 狼群時嚎叫用來集結成員、警告入侵者，暴風雨中用來找同伴。
- 雨天或吃飽時，其他狼不會回應嚎叫。

### 食腐

- 狼在上風處 2～3 公里外就能聞到腐肉。
- 風險低、營養中等，但可能遇到原主人回來；靠近牧場的腐肉可能是毒餌。

### 陷阱與毒餌（Phase 4）

- 牧場周邊可能有腳踏陷阱；感知高或有相關知識的狼較容易察覺。
- 毒餌在夏末秋初最危險，年輕狼特別容易誤食。
- 獵人會模仿狼嚎引誘，冬季和交配季最常見。
- 曾被陷阱傷過的狼會學會避開。

## 狩獵

| 生態事實 | 遊戲規則參考 |

| 會把獵物驅趕到崎嶇冰面、懸崖、山溝、斜坡、陡峭河岸 | 「驅趕」依地形決定，山地和溪流效果最好 |

| 馬鹿奔跑比狼更容易疲憊 | 「保持跟隨」對馬鹿特別有效 |

| 狼很少抓到躲藏的野兔或鳥 | 野兔躲藏後成功率明顯下降 |
| 狼的腳掌適合雪地 | 冬季深雪中追擊鹿類有加成 |

## 牧場（Phase 4）

- 家畜以牛、羊為主。牛常被從後方攻擊；羊一次可能被殺死多隻，但更容易引來人類。
- 野生獵物充足時狼很少攻擊家畜：獵物短缺時，牧場的吸引力上升。
- 損失多發生在夏季放牧期。
- 護衛犬可能戴尖刺項圈；獨居狼偶爾會把放牧犬當成同伴。
- 獵犬組成：視覺獵犬追上並拖慢狼，較重的獵犬再趕來搏鬥。

## 外觀與性別參考

- 北美雄狼平均約 27～45 公斤；雌狼輕約 2.2～4.5 公斤，前額與吻部較窄、腿較短、肩部較不厚實。
- 老狼的尾端、鼻子和前額灰毛較多，可作為老年期外觀變化。

3. 攻擊方式：咬臀部、後腿是主要的做法（從後方消耗）；正面撲咬、咬前腳最容易被踢。
4. **分次狩獵**（新規則，獨居狼特別適合）：咬傷但沒殺死的駝鹿會帶傷留在這一帶幾天，傷勢讓牠變慢、變虛弱；之後探索時可能再遇到（「帶傷的駝鹿」），更好抓。這也能延伸到其他大型獵物。
5. 季節：春末夏初小駝鹿季（母鹿護幼很危險）；冬末老弱多。
6. 地形：密林、倒木、深雪中狼追駝鹿不利（和白尾鹿相反）；水邊是駝鹿的避難處。

**對雪況規則的修正**：雪的效果要依體型與腳的承重分開算，不能一律「雪越深對狼越有利」。

- 北美馴鹿（蹄大）：深雪會縮小馴鹿的速度優勢，狼較能追上（書：幼鹿逃進深雪被追上的案例；整體敘述）。硬雪殼看雪面能不能承受各自的重量：撐得住馴鹿、撐不住狼時馴鹿有利；撐不住馴鹿時馴鹿也被拖慢（推論，沒有具體案例編號）。

**和目前遊戲最大的差異**
1. 森林的野兔沒有指定物種、也不變色；真實北方森林的兔子多半就是雪兔。
2. 雪兔只有「冬天難發現」；真實的雪兔在沒雪的初冬、雪融的春季反而因為白色而顯眼。
3. 沒有族群週期：真實的雪兔有好年壞年，差很多倍。
4. 沒有時段活動（雪兔晨昏、夜間活躍）。

**查不到的**
- 狼抓雪兔的成功率。

**整合後對遊戲的建議（1.8 的兔子）**
1. 森林與苔原都是雪兔（森林的「野兔」改成雪兔，沿用雪兔的夏冬兩套圖）。
2. 毛色依季節轉換、雪況影響快慢；有雪時白兔難發現，初冬無雪、春季雪融時白兔反而顯眼。
3. 約 10 年的族群週期：低谷年很少、高峰年到處都是；高峰年對狼是重要食物。
4. 時段活動：黃昏、夜間最多，中午最少。
5. 幼兔多躲、成兔多跑（急轉），受遮蔽影響。

## 獨居狼與大型獵物（2026-10-08 使用者補充，網路討論）

來源是 WolfQuest 玩家社群的討論（Reddit r/WolfQuestGame，2024），可信度**低**，只當作方向參考；其中一位自稱住在狼出沒地區、觀察多年。
- 獨居、離群遷移中的狼很少主動獵健康的大型獵物（麋鹿），多半靠腐肉與小型獵物度日，直到找到伴侶；受傷、生病的大型獵物例外。
- 原因是風險與收益：一隻狼吃不了那麼多，受重傷的代價又高；能活過一歲的狼通常不冒這種險。
- 例外：黃石公園的「06」號母狼以獨自獵麋鹿聞名，正因為少見。
- 也有人主張只要獵物出現弱點或失誤，獨狼一樣能抓到；WolfQuest 的開發者參考過《Wolves on the Hunt》。
- 和遊戲的關係：《狼之一生》的主角就是離群的獨居狼。目前成年狼獵健康成鹿的成功率很高（白尾鹿母鹿約 82%），和真實「對單一健康個體個位數」差很多。這是 1.8 要決定的方向：要多寫實（見 `progress.md` 待確認）。
