# 《狼之一生》專案總覽（2026-10-16）

給第一次接觸這個專案的人或 AI 看的摘要。細節以 `docs/SPEC.md`（目前規格）與 `docs/progress.md`（進度）為準；這份只整理「現在有什麼」與「接下來要做什麼」。

## 一、這是什麼遊戲

- 玩家扮演一隻北美灰狼，從 8 個月大活到老死或意外死亡。死亡就是結局，沒有勝負，只有「這一生怎麼過」。
- 類型：單機、生存養成、回合制策略。目標平台 Steam（Windows 為主）。
- 引擎：Godot 4（GDScript）。介面以繁體中文為主，架構預留多國語系。單一存檔槽。
- 核心體驗：每個決策都有意義、季節與環境帶來變化、狼的一生會因選擇而完全不同。
- 生態盡量寫實（寫實程度 b：保留遊戲性，但依真實生態資料設計規則；資料與來源整理在 `docs/ecology-reference.md`）。
- 目前是 2D 介面＋像素圖（佔位素材）；正式版目標是 3D 場景＋2D 像素角色。

## 二、開發原則

- 邏輯與畫面分離（`scripts/core/` 是規則，`scripts/ui/` 是畫面）。
- 數值集中在資料檔（`data/*.json`），介面文字用翻譯鍵（`localization/strings_zh_TW.csv`）。
- 每個階段都要能試玩；用 headless 模擬（`tools/sim/`）檢查狩獵成功率、飢餓、壽命、戰鬥勝率等平衡。
- 規格（SPEC、DESIGN）的修改都要先經使用者同意。
- 設計支柱與決策分工在 `docs/design-pillars.md`：核心樂趣依序是「一生的成長與經歷 > 讀懂自然 > 局面的變化 > 有意義的取捨」；檢驗問題之一是「玩家要有理由不選成功率最高的選項」。
- 三層決策分工：核心體驗由使用者決定；影響玩法的規則由 AI 先提 2～3 個方案（寫出感受、代價、假設），使用者選定後才寫規格；可逆的實作細節（程式、初始數值、測試）由 AI 處理。新的核心系統先寫「假設、驗證方式、通過標準」，做最小可玩原型或模擬驗證。

## 三、目前的遊戲內容（Phase 1～Phase 2）

### 一天的流程

- 時間以「回合」計，一天分凌晨、清晨、白天、黃昏、深夜五個時段；四季循環，季節長度不固定，天數到了以後**下一次睡覺**才換季。
- 每回合選一個行動：探索、採集、狩獵、追蹤、移動區域、休息、找睡處、回到殘骸、睡覺等。除了睡覺、休息，每個行動都花體力。
- 「探索」會產生發現（獵物蹤跡、殘骸（骨頭／一些肉／大半具，三種）、危險線索、睡處、採集物），每個發現有後續選項；另有「換個方式探索」（獸徑、登高嗅風、守在水邊、巡邊界）。
- 「照常過日子」：代為行動幾天（獵小獵物、找大型獵物、養傷），遇到值得注意的事、受傷、餓了或換季就停下交還玩家；期間的重要字卡（成年、老年、換季、年度回顧等）留到結束後顯示。

### 狼的素質

- 能力值：速度、力量、技巧、感知、血量上限。
- 狀態值：飽食度（上限 150，超過 100 是胃中存量；飽餐－耐餓模型）、體力、血量、健康值、年齡。
- 成長：技巧、感知靠「做」當下成長；速度、力量、血量上限靠鍛鍊點 × 飽食倍率，睡覺時結算，換季時再依這一季吃飽的天數發放保留的部分。
- 生命階段：從 8 個月大開始，次成年期（一歲前長最快，一歲後仍持續長）→ **2 歲成年**（依次成年期的成長結算潛力上限，體型描述不同）→ **6 歲起老年**（身體逐季衰退，技巧與感知不再成長，行動與狩獵的體力消耗 ×1.3）。
- 壽命：老年後每天有老死的機率（年紀越大越高、體質越好越低），實際約在 9～13 歲間老死；很老或很虛弱時可以自己選擇「找一個安靜的地方躺下」。
- 平衡目標（2026-10-16 調整）：正常成長的狼單挑黑狼，2 歲約四成、3 歲八成多、4 歲幾乎都贏（模擬值，是機率不是保證）；對灰熊仍然打不贏。
- 狩獵傾向（追獵、謹慎、強攻等）依玩法自動形成，影響成長方向。
- 傷勢：輕傷、重傷（重傷時血量回不到七成、睡覺才癒合、挨餓不會好、帶傷硬撐會延長），會留舊傷。

### 地圖

- **森林**四區（東、南、西、北）：各有地形配置（溪谷、深林、林緣草地、倒木區、空地），地形影響狩獵選項。北部冬季有鹿。
- **苔原**四區（林線、中部、東部、遠北）：跨地圖移動，冬春可走冰面捷徑（春融時冰可能裂開）。
- **山地**四區（山腳林地、高山草甸、岩壁峽谷、溪流源頭）：位在中央，和其他三張圖相接；移動、探索比較累，追擊時在碎石坡、岩壁可能摔傷；巢穴最隱蔽。
- **草原**四區（河岸林帶、大河、開闊草原、丘陵草地）：視野極好（容易看到獵物）但潛近很難；大河要渡河，危險依季節與水量。
- 開局先選出生的地圖（各有小小的開局加成），再選巢穴。
- 年況：每年的冬季（暖冬／普通／嚴冬）、夏季（乾旱／普通／多雨）與雪兔週期，季節卡片上有徵兆。對狼來說嚴冬反而好過（深雪、虛弱的獵物多、凍死的屍體）；**荒年是暖冬、夏末到秋天、雪兔低谷**，這時中大型獵物變少、探索常落空，狼會改獵小獵物。成年獨狼不容易餓死（真實灰狼也能十幾天不吃）。
- 巢穴與睡處品質（巢穴、好睡處、勉強過夜等四級）影響恢復與安全。

### 狩獵

- 分階段：發現 → 觀察／潛近 → 追擊 → 搏鬥，每階段有選項與成功率；因素欄寫出加減的原因（風向、地形、時段、感知、獵物狀態等）。
- 獵物會反應（警覺、逃跑、反擊），可以放棄追擊。
- 1.7 加入：每種獵物有自己的搏鬥力量值與跑法（馴鹿、駝鹿適合「跟隨」耗體力，白尾鹿適合「短衝」）。
- 獵到後分段進食；吃的過程中可能有灰熊、狐狸、狼獾、苔原狼來搶，殘骸會隨時間消失。

### 戰鬥

- 戰鬥模式對灰熊、黑狼、苔原狼、狼獾、狐狸等：每回合選攻擊、騷擾（只對灰熊）、威嚇、示弱、撤退等。
- 對手會依血量、耐力、實力差距放棄或示弱；示弱後可放走或追擊。
- 1.7 加入戰況標籤（佔優、勢均力敵、很難纏）與瀕危警告，讓玩家看得出為什麼會輸。
- 戰鬥中可能死亡；第一次打贏黑狼、第一次獨自擊退灰熊會提高潛力（「強狼」「傳奇狼」的條件）。

### 事件

- 森林：暴雨、狼嚎、被驅趕、灰熊路過、森林大火（約每年一成多；徵兆、逃生選擇、焦黑期、新綠期；暴雨能澆熄；正在燒的區域畫成原本的森林加火光，燒完才是焦黑）。
- 苔原：暴風雪（徵兆、挖雪洞、躲巢穴、撤退、凍傷、風雪後的凍死獵物）、渡鴉、白矇天、春融、苔原狼的相遇與嚎叫、苔原狼圍攻狼獾。
- 快轉（「休息到…」）會被事件打斷。

### 知識與回顧

- 知識系統：經驗累積成「似乎 → 通常 → 確定」的知識，影響判斷與提示。
- 辨識：第一次遇到的動物是「陌生的身影」，辨識後才知道是什麼。
- 換日、睡覺、換季都有結算卡片；第一次打贏灰熊、美洲獅、黑熊、黑狼有專屬卡片與能力加成（受重傷打贏只給約三分之一）。
- 死去時先出一張「最後」字卡交代這一生怎麼結束（老死依所在的地圖寫景，戰死寫出對手），再進一生回顧（死因、擅長、主要獵物、活動方式、經歷）。
- 死亡時自動匯出試玩紀錄（含指標：選了最高成功率的比例、字卡是否秒關等），用來分析平衡。
- 除錯選單可以跳年齡、觸發各種事件。

## 三之二、戰術狩獵原型（開發中，還沒接進主遊戲）

主遊戲的狩獵是選單式（每階段選一個選項）。為了讓狩獵更有「讀局面」的樂趣，正在做格子地圖的回合制原型（開始畫面「狩獵原型」，規格在 `docs/proposals/tactical-hunt-prototype.md`、`tactical-hunt-herd.md`）：

- **場地**：40×16 格，開闊地、密林（擋視線）、倒木；固定風向。狼與獵物各自一格，點格子移動：潛行（回喘）、小跑、衝刺（耗喘，距離依速度）；喘不夠時還能小跑但少一格。
- **獵物的警覺**：看見（距離 × 你的動作，密林擋住）＋聞到（只看風向）；起疑 → 逃跑。逃跑時看得到牠可能的方向（感知越高越準）；逃跑速度依體況、會累。鹿群越大越警覺，一隻驚逃整群跟著跑。
- **撲咬與咬住**：命中率看角度（後方最好）、牠累不累、有沒有察覺；從正面撲容易被踢。撲中只是咬住，之後每回合選：
  - 壓倒（看力量，最耗喘）、咬喉（看技巧，成功就咬死）；
  - 依咬的位置多出：**死咬拖住**（省喘、讓牠更累、比較難甩開）、**咬後腿**（從後方才有；成功後牠跑不快、更容易壓倒）；咬在頸部時咬喉比較容易但被踢得兇；
  - 鬆口；獵物每回合掙扎，可能踢中你或掙脫帶傷逃跑。
- **鹿群**：母鹿帶幼鹿；幼鹿慢、好抓、肉少；只有生母會回頭護幼（命中率低，但被踢中時咬著的幼鹿容易掙脫）；衝進鹿群會讓牠們散開、幼鹿可能和母鹿跑散。
- **馬鹿**：更耐跑、很難壓倒、常把狼甩開或踢傷，肉多。
- **特殊招式（構想：全遊戲 3～5 招，要加入特定狼群、跟著牠們狩獵才學得到，招式分屬不同狼群）**：原型先做「前截鎖喉」（參考黃石的母狼 06）：衝到逃跑的成鹿正前方回身鎖喉，成功直接咬死、失敗容易被撞。
- **模擬結果（摘要）**：不同的狼（慢、普通、快）在不同情境的最好打法不一樣；挑幼鹿「成功率高、少受傷、肉少」對上挑成鹿「肉多、常受傷」；快的狼單獨對馬鹿約四成五，學會鎖喉後約六成、受傷少三成。

## 五、後續開發規劃

Phase 1.7～Phase 2 都已實作完成，目前在試玩與修正；戰術狩獵原型確認好玩後，再決定怎麼接進主遊戲（只用在中大型獵物，小獵物維持快速流程）。之後還要補正式的戰鬥動畫素材，以及把佔位美術換成正式素材（已確定以像素故事畫面的風格為方向）。

近期待做或待討論：
- 鄰近狼群（後半生的壓力來源、特殊招式的學習途徑）。
- 年輕挑戰者的收尾（現在每次被打贏就變強，晚年會一直輸）。
- 字卡太多、很多被秒關。
- 狼群合作狩獵（多隻狼輪流騷擾、包圍；15～25 回合的耐力戰）。

時代背景是**美國西部拓荒時代的偏遠地區**：人類是開墾者、牧場、陷阱獵人與獵狼人，環境對人類也很艱難。這是個人興趣的作品，沒有商業壓力，能增加豐富度的構想都會做，原則是每個階段都能試玩。

長期構想（大方向，實作前再討論）：
- **出生背景**：開局前 2～3 步選擇人生起源（出生環境 → 幼年經歷 → 成年前的轉折，例如領袖被人類射殺、和家人走散），獎勵分成初始能力、成長傾向、知識、記憶；Phase 2 的「開局選地圖」是輕量版。
- **人類威脅系統**（Phase 4）：依區域與季節的「人類活動度＋可達性」決定遇到獵人、陷阱、毒餌的風險。
- **惡名昭彰的狼**：咬越多牲畜、越大越顯眼，越可能被取名、懸賞、被獵狼人追獵（參考狼王羅伯等真實例子）。
- **牧場撤離**：很難達成的隱藏結局，要有狼群、人類反制升級後仍撐住，加上環境本身的壓力。

## 六、還沒決定的事

- 1.8～Phase 2 的初始數值（各獵物的成功率、新競爭者的戰鬥勝率、開局加成）：已用模擬訂出，試玩後調整。
- 試玩紀錄顯示玩家多半選成功率最高的選項（約 0.85）、狩獵成功率約 74%，中後期幾乎沒有生存壓力；方向是用戰術狩獵與鄰近狼群增加取捨，而不是單純調難。
- 苔原狼改大之後的戰鬥平衡（一對一與一對二）。
- 玩家狼的性別：延到 Phase 3。
- 模擬的平均壽命約 10～11 歲（四張地圖輪流；多半老死）。
