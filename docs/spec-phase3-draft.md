## Phase 3：成年期與社會

（2026-10-13 新增，提案之十四，使用者同意。）

### 目標與驗收

- 成年後有一條「家庭」的主線：找到伴侶 → 守住領域 → 養大幼狼 → 帶著家族狩獵 → 看孩子離開。獨居一生仍然是可以活完的路。
- 狼群玩法有深度：分工與群獵的布陣會影響結果；狼群大小、成員的個性與年齡都有意義；鄰群是真正的威脅。
- 一生回顧寫得出一個家族的故事。

### 範圍

| 做 | 不做（之後） |
| --- | --- |
| 玩家只有公狼（資料保留性別欄位） | 母狼玩家、以子女身分繼續玩（長期構想） |
| 離群母狼、配對、伴侶同行 | 人類、牧場（Phase 4） |
| 領域（地盤升級）、鄰群（每張地圖最多一群住在地圖上，其他在地圖外） | 狼群之間結盟、併群；加大地圖 |
| 繁殖、育幼、幼狼長大成成員、離群 | 每隻狼都有動畫的多隻戰鬥 |
| 逐隻的持續指派、群獵時同伴在戰術地圖上的角色 | 隊伍、每天的安排快捷（狼群超過約 5 隻時再看） |
| 加入既有狼群（補空缺）、少見的取而代之 | 次成年時被狼群收留 |
| 狼群中的老年、一生回顧的家族篇 | |

### 狼的資料結構

- 具名 NPC 狼（黑狼、挑戰者、伴侶、子女、鄰群的繁殖者）用同一套 `NpcWolf`：現有的名字、性別、年齡、能力、傷勢、關係與紀錄、會老會死，再補潛力、個性、所屬（獨居／狼群 ID）、父母。你的伴侶與自己狼群的成員都具名。
- 狼群：把 Phase 3a 的 `WolfPack`（黑狼一家）通用化，同一套結構給你的狼群以外的所有鄰群用：帶頭的一對具名，其他成員只記年齡；**只在換季時更新**（生幼狼、死亡、離群、擴張），撞上、打架等事件的結果當下就記上去。
- 你的狼群：成員都是具名的 `NpcWolf`（要繼承、個性、指派），伴侶、幼狼、年輕成員；巢穴、集合點。
- 繁殖者死了：有 1.5 歲以上的子女就接手（同 3a 的換代）；沒有時剩下的那隻撐一季，這一季算「有空缺」（可以加入，見下）；再沒人接手就解散，牠們的區域變成沒有主人。
- 離群的子女：留一筆簡短的紀錄（名字、哪一年離開、往哪裡），之後可能重逢，不再逐季模擬。
- 苔原狼維持一群（數量＋共用的關係值）；其中一隻成為你的伴侶時，才具名化成 `NpcWolf`。
- 共用的「生命事件」紀錄：每筆是 {第幾天、你的年齡、類型、牽涉的狼、區域、少量資料}；年度回顧、一生回顧、家族篇都從這份清單產生。計數類的資料（獵到幾隻等）照現行。

### 性別

- 玩家是公狼。描述照舊不分性別；只有配對、育幼的分工用到性別。

### 離群母狼與配對

- 成年後，秋季到冬末遇到離群母狼的機會最高（擴散季在交配前）；春夏很低。
- 機會（初始值）：**每天換日時擲一次**：
  - 基本：秋冬 1.5%、春夏 0.3%；
  - 這一天嚎叫過（新的「嚎叫」行動）：×3，但也會引來鄰群（見「領域與鄰群」）；
  - 這一天在自己的領域邊界標記過：×1.5；
  - 這一區獵物多：×1.2。
- 粗估（秋冬一年 20 天）：不主動找，一年約 30%、兩年約 52%；每 3 天嚎叫一次，一年約 60%；每天嚎叫，一年約 82%。第 2 步用一生模擬確認（目標：秋冬認真找，1～2 年內配對）。
- 第一次遇到先是遠遠看到，或聞到牠的標記（「一股陌生的母狼氣味，還很新鮮」）；接著可以靠近、跟著、一起吃。
- 關係沿用苔原狼的階段（警戒 → 熟悉 → 友善），再多一階「伴侶」：
  - 讓牠先吃、一起狩獵成功、不在牠面前逃跑或示弱，關係會上升；
  - 搶牠的食物、太久沒出現（7 天以上），關係會下降，牠可能離開這一帶；
  - 每次升降多少：第 2 步以模擬決定（待確認）。
- 到「伴侶」時，牠開始跟你同行；冬季換春季時決定有沒有懷孕（見「繁殖與育幼」）。
- 其他來源：
  - 苔原狼的其中一隻（母狼）失去伴侶，而你和牠們的關係是友善：牠可能留下來跟你（具名化成 NPC；苔原狼不守固定領域，配對後牠跟著你回你的領域）；
  - 加入既有狼群（見下）。
- 伴侶有自己的能力、年齡、個性；也會受傷、老去、死亡。伴侶死去後可以再找。

### 同行與指派

- 伴侶與長大的成員都在「狼群」面板（新的畫面）。
- 逐隻指派，**一直有效直到你改**（管理方案甲，2026-10-30 使用者選）：跟著你、留守巢穴、巡視邊界、自由行動、休息養傷。沒有指派的成員依個性與狀態自己行動。不做隊伍。
- 群獵的角色開場時自動分配，可以改（見「群獵」）。
- 跟著你的成員：一起移動、探索時增加感知（多一雙眼睛）、一起吃、一起睡；遇到戰鬥時一起上。
- 主畫面只顯示跟著你的成員（頭像列），細節在面板裡。

### 群獵

- 有同伴跟著時，狩獵照常進戰術地圖，同伴在地圖上行動（沿用 Phase 2i 苔原狼的同伴）。1.8 和苔原狼的協同狩獵都已經是這套。
- 同伴的角色就是牠在地圖上的行為，不另加成功率：

| 角色 | 在地圖上做什麼 | 現況 | 適合的成員 |
| --- | --- | --- | --- |
| 驅趕 | 繞到獵物另一側衝出去，把牠趕向你；目標是一群時衝進去打散，讓弱者落單（取代原本的「衝散」） | 已有 | 速度快、大膽 |
| 追擊 | 跟著猛追、輪流磨獵物的耐力（取代原本的「接力」） | 已有 | 耐跑 |
| 埋伏 | 停在獵物可能逃的路線上，牠經過時撲 | 新 | 力量大、謹慎 |
| 側翼 | 和獵物平行跑，擋住牠轉向 | 新，第 7 步再看要不要 | 速度快 |

- 開場時依成員的能力、個性與獵物自動分配角色，開場前可以逐隻改；你就是你操作的那隻，不用選角色。
- 數量的效果不另加百分比：咬住時，貼著獵物的每隻同伴照現行規則幫忙（壓倒、咬喉、比較難掙脫）；超過封頂後多的同伴不再加成（＝「不出力」）。封頂（含你，初始值，接 ecology 的 MacNulty 研究）：鹿、騾鹿、馬鹿、馴鹿 4 隻；駝鹿 5 隻；野牛 12 隻。個性「謹慎」的同伴比較晚貼上去、「大膽」比較早。
- 搏鬥：同伴也會挨踢、被角刺，受傷依角色（驅趕、貼著咬的最危險）。
- 分食：大型獵物照數量分段；育幼期先留給巢穴的份（見下）。

### 領域與鄰群

- 有伴侶後，1.9b 的地盤升級成領域：最多 3 個相鄰的區域；巢穴在領域裡。
- **每一區的狀態只有三種**：你的、某個狼群的、沒有主人的。
  - 是誰的：巢穴或核心在那一區，或那一方的標記還新鮮（約 5 天淡掉，照 1.9b）。
  - 標記淡掉不等於失去，只代表鄰群可以進來試探（照 3a 的「試探你的地盤」）。
  - **只在換季時換主人**：被試探、而你在換季前沒補標記，那一區變成牠們的（照 3a）。補標記可以擋住這一季的試探。
  - 打贏鄰群：在你的區打贏，清掉試探、進入冷卻；在牠們的邊界打贏、而且你在那一區標記了，下一次換季時變成你的。
- **鄰群的配置（方案甲，2026-10-30 使用者選）**：地圖不加區域；每張地圖最多一群住在地圖上，其他狼群住在地圖外，只在地圖邊緣（沒有連到其他地圖的區域）出現：
  - 森林：住在地圖上的是黑狼一家（成家前只有獨居的黑狼）；地圖外一群，邊界是森林西部（初始值）。
  - 山地、草原：各一群住在地圖上，開局時核心放在離你的巢穴最遠的那一區；草原另有地圖外一群，邊界是開闊草原（初始值）。
  - 苔原：沒有固定領域的狼群，只有遷徙的苔原狼。
  - 地圖外的狼群：不能去牠們的核心，只會在邊界區撞上、被試探、獵物倍率。
- 黑狼一家照 Phase 3a 已實作的規則（成家的條件、換代、態度紀錄、撞上狼群、試探你的地盤），第 4 步接進通用的狼群結構；黑狼的特別之處只在劇情卡片、和你的過往紀錄、只在森林。
- 邊界：和鄰群相鄰的區域，獵物 ×1.15（3a 的黑狼一家是相鄰區 ×1.1、核心 ×0.7，統一時取一個值），但撞上鄰群的機會高。
- 撞上鄰群：**每個時段**擲一次（一天 5 個時段，睡覺、休息時也擲；3a 現行：核心 4%、相鄰區 1.5%）；你們一起嚎叫過的那天 ×0.6；一次事件後這一群冷卻 8 個時段。
- 撞上時的選擇（沿用 3a）：退開、對峙（雙方嚎叫、比數量）、打。勝負主要看數量，其次是 6 歲以上的狼與成年公狼的比例（ecology：Cassidy 2015）。
- 鄰群也會試探你的領域：標記淡掉、你們數量少時比較常來。

### 繁殖與育幼

- 交配：**冬季換春季的那次換季時擲一次**（季末可能延長，不用「最後 5 天」）；伴侶健康、這個冬天吃得夠時才會懷孕（初始 85%；第一年配對 65%）。
- 產仔：春季第 5 天換日時，胎數 3～6（初始：基本 4，去冬吃得好 +1、年況好 +1、伴侶虛弱 −1）。
- 斷奶前（春季）：
  - 伴侶留在巢穴；
  - 你要把食物帶回巢穴：狩獵後「叼一段回去」（佔一段殘骸），或吃飽後回巢「反芻」（扣你的飽食度）；
  - 伴侶與幼狼每天要吃一定的量，不夠時伴侶會自己出去找（巢穴無人看守），幼狼開始挨餓。
- 斷奶後（夏季）：搬到集合點（巢穴附近的一區），伴侶回來一起狩獵；留守可以指派給其他成員。
- 威脅：灰熊、黑熊、美洲獅、郊狼會靠近巢穴或集合點（初始：每天換日時擲 3%，無人看守 ×2.5）。「無人看守」＝這一天大部分的時段，巢穴（集合點）沒有成年的狼。守巢沿用和苔原狼一起守巢的機制（多隻騷擾，熊多半會退）。
- 事件的優先：巢穴、幼狼的事件不佔每天 2 個事件的上限；鄰群的事件優先於其他隨機事件。
- 幼狼的存活：第一年平均約一半（照生態）。每天依餵食、天氣、威脅計算；一窩越大，每隻的存活越低。
- 秋季幼狼開始跟著行動（照苔原狼「秋冬身後跟著年輕的狼」）；成年前可以帶去學狩獵（跟著時，牠的技巧成長）。

### 狼群成員

- 幼狼滿 1 歲成為「年輕成員」，2 歲成年（照玩家的成長規則）。年齡在換季時增加（同玩家）。
- 能力：父母能力的平均 ±15% 的隨機；潛力同樣繼承。
- 個性：出生時抽 1～2 個標籤：大膽、謹慎、耐跑、黏人、獨立；影響適合的角色、貼上去的早晚、離群的時機。
- 離群（初始）：1～3 歲之間，每年秋冬的換季時有機會離開；個性「獨立」較早、「黏人」較晚；狼群越大、食物越少，越早離開。離開時跳一張卡片，記進生命事件。
- 上限 10 隻：
  - 未滿 1 歲的幼狼不算，滿 1 歲的那次換季開始算；出生不會讓誰立刻離開；
  - 超過上限不會立刻離開，而是提高秋冬換季時的離群機率；
  - 誰先走：繁殖的一對以外，最年長的年輕成員優先，「獨立」加權；
  - 鄰群（含黑狼一家）用同一條規則。

### 衝突與戰鬥

- 沿用現有的三段，不為不同對手各做一套：
  1. 徵兆：足跡、嚎叫、遠遠看到（3a 已有）；
  2. 對峙：狼群是「退開／對峙（比數量）／打」（3a 已有）；單隻的對手是威嚇的三種結果（嚇退／僵持／激怒，2026-10-29 已有）；
  3. 戰鬥。
- 冷卻：每個對手各自計算（每個狼群、黑狼、具名的挑戰者、熊），一次事件後幾個時段內不再出現（黑狼一家現行 8 個時段）。
- 在別人的領域被圍：可以逃（現行被追上的機率），或對狼「示弱」（受一點傷、被趕出這一區，記進態度紀錄）。
- 多隻戰鬥先不做逐隻的動畫：狼群對狼群用「數量與組成決定勝算的對峙」，打起來時同伴每回合有機率咬中（同現行苔原狼圍攻狼獾）；同伴依個性行動，不下指令。畫面最多 3～4 隻的動畫、戰鬥中的指令，第 7 步之後再評估。
- 狼群對灰熊（守殘骸、守巢）：沿用現行的灰熊戰鬥，數量越多熊越快退；照生態，致命很少。
- 狼群對鄰群：最危險，可能有成員死亡；勝方佔走一個邊界區域（照「領域與鄰群」的換主人規則），或對方退回。

### 加入既有狼群（取代「挑戰頭狼」）

- 只在你 **2 歲以上、沒有伴侶**時（避免同時有兩個家；生態上被接納的多半是離群的獨狼）。伴侶死了之後可以。
- 鄰群失去繁殖的公狼（死亡、被趕走）時，出現空缺：
  - 在牠們的邊界一再出現、不搶牠們的獵物、跟著牠們的母狼（關係階段同配對）；
  - 成功後成為這一群的繁殖公狼，接手牠們的領域與成員；那隻母狼成為你的伴侶。成員具名化；前任留下的幼狼、年輕成員一開始的關係是「熟悉」。
- 取而代之（少見）：鄰群的繁殖公狼老弱、受傷時，可以直接挑戰；贏了接手，輸了多半重傷或死亡。贏了但關係不夠的成員會離開，狼群變小（最少留下母狼）。
- 次成年時被狼群收留不做（那是另一種玩法：你不是帶頭的）。

### 狼群中的老年

- 老年後，你帶領的群獵加成下降，年輕成員的加成上升（重心轉到子女）。
- 鄰群衝突時，6 歲以上的狼反而是優勢（生態）：老年的你在狼群裡有自己的角色。
- 1.9b 的年輕挑戰者，在你有狼群時改成「外來的公狼試探你們的領域」；狼群大時牠很少得逞。
- 伴侶死去、你也老了時，可以選擇「把領域留給子女」，自己離開成為獨居的老狼（接 1.9b 的最後一章）。

### 一生回顧

- 加上家族篇：伴侶（名字、在一起幾年、怎麼死的）、每一窩的幼狼與長大的數量、離群子女的去向、你死時狼群還剩誰。全部從共用的生命事件紀錄產生，第 1 步就開始累積。

### 實作順序

1. 基礎：`WolfPack` 通用化成多個狼群（黑狼一家改用它，3a 的回歸測試全部通過）、每張地圖的鄰群配置、`NpcWolf` 補欄位、共用的生命事件紀錄、每個對手各自的冷卻、事件的優先。玩家為公狼。
2. 離群母狼與配對（嚎叫、標記、苔原母狼具名化）。
3. 伴侶同行、狼群面板（持續的逐隻指派）、戰術地圖上的伴侶（驅趕、追擊、埋伏）。
   - 第 2、3 步合起來是一段可以獨立試玩的循環：找到伴侶 → 同行 → 一起探索 → 兩隻一起狩獵 → 一起吃、睡。
   - 通過標準：有伴侶時大型獵物的成功率高 10～20 個百分點；你會依伴侶的角色改變自己的位置（不是每次都潛近到最近）；一場的回合數不超過單狼的 1.5 倍；壯年的作業感有沒有降低（使用者試玩）。
4. 領域與鄰群（領域的三種狀態與換主人、地圖上與地圖外的鄰群、黑狼一家接進通用結構）。
5. 繁殖與育幼（交配、產仔、帶食物回巢、集合點、守巢、幼狼存活）。
6. 狼群成員（長大、繼承、個性、離群、上限）。
7. 群獵擴充（多隻的角色分配、封頂、要不要側翼）與狼群的衝突。
8. 加入既有狼群、取而代之。
9. 狼群中的老年、一生回顧的家族篇。

每一步：自動玩家跟著擴充（會配對、育幼），一生模擬看壽命、子女數、死因。

### 試玩指南

- 第 2 步：秋冬嚎叫、標記，遇到離群母狼；建立關係的節奏合不合理。
- 第 3 步：狼群面板好不好用；伴侶在戰術地圖上驅趕、追擊、埋伏的手感。
- 第 4 步：鄰群的威脅感；邊界獵物多但危險的取捨。
- 第 5、6 步：育幼期帶食物回巢的負擔、幼狼的存活與離群。
- 第 7 步：角色的分配有沒有差別；狼群大時多的同伴不再加成的感覺。
- 第 8、9 步：加入狼群的路線；老年在狼群裡的感覺；一生回顧的家族篇。
