## Phase 3：成年期與社會

（2026-10-13 新增，提案之十四，使用者同意。）

### 目標與驗收

- 成年後有一條「家庭」的主線：找到伴侶 → 守住領域 → 養大幼狼 → 帶著家族狩獵 → 看孩子離開。獨居一生仍然是可以活完的路。
- 狼群玩法有深度：分工與群獵的布陣會影響結果；狼群大小、成員的個性與年齡都有意義；鄰群是真正的威脅。
- 一生回顧寫得出一個家族的故事。

### 範圍

| 做 | 不做（之後） |
| --- | --- |
| 玩家只有公狼（資料保留性別欄位） | 母狼玩家、以子女身分繼續玩（長期構想） |

| 逐隻或整隊的指派、群獵布陣、多隻戰鬥 | |

| 狼群中的老年、一生回顧的家族篇 | |

### 狼的資料結構

- 具名 NPC 狼（黑狼、挑戰者、伴侶、子女、鄰群的繁殖者）用同一套：名字、性別、出生年、能力與潛力、傷勢、個性、所屬（獨居／狼群 ID）、和你的關係與紀錄、會老會死。
- 鄰群的一般成員不具名，只記數量、年齡組成（幼、年輕、成年、6 歲以上）與整體強度。
- 狼群（你的與 AI 的）：成員、繁殖的一對、領域區域、巢穴、標記的新舊、這一年的幼狼。

### 性別

- 玩家是公狼。描述照舊不分性別；只有配對、育幼的分工用到性別。

### 離群母狼與配對

- 成年後，秋季到冬末遇到離群母狼的機會最高（擴散季在交配前）；春夏很低。
- 機會的來源（每天，初始值）：
  - 基本：秋冬每天 1.5%、春夏 0.3%；
  - 嚎叫（新的「嚎叫」行動，或沿用現有的嚎叫）：當天 ×3，但也會引來鄰群（見「領域與鄰群」）；
  - 在自己的領域邊界標記過：×1.5；
  - 這一區獵物多：×1.2。
- 第一次遇到先是遠遠看到，或聞到牠的標記（「一股陌生的母狼氣味，還很新鮮」）；接著可以靠近、跟著、一起吃。
- 關係沿用苔原狼的階段（警戒 → 熟悉 → 友善 → 伴侶）：
  - 讓牠先吃、一起狩獵成功、不在牠面前逃跑或示弱，關係會上升；
  - 搶牠的食物、太久沒出現（7 天以上），關係會下降，牠可能離開這一帶。
- 到「伴侶」時，牠開始跟你同行；冬末交配。
- 其他來源：
  - 苔原狼的其中一隻（母狼）失去伴侶，而你和牠的關係是友善：牠可能留下來跟你（苔原狼不守固定領域，配對後牠跟著你回你的領域）；
  - 加入既有狼群（見下）。
- 伴侶有自己的能力、年齡、個性；也會受傷、老去、死亡。伴侶死去後可以再找。

### 同行、指派與隊伍

- 伴侶與長大的成員都在「狼群」面板（新的畫面）：
  - 逐隻指派：跟著你、留守巢穴、巡視邊界、自己狩獵、休息養傷；
  - 隊伍：把幾隻存成一隊（例如「狩獵隊」「守巢隊」），一鍵套用；最多 3 隊；
  - 沒有指派的成員依個性與狀態自己行動。
- 跟著你的成員：一起移動、探索時增加感知（多一雙眼睛）、一起吃、一起睡；遇到戰鬥時一起上。
- 主畫面只顯示目前跟著你的隊伍（頭像列），細節在面板裡。

### 群獵

- 只在跟著你的成員有 1 隻以上時出現新的選項；1.8 和苔原狼的協同狩獵併進這裡。
- 布陣：進入追擊前，逐隻指定角色，或選一種隊形一次套用。

| 角色 | 作用 | 適合的成員 |
| --- | --- | --- |
| 驅趕 | 把獵物趕向埋伏的位置 | 速度快、大膽 |
| 埋伏 | 在前方攔截，撲擊的主力 | 力量大、謹慎（能等） |
| 側翼 | 防止獵物轉向逃走 | 速度快 |
| 接力 | 輪流追，用自己的耐力磨獵物 | 耐跑 |
| 衝散 | 衝進群裡，讓弱者落後 | 大膽 |

| 隊形 | 角色組合 | 適合的獵物 |
| --- | --- | --- |
| 包抄 | 驅趕＋埋伏（＋側翼） | 單隻的鹿、馬鹿 |
| 接力追擊 | 接力×2 以上 | 駝鹿、馴鹿、叉角羚以外的長距離獵物 |
| 衝散鹿群 | 衝散＋其他人觀察找弱者 | 成群的鹿、馬鹿、馴鹿、野牛 |

- 角色合不合適，會讓這一步的成功率 ±（初始 ±8%）；你自己也要選一個角色。
- 數量的效果（初始值，接 ecology 的 MacNulty 研究）：

| 獵物 | 每多一隻的加成 | 封頂 |
| --- | --- | --- |
| 鹿、騾鹿、馬鹿、馴鹿 | +6% | 4 隻（之後不再增加） |
| 駝鹿 | +5% | 5 隻 |
| 野牛 | +4% | 12 隻 |

- 「不出力」：超過封頂後，每多一隻有 20% 的機率是站在旁邊看（不加成、不受傷）；個性「謹慎」機率較高、「大膽」較低。
- 搏鬥：成員也會挨踢、被角刺，受傷依角色（埋伏、衝散最危險）。
- 分食：大型獵物照數量分段；育幼期先留給巢穴的份（見下）。

### 領域與鄰群

- 有伴侶後，1.9b 的地盤升級成領域：
  - 最多 3 個相鄰的區域（獵物多的地圖 2 區就夠）；
  - 標記沒補，約 5 天淡掉（照 1.9b）；淡掉的區域，鄰群會開始進來；
  - 巢穴在領域裡。
- 每張地圖有 1～2 個 AI 狼群（森林 1＋黑狼的狼群、山地 1、草原 2；苔原沒有固定領域的狼群，只有遷徙的苔原狼）：
  - 各有領域、數量 3～9 隻、繁殖的一對（具名）、年齡組成；
  - 會隨年份增減：生幼狼、成員死亡、離群；
  - 黑狼是特別的劇情角色（使用者決定）：
    - 一開始照現行是獨居的公狼，**只待在森林**（不會出現在其他地圖，牠的狼群也只在森林）；
    - **你滿 3 歲之後**才有機會成立狼群：每年冬季（初始 25%，牠還沒老、健康、還活著時）找到伴侶，在牠的範圍成立狼群；
    - 成立時有專屬的劇情卡片（例如在牠的範圍聽到兩隻狼的合嚎、看到牠身邊多了一隻母狼）；之後牠的狼群是森林的鄰群之一，帶著你和牠的過往紀錄（打贏過、示弱過、被牠趕過），影響牠們試探你領域的頻率與對峙時的態度；
    - 森林的鄰群：一般狼群 1 個；黑狼成立狼群後多 1 個（佔牠原本的範圍）。
- 邊界：和鄰群相鄰的區域，獵物 ×1.15，但撞上鄰群的機會高。
- 撞上鄰群（初始值）：在鄰群領域裡每段 4%、邊界 1.5%；你們一起嚎叫過的那天 ×0.6。
- 撞上時的選擇：退開、對峙（雙方嚎叫、比數量）、打。
  - 勝負主要看數量（多一隻，勝算明顯提高），其次是 6 歲以上的狼與成年公狼的比例（ecology：Cassidy 2015）；地點不影響。
  - 單獨在別人的領域被發現：很危險，被包圍時要先逃。
- 鄰群也會試探你的領域：標記淡掉、你們數量少時比較常來。

### 繁殖與育幼

- 冬末（冬季最後 5 天）交配；伴侶健康、這個冬天吃得夠時才會懷孕（初始 85%；第一年配對 65%）。
- 春季第 5 天左右產仔，胎數 3～6（初始：基本 4，去冬吃得好 +1、年況好 +1、伴侶虛弱 −1）。
- 斷奶前（春季）：
  - 伴侶留在巢穴；
  - 你要把食物帶回巢穴：狩獵後「叼一段回去」（佔一段殘骸），或吃飽後回巢「反芻」（扣你的飽食度）；
  - 伴侶與幼狼每天要吃一定的量，不夠時伴侶會自己出去找（巢穴無人看守），幼狼開始挨餓。
- 斷奶後（夏季）：搬到集合點（巢穴附近的一區），伴侶回來一起狩獵；留守的工作可以指派給其他成員。
- 威脅：灰熊、黑熊、美洲獅、郊狼會靠近巢穴或集合點（初始：每天 3%，無人看守 ×2.5）；守巢沿用和苔原狼一起守巢的機制（多隻騷擾，熊多半會退）。
- 幼狼的存活：第一年平均約一半（照生態，明尼蘇達的高密度地區更低）。每天依餵食、天氣、威脅計算；一窩越大，每隻的存活越低。
- 秋季幼狼開始跟著行動（照苔原狼「秋冬身後跟著年輕的狼」）；成年前可以帶去學狩獵（跟著時，牠的技巧成長）。

### 狼群成員

- 幼狼滿 1 歲成為「年輕成員」，2 歲成年（照玩家的成長規則）。
- 能力：父母能力的平均 ±15% 的隨機；潛力同樣繼承。
- 個性：出生時抽 1～2 個標籤：大膽、謹慎、耐跑、黏人、獨立；影響適合的角色、不出力的機率、離群的時機。
- 離群（初始）：1～3 歲之間，每年秋冬有機會離開；個性「獨立」較早、「黏人」較晚；狼群越大、食物越少，越早離開。離開時跳一張卡片；一生回顧記下牠。
- 上限：狼群 10 隻（G-2），超過時年輕的成員會被擠出去（離群）。

### 多隻對多隻的戰鬥

- 1.9 的戰鬥演出擴充：
  - 畫面最多 3～4 隻，其他用文字帶過；
  - 你可以對成員下指令（逐隻或整隊）：夾擊、騷擾、退後、保護受傷的同伴；沒有指令的依個性行動。
- 狼群對灰熊（守殘骸、守巢）：沿用現行的灰熊戰鬥，數量越多熊越快退；照生態，致命很少。
- 狼群對鄰群：最危險，可能有成員死亡；勝方佔走一個邊界區域，或對方退回。

### 加入既有狼群（取代「挑戰頭狼」）

- 鄰群失去繁殖的公狼（死亡、被趕走）時，出現空缺：
  - 你獨居或沒有伴侶時，可以在牠們的邊界一再出現、不搶牠們的獵物、跟著牠們的母狼（關係階段同上）；
  - 成功後成為這一群的繁殖公狼，接手牠們的領域與成員（成員會帶著前任的幼狼）。
- 取而代之（少見）：鄰群的繁殖公狼老弱、受傷時，可以直接挑戰；贏了接手，輸了多半重傷或死亡。
- 年輕（次成年）時被接納的機會比成年高（照 1.7b 的鋪陳）。

### 狼群中的老年

- 老年後，你帶領的群獵加成下降，年輕成員的加成上升（重心轉到子女）。
- 鄰群衝突時，6 歲以上的狼反而是優勢（生態）：老年的你在狼群裡有自己的角色。
- 1.9b 的年輕挑戰者，在你有狼群時改成「外來的公狼試探你們的領域」；狼群大時牠很少得逞。
- 伴侶死去、你也老了時，可以選擇「把領域留給子女」，自己離開成為獨居的老狼（接 1.9b 的最後一章）。

### 一生回顧

- 加上家族篇：伴侶（名字、在一起幾年、怎麼死的）、每一窩的幼狼與長大的數量、離群子女的去向、你死時狼群還剩誰。

### 實作順序

1. 狼的資料結構整理（具名 NPC 狼通用化、狼群資料）、玩家為公狼
2. 離群母狼與配對（嚎叫、標記、苔原狼補位）
3. 伴侶同行、狼群面板（逐隻與隊伍指派）、兩隻的群獵（包抄）
4. 領域與鄰群（AI 狼群、邊界、撞上鄰群、黑狼成立狼群）
5. 繁殖與育幼（交配、產仔、帶食物回巢、集合點、守巢、幼狼存活）
6. 狼群成員（長大、繼承、個性、離群、上限）
7. 群獵完整版（布陣的角色與隊形、數量遞減、不出力）與多隻戰鬥
8. 加入既有狼群、取而代之
9. 狼群中的老年、一生回顧的家族篇

### 試玩指南

- 第 2 步：秋冬嚎叫、標記，遇到離群母狼；建立關係的節奏合不合理。
- 第 3 步：狼群面板好不好用；兩隻包抄的手感。
- 第 4 步：鄰群的威脅感；邊界獵物多但危險的取捨。
- 第 5、6 步：育幼期帶食物回巢的負擔、幼狼的存活與離群。
- 第 7 步：布陣的選擇有沒有差別；狼群大時「不出力」的感覺。
- 第 8、9 步：加入狼群的路線；老年在狼群裡的感覺；一生回顧的家族篇。
