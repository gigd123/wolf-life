# 苔原詳細規格

SPEC.md「苔原」要求開工前另寫一份詳細規格。這份是實作 6a 時依 SPEC 與 DESIGN.md 草擬的版本，**2026-10-02 使用者確認通過**（含 6b、6c 的提案）；數值都是初始值，之後依試玩調整。可以再併入 SPEC.md。實際數值以資料檔為準（`data/regions.json`、`data/balance.json`），這裡記錄設計的理由。

## 跨地圖的基礎建設（6a，已實作）

- 大地圖寫在 `regions.json` 的 `maps`：每張地圖有名稱、地圖按鈕的 2×2 排列（`layout`）、會不會起火（`fire`）、嚴寒（`cold`）。每個區域多一個 `map` 欄位。
- 跨地圖的連接寫在 `links`（雙向）：森林北部 ↔ 苔原林線，3 回合（DESIGN.md「移動回合」森林↔苔原 2 回合，加上抵達後選區域的 1 回合），額外消耗體力 8。
- 地圖畫面顯示目前所在的那張地圖，有連接的區域下方多一個「前往苔原（3 回合）」按鈕。
- 區域知識、獵物出沒知識、危險知識都以區域 id 記錄，區域 id 不重複，所以自然按地圖分開。存檔不需要另外的欄位（目前的地圖由所在區域決定）；一生回顧記錄去過的地圖（`life_log.maps_visited`）。
- 巢穴可以選在另一張地圖：「在這裡安家」依區域的 `can_den`。開局仍只能選森林。
- Phase 2 加山地、草原時，只要在 `maps`、`links`、`regions` 加內容。

## 森林大火與苔原（6a，已實作）

- 使用者決定：有苔原之後，大火的延燒恢復原本的強度（每個時段 55%），有機會燒掉整片森林。
- 在森林北部時，逃生多一個「逃進苔原林線」（危險度 0.4，介於逃往其他森林區域 0.55 與溪邊 0.25 之間）。

## 6c：駝鹿（已確認）

- 大型獵物，單獨行動，主要在河谷（權重 3），林線 1。
- 體型比雄鹿大很多：搏鬥時正面踢擊反擊，單狼極難獵捕。提案：反擊 45、飽食度 150（分 5 段吃），搏鬥的被踢中部位以腿為主（影響速度）；完整深度狩獵，追擊中可能轉身站定（比雄鹿更常）。
- 美術：`moose`、`moose_run`、`moose_kick`、`moose_hurt`、`carcass_moose`。

## 6d：苔原的事件（已實作，與草案的差異見 progress.md「已採用的做法」）

2026-10-02 使用者決定：苔原的大小事件、狼獾、渡鴉都放在 1.6。狼獾、渡鴉的美術之後補上，先用程式佔位。設計方向是沿用森林的兩種模式：一個「有徵兆、要選擇、留下後果」的大事件，加上會反覆出現的角色與小事件；苔原的主軸是「寒冷」與「搶食」。

### 暴風雪（大事件，對應森林大火）

- 大火在夏秋把狼往北推，暴風雪在冬季把狼往南推回林線，讓「什麼季節住哪裡」成為一年裡的取捨。
- 發生：只在冬季、只在苔原。每個冬季約 40% 機率發生一次，持續 2～3 天；狼在森林時不受影響（只聽到北方的風聲）。
- 徵兆（起事前 1～2 個時段，感知越高越早察覺，會打斷快轉）：風突然停了、天色發黃；雪兔都躲進雪裡，馴鹿背風擠成一團。
- 選擇（各附平安率）：在雪地挖洞躲著（消耗少，但飢餓累積）、躲進巢穴或沙脊、頂著風往林線撤退（可能在白茫茫中走錯區域）。
- 後果：期間嚴寒消耗 ×3、不能狩獵；可能凍傷（耳朵、腳掌），重度凍傷可能留下舊傷。
- 事後：雪地上出現凍死的馴鹿或駝鹿（冬殺），幾天內可以撿到屍體，但灰熊、狼獾也會來搶。
- 一生回顧記下經過。

### 狼獾（具名角色，對應陌生灰狼）

- 體型小但極兇猛的搶屍者。沿用 `NpcWolf` 的結構（具名、持續存在、有能力值、年齡與相遇紀錄），之後泛化為「具名 NPC 動物」。
- 牠爭的是「你的食物」，不是地盤：會尾隨你、在你吃不完的屍體或殘骸旁出現、偷吃苔原的殘骸。
- 戰鬥沿用戰鬥模式：力量值約 110（比狐狸強很多、比灰熊弱很多），傷害不高但很少放棄（耐力低於 15% 才退）；牠不會想殺你。對峙時可以讓牠吃一部分（失去一段）換牠離開。
- 每次相遇與勝負記入一生回顧。

### 渡鴉（小事件，不戰鬥）

- 看到渡鴉在遠處盤旋：可以跟過去，有機會找到屍體（撿食）。
- 你在苔原獵到大型獵物時會引來渡鴉：分段進食時，灰熊、狼獾找上門的機率隨時間增加得更快（吃得越久，越多動物知道）。

### 白矇天（小事件）

- 開闊苔原、遠北偶爾起霧或刮白毛風，持續 1～2 個時段：探索與狩獵的感知 −20%，移動有機會走錯到另一個相鄰區域。

### 春融（小事件）

- 春季的苔原河谷河冰變薄：從河谷移動到相鄰區域時可以選「走冰面」（少 1 回合，但有落水風險：體力歸零、受凍）。

## 6e：苔原狼（已實作，數值與差異見 progress.md）

2026-10-02 使用者提議：苔原上的另一種狼，現在是競爭對手，Phase 3 有機會配對或成為狼群的一份子；體型比北美灰狼小一些，但比郊狼強大許多。使用者會補做美術。

- 生態上是灰狼的亞種（北美的苔原狼／荒原狼跟著馴鹿遷徙），和玩家同種，之後配對、成為狼群一員都合理。
- 不是固定盤踞一地的獨狼，而是一對（或一小群）跟著馴鹿遷徙的狼：春秋遷徙季節出現在開闊苔原、河谷，冬季偶爾到林線，夏季遠在遠北。和陌生灰狼「守地盤」的模式不同。
- 沿用 `NpcWolf`：每隻都有能力值（約灰狼的 85%：力量 60～66、速度 70～76、技巧 60～66，速度略快）、年齡、紀錄；戰鬥力量值約 125。
- 互動：遠方的嚎叫（可以「回應嚎叫」）、在馴鹿群附近相遇、在屍體旁爭食。可以避開、跟隨、威嚇、挑戰，也可以「讓牠們先吃」或「保持距離一起守著屍體」。
- 關係值（1.6 只記錄，不做配對與狼群）：回應嚎叫、讓牠們先吃、不起衝突的相遇會讓牠們對你越來越熟悉；攻擊、搶食會讓牠們敵視你。Phase 3 依關係值決定能不能配對或加入。
- 戰鬥：和陌生灰狼相同，雙方都能示弱；牠們通常兩隻一起，打起來更危險（第二隻偶爾插進來）。
- 美術需求：spritesheet（待機、走路、嚎叫、倒下，格式同 `wolf_sheet.png`，毛色偏淺、體型略小）、戰鬥姿勢（威嚇、撲咬、閃避、受傷、示弱）、兩隻並排的圖（可選）。

## 實作順序（提案）

6b 雪兔、北美馴鹿 → 6c 駝鹿 → 6d 暴風雪、狼獾、渡鴉、白矇天、春融 → 6e 苔原狼。暴風雪的冬殺屍體與渡鴉需要馴鹿、駝鹿，苔原狼跟著馴鹿遷徙，所以放在 6b、6c 之後。
