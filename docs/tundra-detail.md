# 苔原詳細規格

SPEC.md「苔原」要求開工前另寫一份詳細規格。這份是實作 6a 時依 SPEC 與 DESIGN.md 草擬的版本，**2026-10-02 使用者確認通過**（含 6b、6c 的提案）；數值都是初始值，之後依試玩調整。可以再併入 SPEC.md。實際數值以資料檔為準（`data/regions.json`、`data/balance.json`），這裡記錄設計的理由。

## 跨地圖的基礎建設（6a，已實作）

- 大地圖寫在 `regions.json` 的 `maps`：每張地圖有名稱、地圖按鈕的 2×2 排列（`layout`）、會不會起火（`fire`）、嚴寒（`cold`）。每個區域多一個 `map` 欄位。
- 跨地圖的連接寫在 `links`（雙向）：森林北部 ↔ 苔原林線，3 回合（DESIGN.md「移動回合」森林↔苔原 2 回合，加上抵達後選區域的 1 回合），額外消耗體力 8。
- 地圖畫面顯示目前所在的那張地圖，有連接的區域下方多一個「前往苔原（3 回合）」按鈕。
- 區域知識、獵物出沒知識、危險知識都以區域 id 記錄，區域 id 不重複，所以自然按地圖分開。存檔不需要另外的欄位（目前的地圖由所在區域決定）；一生回顧記錄去過的地圖（`life_log.maps_visited`）。
- 巢穴可以選在另一張地圖：「在這裡安家」依區域的 `can_den`。開局仍只能選森林。
- Phase 2 加山地、草原時，只要在 `maps`、`links`、`regions` 加內容。

## 嚴寒（6a，已實作）

在苔原每個時段額外消耗（再乘區域的嚴寒倍率）：

| 季節 | 飽食度 | 體力 |
| --- | --- | --- |
| 冬 | −3 | −4 |
| 春、秋 | −1 | −1 |
| 夏 | 0 | 0 |

冬季在苔原時，頂部顯示嚴寒圖示。遠北的冬天每個時段約 −4.5 飽食度、−6 體力，加上原本的 −4 飽食度，一天要多吃約 40。

## 森林大火與苔原（6a，已實作）

- 使用者決定：有苔原之後，大火的延燒恢復原本的強度（每個時段 55%），有機會燒掉整片森林。
- 在森林北部時，逃生多一個「逃進苔原林線」（危險度 0.4，介於逃往其他森林區域 0.55 與溪邊 0.25 之間）。

## 6c：駝鹿（已確認）

- 大型獵物，單獨行動，主要在河谷（權重 3），林線 1。
- 體型比雄鹿大很多：搏鬥時正面踢擊反擊，單狼極難獵捕。提案：反擊 45、飽食度 150（分 5 段吃），搏鬥的被踢中部位以腿為主（影響速度）；完整深度狩獵，追擊中可能轉身站定（比雄鹿更常）。
- 美術：`moose`、`moose_run`、`moose_kick`、`moose_hurt`、`carcass_moose`。
