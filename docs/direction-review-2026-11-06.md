# 方向檢查：Claude Code 的分析（2026-11-06）

回應使用者與 ChatGPT 討論後的〈《狼之一生》核心方向補充與開發原則〉（2026-11-06）第九節的七個問題。只是分析與建議，**沒有改規格或實作**；要改設計支柱、規則時另外提案、使用者同意後才寫入。前一份整理是 `docs/status-and-direction-2026-11-06.md`。

## 那份文件的重點（摘要）

- 核心定位：玩家親身經歷一隻狼的一生。優先順序 **B 人生故事感（主要）> A 生存成就感 > C 世界探索感**；重視「經歷與見證」，不刻意煽情。
- 戰術狩獵與戰鬥保留、是正確方向（取代甩骰子感）；避免每次都沒有新判斷的重複流程；日常小獵物可以簡化；「交給本能」應該是信任能力與知識的選擇；戰術場景要隨年齡、家庭、環境不同。
- HD-2D 保留為正式視覺方向，先不做正式美術。
- 三個層次：狼的一生（核心）、自然探索與生存、戰術互動，要形成連續循環。
- 成年後的壓力優先來自玩家已經擁有的東西（家庭、伴侶、領域、熟悉的環境）；驗證順序：家庭責任、狼群與領域競爭、季節與生態變化、人類活動。
- 一生回顧不只是統計，要呈現這一生的獨特之處；保留世界延續的感覺。
- 策略：先驗證整合後的體驗，再擴充；食物、事件頻率、卡片閱讀率等要結合真人試玩，不只看模擬。
- 新功能的七個檢查問題（生命故事、理解自然、選擇的結果、不同階段的差異、決策價值、會不會更重複、是不是現在要做）。

## 一、Phase 1～3 有沒有支援「經歷一隻狼的一生」

**骨架有，故事感多半要到死後的回顧才出現。**

- 有：完整的生命階段（次成年 → 2 歲成年 → 6 歲老年 → 老死）、配對、生小狼、子女離群、接手狼群、生命事件紀錄（`GameState.add_life_event`）、年度回顧；一生回顧有家族篇（伴侶怎麼開始和結束、幾窩養大幾隻、誰離群到哪裡建立狼群、死時留下誰；`LifeSummary._family_lines`）。
- 缺：玩的當下，重要的時刻和日常用差不多的卡片呈現，而試玩紀錄裡一半的卡片 1 秒內被按掉；大段時間交給「照常過日子」。人生故事是事後讀到，不是當下經歷到。

## 二、哪些系統互相支援，哪些還是獨立的

- 已經連起來：吃飽 → 成長 → 潛力 → 戰鬥勝率；季節與年況 → 獵物分布 → 飢餓；知識 → 狩獵時看得清不清楚；小狼要餵 → 春夏必須多獵（模擬裡要餵小狼的春夏約 36% 的天挨餓）；鄰群與領域 → 在哪裡狩獵。
- 比較獨立：大火、暴風雪、鮭魚洄流、猞猁、灰熊藏食、美洲獅藏屍、狼獾、小撲——多半是「遇到 → 選一次 → 結束」，不太改變之後的人生。狩獵傾向在試玩紀錄裡效果只有 0.01。戰鬥原型的知識等級還沒接到主遊戲的知識系統。

## 三、家庭與領域能不能讓成年不一樣

規則上有空間，要試玩驗證。最擔心的是家庭運作得太「自動」：小狼自己長大、自己離群，玩家能做的決定主要是巢穴放哪、反芻餵食。要看的是：**有了家庭後，玩家去哪、獵什麼、冒不冒險有沒有改變**；沒有的話，家庭就只是多幾張卡片。

## 四、戰術場景怎麼和人生結合

現在不同年齡的差別主要是能力值，加上伴侶或狼群同行。比較能結合的做法是**讓戰術的「賭注」來自人生狀態**：帶肉回巢給小狼（叼著肉撤退本身是目標）、領域邊界的衝突牽涉家人、老了改成搶食與伏擊。這些會改變玩法，之後要做時再提方案。

戰術場景的頻率（同意看試玩決定），可能的方向：

| 方案 | 做法 | 好處 | 代價 |
| --- | --- | --- | --- |
| A 情境決定 | 小獵物快速結算；中大型與特殊情境才進戰術 | 節奏穩、重要的狩獵有份量 | 小狩獵失去操作感 |
| B 玩家每次選 | 每次狩獵問「親自狩獵／交給本能」；本能的表現跟著知識、經驗長 | 符合「信任本能」，玩家控制節奏 | 本能太好用時玩家就不親自打 |
| C 人生階段決定 | 小時候多親自（學習）；成年後熟悉的獵物自動、陌生的親自 | 最貼近「一生」 | 規則最複雜 |

Claude Code 傾向 **B 加一點 A**（小獵物預設快速，其他讓玩家選）。

## 五、一生回顧與世界延續缺什麼

- 回顧：現在多半是「幾歲做了什麼」的條列；缺章節結構（幼年、離家、成家、全盛、衰老）、少數幾個關鍵抉擇、重要的地點、具名的對象（伴侶、宿敵、子女）。
- 世界延續（目前只到「死時留下了誰」）：

| 方案 | 內容 | 成本 | 對核心的影響 |
| --- | --- | --- | --- |
| A 尾聲字卡 | 死後幾年的簡短後記（子女的狼群、黑狼一家、你的領域後來怎樣） | 低 | 加強「曾經是世界的一部分」 |
| B 下一隻狼在同一個世界 | 下一局看得到前一隻狼留下的痕跡（後代、地盤、氣味標記） | 中高 | 局與局之間有連結，可能稀釋單一生的完整感 |
| C 扮演子女繼續 | 死後選一隻子女接著玩 | 高 | 核心從「一生」變成「家族史」 |

建議先 A，B 列為長期構想。

## 六、保留、整合、簡化、暫緩

- 保留：生命階段與成長、Phase 3 家庭、戰術狩獵、知識、季節與年況、一生回顧。
- 整合：戰術戰鬥接進主遊戲（取代選單式的灰熊、美洲獅戰鬥）；戰鬥原型的知識等級接到主遊戲的知識；藏食物、搶食與「餵家人」連起來。
- 簡化：卡片數量（重要時刻和例行事件分開呈現）、小獵物的狩獵流程、重疊的搶食事件（灰熊搶食、灰熊藏食、美洲獅藏屍）。
- 暫緩：人類系統的擴充（牧場以外）、出生背景、特殊招式、群戰、正式美術、食物方案 B。
