# 設計支柱（草稿，2026-10-14）

《狼之一生》的設計判斷基準，一頁內讀完。新系統的提案、規格與試玩驗證都拿這份對照。
內容由 Claude Code 從 `DESIGN.md` 與 2026-10 的討論整理，標【待確認】的是推測，需要使用者改寫或刪掉。

## 一、這是什麼遊戲

扮演一隻北美灰狼，從 8 個月大活到死亡。沒有主線、沒有勝負，只有這一生怎麼過；每一局因為世界的變化與自己的選擇而不同。

## 二、核心樂趣（依重要性）

1. **成長與生命歷程**：從笨拙的次成年狼，長成熟練的獵手，再老去；回頭看，這一生有起伏、有故事。（使用者試玩時最喜歡的部分）
2. **讀懂自然**：從蹤跡、氣味、季節、天氣判斷「今天該去哪、該追什麼」；判斷對了是自己的本事。
3. **局勢會變**：世界不會停在原地。獵物會移動、鄰群會擴張、會遇到嚴冬；玩家找到的舒適圈遲早會被打破，要重新適應。
4. **有份量的取捨**：重要的狩獵和衝突，值得花心力想；每個選擇都有代價。
5. 【待確認】**狩獵與戰鬥本身的操作樂趣**：見「七、待討論」。

## 三、玩家應該面對的決策

- **去哪裡**：食物多的地方通常也危險（灰熊、鄰群、人類），安全的地方食物少。
- **追不追**：值不值得為這頭獵物花體力、冒受傷的風險；現在追，還是等更好的時機。
- **賭不賭**：成功率高但收穫小，或成功率低但收穫大；失敗的後果不同，不只是「沒抓到」。
- **留不留**：守住獵物還是放棄、留在這區還是搬走、留在狼群還是離開。
- **長期規劃**：為冬天、為繁殖季、為老年做準備。

檢驗：**玩家要有理由不選當下成功率最高的選項。**如果最高成功率長期也是最好的選擇，選項再多也只是一種策略。

## 四、不想變成的樣子

- **作業**：每天重複一樣的步驟、一樣的最佳解。
- **隨機懲罰**：威脅要看得到徵兆、可以避開；死亡或失敗事後回想，要能說出「我哪裡判斷錯了」。
- **為複雜而複雜**：多一層操作卻沒有多一個有意義的選擇，就不要做。
- **數值堆疊**：內容變多，但決策結構沒有變。
- **違背生態**：規則可以簡化，但不要做出狼不會做、或做不到的事。【待確認】生態準確和好玩衝突時，哪一邊優先？

## 五、新系統的檢驗問題

世界的變數（獵物分布、鄰群、天氣、人類）至少要符合五個條件中的大部分：

1. 會延續（不是一次性事件）
2. 會移動或改變
3. 有看得到的徵兆
4. 會改變最好的決策
5. 會回應玩家的行為

提案時另外回答：

- 這個系統讓玩家多了什麼決策？
- 失敗時發生什麼事？和其他選項的失敗有什麼不同？
- 怎麼驗證？寫下「假設、驗證方式、通過標準」，能用 AutoPlayer 多種子模擬的就用模擬。

### 生態、抽象、體驗三項檢查

每個重要系統（會影響玩法的規則，不含介面與數值微調）在提案時都寫出這三項：

1. **生態依據**：真實的狼與獵物是怎麼做的？標出可信度（研究／記述／推論，同 `ecology-reference.md`）。
2. **遊戲抽象**：遊戲裡簡化成什麼樣子？哪些細節省略了、為什麼可以省略？
3. **玩家體驗**：玩家看得懂這條規則嗎？能利用它做出判斷嗎？它帶來的是決策，還是只是數值懲罰？

三者不必完全一致，但要寫出差異在哪裡、為什麼接受這個差異。

只看單一系統時，三項常常都說得通，組合起來卻不對。所以也要檢查：

- **真實但沒有決策**：例如成年獨狼很少餓死（生態正確），所以荒年不會造成飢餓。這時壓力要從別的地方來，而不是硬把飢餓加重。
- **合理但只剩懲罰**：例如老狼會衰退，但老年的玩法不能只有數值一路往下掉，要有新的判斷（經驗、取捨）。
- **細節不必逐一模擬**：例如群獵不必逐隻模擬每個動作，只要關鍵的戰術與代價呈現得出來。

例：戰術狩獵的「死咬拖住」。

- 生態：狼常咬住獵物後腿或腰腹，用體重拖住，等獵物力竭。
- 抽象：簡化成咬住後的一個選項，消耗比撲咬少，但要多耗幾回合。
- 體驗：玩家要在「現在搏一把殺掉」和「慢慢耗、但可能被甩開或被踢」之間選擇。

## 六、決策分工

| 層級 | 誰決定 | 例子 |
| --- | --- | --- |
| 1. 核心體驗 | 使用者 | 這份文件、遊戲要給什麼樂趣、範圍與優先順序 |
| 2. 影響玩法的規則 | Claude Code 提 2～3 個方案與代價，使用者選 | 狩獵流程、失敗的後果、鄰群怎麼運作、獨狼與狼群的差異 |
| 3. 可逆的實作細節 | Claude Code | 程式結構、介面實作、初始數值、測試 |

- 第 2 層的提案要標出哪些是 Claude Code 的假設。
- 實作時發現規則有矛盾，先問，不自己改規則。
- 先做最小可玩版本並試玩，確認成立再擴充。

## 七、待討論

- **狩獵與戰鬥的形式**：使用者原本設想的是戰術回合型（B：判斷距離、獵物方向、體力、包圍位置）。目前做出來的是數值選單型（A）和事件抉擇型（C）的混合。B 可玩度可能更高，但開發與平衡成本也高，而且和 Phase 3 的群獵布陣、HD-2D 的場景演出都有關係。另外開一次討論決定。
- 【待確認】生態準確與好玩衝突時的優先順序。
- 【待確認】一局大約想玩多久；一生裡「平穩期、變動期、適應期」大約怎麼分配。
