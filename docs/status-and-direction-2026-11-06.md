# 《狼之一生》目前進度與方向檢查（2026-11-06）

給使用者和 ChatGPT 討論用。整理「已經做了什麼、接下來要做什麼」，再加上 Claude Code 對「這個方向好不好玩」的看法。
更完整的遊戲內容說明在 `docs/project-overview.md`（10-16 版，Phase 3 之後的部分以這份為準）；設計判斷基準在 `docs/design-pillars.md`。

---

## 一、一句話

扮演一隻北美灰狼，從 8 個月大活到死亡的單機生存養成遊戲（Godot 4、繁體中文、目標 Steam）。沒有勝負，只有「這一生怎麼過」。

使用者定的核心樂趣（依重要性）：
1. 成長與生命歷程（從笨拙的小狼長成獵手再老去，回頭看有故事）
2. 讀懂自然（從蹤跡、氣味、季節判斷該去哪、追什麼）
3. 局勢會變（舒適圈會被打破，要重新適應）
4. 有份量的取捨（重要的狩獵和衝突值得想）

檢驗問題：**玩家要有理由不選當下成功率最高的選項。**

## 二、已經做了什麼

規模：核心邏輯約 1.9 萬行、畫面約 1 萬行 GDScript；91 個 headless 模擬／回歸測試；約 2500 條文案。美術全是佔位圖。

### 1. 主遊戲（全部「實作完成」，但大多**還沒經過真人試玩驗收**）

| 範圍 | 內容 |
| --- | --- |
| 一生 | 8 個月大開始 → 2 歲成年 → 6 歲起老年 → 老死（平均約 10 歲）。能力值（速度、力量、技巧、感知、血量）靠「做」和吃飽成長，成年時依成長定潛力上限；傷勢、舊傷、體質 |
| 一天 | 一天五個時段、四季、年況（暖冬／嚴冬、乾旱／多雨、雪兔週期）；探索（四種方式）、狩獵、移動、睡覺、休息、藏食物；「照常過日子」自動代玩幾天 |
| 地圖 | 森林、苔原、山地、草原各四區，加上牧場（拓荒時代的人類） |
| 動物 | 約 25 種：鹿類、馴鹿、駝鹿、野牛、叉角羚、大角羊、河狸、旱獺、兔類、鮭魚；灰熊、黑熊、美洲獅、狼獾、郊狼、狐狸、猞猁、渡鴉；黑狼、苔原狼、其他狼群；家畜與獵狼人 |
| 狩獵 | **戰術格子地圖**（40×16，潛行／小跑／衝刺、風向與視線、警覺、逃跑方向、撲咬→咬住後選壓倒／咬喉／死咬拖住／咬後腿）。所有狩獵都走戰術場景，可「交給本能」自動打完 |
| 戰鬥 | 選單式回合（攻擊、騷擾、威嚇、示弱、撤退），對手會放棄或示弱；有戰況標籤 |
| 事件 | 森林大火、暴風雪、渡鴉、鮭魚洄流、灰熊搶食、美洲獅藏屍、灰熊藏食、牧場與獵狼人 |
| 社會（Phase 3） | 遇到離群母狼 → 配對 → 伴侶同行與一起狩獵 → 領域與鄰群 → 生小狼、反芻餵食 → 子女成長、離群 → 加入或接手狼群 → 老年被挑戰；一生回顧的家族篇 |
| 知識 | 經驗累積成「似乎 → 通常 → 確定」，影響判斷與提示；第一次見到的動物要先辨識 |
| 回顧 | 年度回顧、死亡字卡、一生回顧；死亡時自動匯出試玩紀錄（給平衡分析用） |

### 2. 最近做的（2026-11-04～06）

- **戰術戰鬥原型**（主選單「戰鬥原型」，還沒接進主遊戲）：和灰熊、美洲獅在格子地圖上搶食、守食、遭遇、伏擊。對手每回合先「預告」要做什麼，玩家依知識看得清不清楚，再決定移動＋動作；同步結算。伴侶可以下指令（牽制、叼肉、退開）。目標是「打不贏，但能靠判斷搶到一點肉再脫身」。使用者試玩：**覺得不錯**；同步當正式方向。
- **HD-2D 畫面**（3D 地形＋像素角色，類似《三角戰略》）：先做測試場景，使用者滿意；已套到戰鬥原型和主遊戲的戰術狩獵（可切回 2D），可縮放、捲動。正式美術之後才做。

### 3. 使用者實際試玩過的

- 早期版本（Phase 1～2）的完整一生數次：**最喜歡的是成長與生命歷程**。
- 最近：戰術戰鬥原型、HD-2D 測試（都覺得不錯）。
- **還沒試玩**：Phase 2b 之後到 Phase 3 的整合版本（很多系統是模擬驗證過，真人沒玩過）。

## 四、方向檢查：會不會不好玩？（Claude Code 的看法）

### 好的跡象

- **使用者最喜歡的「一生的成長」是真的成立過**，而且是這個遊戲獨特的地方（很少遊戲讓你從小狼活到老死）。
- 戰術狩獵、戰術戰鬥兩個原型試玩都覺得不錯，代表「讀局面、做判斷」這層有樂趣。
- 生態資料紮實，世界有「真實感」——這是賣點，也是讀懂自然的基礎。

### 試玩紀錄裡的警訊（2026-11-04，Phase 2 版本、3.7 歲、167 分鐘）

| 指標 | 數字 | 意思 |
| --- | --- | --- |
| 決策時是吃飽的 | 95% | 生存壓力幾乎沒有 |
| 選了成功率最高的選項 | 76% | 多半有一個明顯的最佳解 |
| 卡片出現 1 秒內就按掉 | 50% | 很多文字沒在讀 |
| 每天的事件 | 0.5 個；最長 11 天沒事 | 平淡的日子多 |
| 遊玩時間 | 3.7 歲用了 167 分鐘 → 一生約 7～8 小時 | 一生很長，中段容易重複 |

### 主要風險

1. **系統很多、驗證很少**。過去一個月做了大量系統（Phase 2b～3、4a），幾乎都是模擬驗證；真人只玩過一部分。最大的風險不是哪個系統錯，而是「全部疊起來之後，玩起來是不是一直在做同樣的事」。
2. **中段的決策不夠重**。成年後食物不缺、威脅可以避開，玩家容易進入「照常過日子」的作業循環。設計支柱自己也寫了：不想變成作業、不想要數值堆疊。
3. **每次狩獵都走戰術場景，可能太花時間**。一次戰術狩獵 10～30 回合；一生要獵幾百次。有「交給本能」，但如果玩家大多交給本能，戰術層的樂趣就沒用到；如果都自己打，一生會很累。
4. **文字多、被略過**。一半的卡片秒關，代表敘事量可能超過玩家想讀的量，或是重複的卡片太多。
5. **範圍很大**。個人作品、沒有商業壓力是優點，但規劃中還有人類、出生背景、特殊招式、群戰、正式美術……容易一直加、一直沒有「收斂成一個好玩的版本」。

### 建議（給討論用，不是決定）

1. **先停止加新系統**，用最新版完整玩一次（或請朋友玩），只回答幾個問題：
   - 哪一段最想繼續玩？哪一段開始想快轉？
   - 有沒有「我判斷對了」的時刻？大約多久一次？
   - 中段（3～6 歲）每天在做什麼？會不會一直重複？
   - 死掉的時候，有沒有想再開一局？
2. **找出「一生的節奏」**：設計支柱有一項待確認——一局想玩多久、平穩期／變動期／適應期怎麼分配。這個決定會影響很多系統要不要留。
3. **讓戰術場景只出現在重要的時刻**（大型獵物、搶食、衝突），日常的小狩獵快速帶過；或讓玩家選擇。
4. **砍掉或合併沒有帶來決策的系統**：試玩後列出「有改變我做法的系統」和「只是多一張卡片的系統」。
5. 正式美術（HD-2D）等核心循環確定好玩之後再投入。

### 想請 ChatGPT 一起想的問題

- 這類「扮演一隻動物的一生」的遊戲（例如 Shelter、Wolfquest、Sang-Froid、The Long Dark 的生存節奏），什麼樣的節奏讓玩家願意玩完一生？
- 一生 7～8 小時是太長、剛好，還是應該做成更短、可以多玩幾局的形式？
- 戰術場景（狩獵、戰鬥）和「一生的流動感」怎麼平衡：多少比例的時間在戰術層比較好？
- 成年後的壓力要從哪裡來，才不會變成作業、也不會變成硬加難度？（目前的方向：鄰群、家庭、季節、人類）
- 哪些系統最可能是「為複雜而複雜」？
