# 《狼之一生》開發現況與玩法說明（2026-10-14）

給外部（ChatGPT 等）討論用的整理：遊戲是什麼、到 Phase 2 做了哪些東西、探索與狩獵實際怎麼玩、試玩的感受，以及之後的規劃。最後一節是想討論的問題。

---

## 一、遊戲是什麼

- **類型**：單機的生存養成遊戲，以文字敘事為主，搭配像素圖與簡單的動畫。引擎是 Godot 4。
- **設定**：玩家是一隻北美灰狼，時代背景是美國西部拓荒時期的偏遠地區。牠 8 個月大時和狼群走散，從此獨自生活，一直活到老死或意外死亡。
- **核心**：沒有勝負、沒有強迫的主線劇情，死亡就是結局，最後是一段「一生回顧」。目標是讓自然生態的很多要素互相影響，讓每一局都長出不同的故事。
- **時間尺度**：
  - 一天分 5 個時段：清晨、白天、黃昏、深夜、黎明前；每個時段 4 回合。
  - 一季 10 天，一年 4 季（40 天）。
  - 一生大約 10 年；目前一隻狼從頭玩到死，要好幾個小時。
- **能力值**：速度、力量、技巧、感知、血量上限。另有狀態：血量、體力、飽食度、健康值，以及傷勢、燒傷、凍傷、中毒。
- **生命階段**：
  - 次成年期：8 個月～2 歲，成長最快，分兩段；
  - 成年期：2～6 歲，巔峰；
  - 老年期：6 歲以上，衰退，但經驗最多。

## 三、目前的世界

### 地圖（4 張，各 4 區）

| 地圖 | 區域 | 特色 |
| --- | --- | --- |
| 森林（西） | 東部（溪流、林緣）、北部（密林、冬季鹿場）、南部（林緣、空地）、西部（老林、倒木、灰熊多） | 起始地圖；鹿多、地形多樣 |
| 苔原（北） | 林線、開闊苔原、河谷柳叢、遠北 | 馴鹿遷徙、暴風雪、冰面、苔原狼 |
| 山地（中） | 高山草甸、岩壁峽谷、山腳林地、溪流源頭 | 地形崎嶇、會摔傷；大角羊、美洲獅；夏季鹿上山、冬季下山 |
| 草原（南） | 丘陵草地、開闊草原、河岸林帶、大河 | 視野好、沒掩護；野牛群、叉角羚；渡大河 |

- 地圖之間要走好幾個回合；巢穴可以設在任何地圖。
- 開局可以選地圖，各有小加成。

### 動物

- **獵物**：
  - 森林：白尾鹿、野兔、雪兔、馬鹿、駝鹿；
  - 苔原：北美馴鹿；
  - 山地：騾鹿、大角羊、河狸；
  - 草原：美洲野牛、叉角羚。
  - 大多有幼體、雄性、群體的差異。
- **競爭者**：
  - 灰熊、黑熊、美洲獅、加拿大猞猁、郊狼、紅狐、狼獾、渡鴉；
  - 具名的狼：黑狼（宿敵）、一對苔原狼、老年時出現的年輕挑戰者。

### 會互相影響的系統（目前已有）

- **季節**：獵物分布、幼體、群大小、遷徙；灰熊冬眠；雪兔換毛。
- **天氣**：
  - 風向：影響氣味與潛近，每時段可能變；
  - 暴雨：沖掉足跡，雨停後的足跡最清楚；
  - 暴風雪、白矇天。
- **雪況**：淺雪、深雪、硬雪殼；對每種獵物的影響不同（深雪對白尾鹿不利，但對駝鹿有利）。
- **大火**：
  - 會燒過區域，有徵兆、可以躲避；
  - 燒過的地方長出新芽，引來鹿。
- **年況**：嚴冬年、暖冬年、乾夏、雪兔的豐荒週期。
- **過度狩獵**：同一區連續狩獵，獵物會變少，要好幾天才恢復。
- **競爭與搶食**：
  - 灰熊幾乎總能搶走你的殘骸，你可以咬一塊就跑；
  - 美洲獅藏起來的獵物可以偷；
  - 搶猞猁抓到的雪兔；
  - 渡鴉在殘骸上空盤旋。
- **具名角色的長期關係**：
  - 黑狼：會老、會死，可以挑戰、示弱，也可以搶地盤；
  - 苔原狼：關係會變化，可以一起狩獵、一起守巢，每年會繁殖。
- **知識系統**：同樣的發現累積 3 次，從「似乎」→「通常」→「確定」；確定之後會顯示發現機率，並提高成功率。

## 四、一天怎麼過（主畫面）

主畫面有：
- 區域背景、狀態列、四區小地圖；
- 行動按鈕：探索、換個方式探索、照常過日子、採集、找睡處、短暫休息、休息到…、睡覺、回到殘骸、做巢穴、標記地盤、躺下（老年）；
- 行動紀錄。

典型的一天：
1. 早上在巢穴或睡處醒來，看到換日摘要，例如「後腿的傷不再作痛」。
2. 選一個區域去探索，可能需要移動 1 回合以上。
3. 探索得到一個「發現」，從 2～3 個後續選項中選一個：追蹤、繼續探索、避開、記下。
4. 追蹤成功就遇到獵物，進入狩獵畫面。
5. 狩獵成功就分段進食；可能被灰熊、狐狸搶食。
6. 中間會有世界主動找上門的事件：灰熊路過、暴雨、獵物靠近、遠方狼嚎、黑狼現身、大火的徵兆。
7. 晚上找睡處或回巢睡覺，睡處好壞影響恢復。

## 五、探索、追蹤、狩獵的詳細流程

### 5-1 探索

**先選探索方式**（直接按「探索」等於沿獸徑走）：

| 方式 | 容易找到 | 代價 |
| --- | --- | --- |
| 沿獸徑走 | 獵物的足跡、獵物本身 | 一般 |
| 登高嗅風 | 遠處的動靜：渡鴉盤旋、殘骸、灰熊或其他狼的氣味、天氣與大火的徵兆 | 受風向影響很大 |
| 守在水邊 | 來喝水的獵物（清晨、黃昏多），可以伏擊 | 花 2 回合，體力很少 |
| 巡一圈邊界 | 其他狼的標記、熊的抓痕、地盤的狀況 | 比較累，容易撞見牠們 |

**每次探索產生一個「發現」**，由四個欄位組合而成：
- 地點特徵：溪流旁、密林、林緣、空地、岩坡等；
- 線索類型：氣味、足跡、聲音、痕跡、直接目擊；
- 來源：哪種動物或什麼東西；
- 新鮮度：新鮮的可以追，陳舊的只提供資訊。

出現的權重受這些條件影響：區域、時段、季節、雪況、年況、資源是否被過度狩獵、獵物遷徙，以及玩家的知識。

**發現的種類**：
- 獵物線索佔六到七成；
- 其餘是：
  - 環境（雪況、天氣徵兆、燒過的地面）；
  - 獵物的狀況（跛腳的母鹿、落單的小馴鹿、鹿群、躲在草裡的幼鹿）；
  - 別人的獵物（狐狸、狼獾、灰熊正在吃的殘骸、吃剩的骨頭）；
  - 其他狼的標記；
  - 具名地點。
- 「什麼都沒發現」不超過 15%，而且也會附帶一點資訊。

**後續選項**：
- 追蹤：做一次感知判定，受風向影響，成功就遇到那隻動物；
- 繼續探索：在同一區換一個發現；
- 避開：例如遇到灰熊的痕跡時；
- 記下：把陳舊的線索寫進知識。

**區域會累積**：
- 具名地點：每區有 2～4 個，例如水潭、冬季鹿場、獸徑匯集處、瞭望點、灰熊常翻找的坡地。發現之後可以直接「去那裡」。
- 會延續的對象：探索時看到的特別個體，例如跛腳的母鹿、被咬傷的駝鹿，會在這一帶留幾天，之後有機會再碰到（「又是那頭跛腳的母鹿」）。

**省時的機制**：
- 「探索到有值得注意的發現為止」：平淡的結果一次帶過，最多花半天。
- 「照常過日子」：選 1～3 天和一種方式（獵小獵物、找大型獵物、養傷），由程式代為行動。遇到任何值得注意的事就停下、交還給玩家。次成年期不能用。

**未知與學習**：
- 灰熊、陌生的狼這類線索，一開始看不懂，例如「樹上一組巨大的爪痕」；
- 實際遇過之後才認得，文字改成已辨識的版本；
- 第一次遇到灰熊一定是遠距離目擊，避免玩家還沒學會就被殺。

### 5-2 追蹤與風向

- 每個時段有一個風向，換算成三種相對狀態：
  - 逆風（風從獵物吹向你）：氣味線索多，潛近不容易被發現；
  - 側風：一般；
  - 順風：氣味線索少，潛近容易被發現，要花 1～2 回合繞到下風處。
- 狩獵途中風向也可能轉變，成為失敗的原因之一。
- 暴雨中氣味大幅減少，追蹤容易跟丟；雨停後的一個時段，泥地上的足跡特別清楚。

### 5-3 狩獵

**深度依獵物的危險程度分級**（避免每次都點一樣多的按鈕）：

| 等級 | 對象 | 流程 |
| --- | --- | --- |
| 簡易 | 野兔、雪兔、幼體、受傷個體 | 一次撲抓 |
| 標準 | 狐狸、白尾鹿母鹿等 | 潛近 → 追擊 |
| 完整 | 健康的成年雄鹿、馬鹿、駝鹿、野牛等 | 觀察 → 潛近 → 追擊 → 搏鬥 |

**各階段的選項**：

| 階段 | 選項 |
| --- | --- |
| 觀察 | 觀察：看出獵物的狀態與體況，預判牠會逃、站定還是反擊（看感知）；也可能被察覺 |
| 試探 | 追一小段就停，看誰落後、跛腳；花的體力少，發現沒機會就放棄（大型獵物、群體） |
| 潛近 | 正面接近（快，但容易被發現）、繞到下風處（看技巧）、伏低等待（幾乎不耗體力，但獵物可能走掉） |
| 追擊 | 全力衝刺（比爆發）、保持跟隨（用你的耐力磨獵物的耐力）、切側翼（看技巧）、地形專屬選項（例如驅趕向密林、逼向溪流、從林中突襲） |
| 搏鬥 | 咬後腿（安全但慢）、直取咽喉（成功率低，失敗容易被反擊；獵物累了時會提高）、閃避等待破綻 |

**影響成功率的因素**：
- 能力值：速度、力量、技巧、感知；
- 風向、地形、雪況、時段；
- 獵物的體況（健康、普通、虛弱）與警覺；
- 群體：很多雙眼睛，潛近較難，但能挑出弱者；
- 避難處：大角羊靠近岩壁、河狸在水邊時，幾乎抓不到；
- 你的傷勢、喘的程度、知識。

**兩層體力**：
- 喘（爆發）：只在狩獵和戰鬥中出現；短衝、撲抓扣很多，跟隨、潛近扣很少；狩獵結束就回滿，中途也可以停下喘口氣。
- 體力（耐力）：一整天的活動量；一場狩獵結束時依長短扣一次。
- 目標是一天大約能狩獵 2～4 次。

**獵物的反應**：
- 逃跑、站定（健康的雄鹿、背靠障礙物）、反擊（受傷被逼近、護幼）、躲藏（野兔、幼體）、護幼（母鹿介入）。
- 例如：健康的白尾鹿一被追就翹起白尾巴逃，等於告訴你「追了也是白追」。
- 例如：壯年駝鹿多半站定反擊，非常危險；老弱的才會逃。

**介面的呈現**：
- 每個選項旁邊列出成功率（精確數字）與 2～3 個關鍵因素，例如「逆風 ✓　林緣 ✓　鹿很警覺 ✗」；
- 失敗時寫出主因，例如「風向轉了，鹿聞到你」；
- 次成年期的成功率用模糊的說法，長大後才變成數字。

**失敗也有結果**：獵物往某個方向逃（可以再追）、受傷，或你得到一些牠的資訊。

**分次狩獵**：咬傷但沒殺死的大型獵物，會帶傷留在這一帶幾天，之後再遇到時更好抓。

**進食與之後**：
- 大型獵物分段吃（白尾鹿 3 段），待得越久，被搶食的機率越高；
- 吃不完可以離開，殘骸最多留 2 天；
- 灰熊來搶時可以守住（很危險）、叼走一塊、或放棄；認得灰熊之後，還有「咬一塊就跑」「整個叼走」。

### 5-4 一個典型的狩獵過程（冬季，森林北部）

1. 選「沿獸徑走」探索，發現：「雪地上有一行新鮮的鹿蹄印，往雲杉林去。」
2. 選「追蹤」：側風，感知判定成功。
3. 遇到一小群白尾鹿（3 頭），進入狩獵。因為是成群的鹿，先觀察：其中一頭母鹿腳步拖沓，體況虛弱。
4. 潛近時選「繞到下風處」，花 1 回合，看技巧，成功。
5. 追擊時選「全力衝刺」；深雪讓鹿陷得比你深，對你有利。鹿群散開，你追上那頭虛弱的母鹿。
6. 一次撲倒，分 3 段吃。第 2 段時，渡鴉開始盤旋……
7. 睡前的換日摘要：「這幾天吃得很飽，追擊又多，你的腿更有力了。」

## 六、試玩的感受（使用者回饋，2026-10-14）

- 到 Phase 2 這一版，作業感比之前低，因為多了很多新的探索要素，感覺像在玩新遊戲或大改版。
- 但預估玩 2～3 小時、把新要素都看過之後，作業感可能又會回來。
- 理想是：有很多自然生態要素互相影響，即使沒有強迫的主線，每次玩起來也不一樣。逐版加功能的方向應該是對的。
- 難點：探索、追蹤、狩獵這個每天都在重複的核心循環，作業感很難改善。

### Claude Code 的初步分析

作業感多半不是因為內容不夠，而是做決定的結構每次都一樣：

1. **最佳選擇常常一眼就看出來**：選項有精確成功率，玩家自然選最高的。試玩紀錄有記「選最高成功率的比例」，可以用來驗證。
2. **單次狩獵的結果不太影響之後的世界**：雖然已經有過度狩獵、延續的對象、分次狩獵，但份量還不夠，多數狩獵仍是獨立的一場。
3. **資訊太完整**：牠在哪、狀態如何、機率多少都直接告訴你，少了「讀懂自然」的過程。
4. **重要和不重要的狩獵，花的心力差不多**。

## 七、後續規劃

### Phase 3：成年期與社會（規格草稿，待確認）

主線改成依生態的「家庭」：
> 找到伴侶 → 建立領域 → 養大一窩幼狼 → 帶著家族狩獵、守住領域 → 看孩子一個個離開。

- 配對：成年後秋冬最容易遇到離群的母狼；嚎叫、標記可以提高機會，但也會引來鄰群。玩家暫時只有公狼。
- 狼群面板：可以逐隻指派任務，也可以存成隊伍；狼群上限 10 隻。
- 群獵的布陣：
  - 5 種角色：驅趕、埋伏、側翼、接力、衝散；
  - 3 種隊形：包抄、接力追擊、衝散鹿群；
  - 數量的效果會遞減：獵馬鹿約 4 隻就封頂，獵野牛要 9～13 隻。
- 領域與鄰群：
  - 每張地圖有 1～2 個 AI 狼群；邊界獵物多，但也最危險（研究中，自然死亡約三分之二是被其他狼殺死）；
  - 黑狼是劇情角色，在玩家 3 歲後可能在森林成立自己的狼群。
- 育幼：冬末交配、春季產仔；要把食物帶回巢，還要守巢防熊和美洲獅；幼狼第一年的存活約一半。
- 成員：能力從父母繼承，各有個性；1～3 歲之間會離群。
- 加入既有狼群：補上失去的繁殖者（取代「挑戰頭狼」的設計）。
- 狼群中的老年：交棒給子女；在狼群衝突中，6 歲以上的老狼反而是優勢。

### Phase 4：人類

牧場、獵人、陷阱與毒餌、獵犬；狼的足跡與標記會被人類循線找到。

### Phase 5：正式化

- HD-2D 美術：3D 場景加上 2D 像素角色，有景深、霧、光束、即時光影，參考《歧路旅人》。目標畫面是黃昏斜角的林中場景。
- 介面改成疊在場景上的面板；狩獵和戰鬥直接在場景裡演出。

### 改善探索與狩獵的候選方向（尚未決定，供討論）

| 方向 | 內容 | 現況 |
| --- | --- | --- |
| 有身分的獵物個體 | 跛腳的老母鹿、追丟兩次的大公鹿；受傷逃走的會留在附近、傷勢惡化；牠也會記得你、變得更警覺 | 雛形已有（延續的對象、分次狩獵），份量還小 |
| 追蹤變成讀線索 | 足跡有新舊與方向；血跡、斷枝、啃過的樹皮透露狀態；線索連成跨區域的路；少給數字、多給描述 | 目前追蹤是一次判定 |
| 獵物會學習、會移動 | 同一區被獵太多次，鹿群變警覺、搬走，逼你換地方 | 有過度狩獵讓獵物變少，沒有行為上的學習 |
| 狩獵中途的變數 | 獵物衝進河裡、跑上硬雪殼；渡鴉的叫聲引來灰熊；另一隻鹿竄出 | 有風向轉變，其他很少 |
| 瑣碎的狩獵自動化 | 小獵物併進「照常過日子」，把注意力留給重要的狩獵 | 部分已有 |
| 加一點操作性 | 潛近時看風向、一步步靠近；追擊時分配體力的節奏 | 沒有；和文字節奏不一定搭 |

## 八、想討論的問題

1. 在「沒有主線、靠生態系統互相影響」的遊戲裡，每天重複的核心循環（探索 → 追蹤 → 狩獵 → 進食），有哪些設計手法可以長期維持新鮮感？有沒有值得參考的遊戲？
2. 成功率要精確顯示，還是改成模糊的描述？兩者在可讀性和「讀懂自然」的樂趣之間怎麼取捨？
3. 追蹤怎麼從一次判定，變成有趣的「讀線索」過程，又不會變成另一種重複？
4. 上面六個候選方向，哪幾個最值得先做？還有什麼沒想到的方向？
5. Phase 3 的狼群與群獵，怎麼設計才能讓狩獵真正變得更有策略，而不是多一層操作？
