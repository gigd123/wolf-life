## 遊戲概述

玩家扮演一隻北美灰狼，從 8 個月大活到老死或意外死亡；死亡即為結局，沒有勝負，只有這一生怎麼過。

| 項目 | 內容 |
| --- | --- |
| 平台 | Steam（Windows 為主，之後可考慮 Mac / Linux） |
| 類型 | 單機、生存養成、策略回合制，無連線功能 |
| 開發引擎 | Godot 4（GDScript；可用 GodotSteam 串接 Steam 功能） |
| 語言 | 繁體中文為主，架構預留多國語系 |
| 存檔 | 單一存檔槽 |
| Phase 1 視覺 | 2D 介面＋可點擊的區域地圖，素材由 Claude 以程式生成 |
| 正式版視覺目標 | 3D 場景＋2D 像素角色，加上景深、光暈、霧氣、動態光影等後製（類似《歧路旅人》的風格） |

核心體驗有三點：每一次決策都有意義、季節與環境帶來變化、狼的一生會因選擇而完全不同。

宣傳時避免使用「HD-2D」（Square Enix 商標）一詞；名稱也要避免與既有作品《WolfQuest》相似。

## 開發原則與架構

以下原則適用所有階段，Phase 1 就要遵守。

### 邏輯與畫面分離

- 遊戲規則（時間、素質、遭遇、狩獵判定、存檔）寫在不依賴畫面節點的邏輯層，畫面層只負責顯示與輸入。
- 目的：Phase 1 是 2D 介面，正式版要換成 3D 場景＋像素角色；屆時只替換畫面層，規則、數值、存檔不需重寫。

### 資料驅動

- 所有數值（素質、獵物、遭遇機率、恢復量、飽食度下降等）集中在資料檔（JSON 或 Godot Resource），不寫死在程式裡。
- 動物共用同一套框架，每種動物只是不同的資料。
- 區域、季節、時段的修正值也放在資料檔。

### 多國語系

- 介面與事件文字一律使用翻譯鍵，透過 Godot 的 TranslationServer 與 CSV 翻譯表載入。
- Phase 1 只需提供繁體中文（`zh_TW`），但不可在程式碼中直接寫中文字串。

### 存檔

- 單一存檔槽，JSON 格式存於 `user://`。
- 存檔內容：狼的全部狀態、時間、巢穴位置、狀態效果、一生紀錄、隨機種子。
- 在每天開始與睡覺後自動存檔。

### 測試與除錯

- 隨機數使用可指定種子的產生器，方便重現問題。
- 提供「時間倍率」設定（見「時間系統」），讓完整一生能在合理時間內測完。
- 除錯選單：直接調整素質、跳季節、跳年齡、強制觸發遭遇。

## Phase 1 規格

### 範圍

| 項目 | 內容 |
| --- | --- |
| 地圖 | 森林一張，分為北、東、南、西四個區域 |
| 動物 | 灰熊（競爭動物）、白尾鹿、野兔、狐狸（獵物），皆含幼體與成體 |
| 採集物 | 漿果、藍莓、蘑菇、蜂巢 |
| 季節 | 完整四季 |
| 巢穴 | 一個，開局時在四個區域中自選 |
| 生命週期 | 從次成年期一路到老年期與死亡 |
| 社會系統 | 不實作；成年期只有素質變化，這點已確認可接受 |
| 介面 | 可點擊的區域地圖、狀態列、行動選單、狩獵回合畫面 |
| 附帶任務 | 3D 視覺測試場景（見下方） |

試玩重點：「選巢 → 出門 → 找食物 → 狩獵或採集 → 受傷／恢復 → 繼續生存」的循環是否好玩，四季與四個區域是否產生不同的策略。

### 森林的方位與四個區域

世界地圖中，森林位於西側，山地在森林東方（世界中央），苔原在北，草原在南。

| 區域 | 相鄰 | 地形與特色 | 主要內容 |
| --- | --- | --- | --- |
| 森林東部 | 山地 | 地形略有起伏；溪流從山區流入 | 白尾鹿；之後是通往山地的出口 |
| 森林北部 | 苔原 | 針葉林密、較冷，體力消耗稍高；溪流從東部流經此區 | 冬季白尾鹿聚集避寒（鹿冬營地），冬季狩獵重點 |
| 森林南部 | 草原 | 林緣較開闊 | 野兔、狐狸多；之後牧場位於此區外側 |
| 森林西部 | 地圖外緣 | 最深的老林 | 漿果、藍莓、蘑菇、蜂巢集中；灰熊出沒機率最高 |

- 區域之間移動一律 1 回合。
- 溪流路徑：山地 → 森林東部 → 森林北部。
- 各區巢穴可有不同優缺點，例如西部靠近食物但灰熊多、北部冬季方便獵鹿但較冷（數值待定）。

### 動物與採集物分布（初始值）

以下為相對機率，實際數值放在資料檔。

| 項目 | 東部 | 北部 | 南部 | 西部 | 季節備註 |
| --- | --- | --- | --- | --- | --- |
| 白尾鹿 | 中 | 中（冬季高） | 低 | 低 | 春季有幼鹿、母鹿護幼；秋季發情期雄鹿具攻擊性 |
| 野兔 | 低 | 低 | 高 | 中 | 全年 |
| 狐狸 | 低 | 低 | 高 | 低 | 全年；Phase 1 只當獵物，不搶食 |
| 灰熊 | 低 | 低 | 低 | 高 | 冬季冬眠不出現；春季可能出現母熊帶幼熊 |
| 漿果、藍莓 | 低 | 無 | 低 | 高 | 夏、秋 |
| 蘑菇 | 低 | 低 | 無 | 高 | 秋 |
| 蜂巢 | 無 | 無 | 低 | 高 | 夏 |

### 採集物效果

| 採集物 | 效果（初始值） | 風險 |
| --- | --- | --- |
| 漿果、藍莓 | 小幅補充飽食度、體力、血量 | 無 |
| 蘑菇 | 補充飽食度、體力、血量 | 有機率中毒 |
| 蜂巢 | 補充飽食度與較多體力 | 有機率被蜜蜂螫傷，扣少量血量 |

中毒是持續數天的狀態效果：期間體力恢復減半，每天小幅降低健康值，數天後自然痊癒。

### 灰熊行為

| 情況 | 行為 | 玩家選項 |
| --- | --- | --- |
| 狩獵成功後 | 灰熊前來搶奪獵物 | 戰鬥、撤退、放棄獵物 |
| 一般遭遇 | 灰熊示威 | 戰鬥、撤退 |
| 狼為次成年期或老年期 | 灰熊有機率不示威、直接攻擊 | 戰鬥、逃跑 |
| 母熊帶幼熊 | 攻擊性與直接攻擊機率提高 | 同上 |

- 單狼與成年灰熊戰鬥應極度不利，迎戰是高風險選擇。
- 冬季灰熊冬眠，西部因此變安全，但也沒有採集物。

### 時間倍率

| 模式 | 一季天數 | 用途 |
| --- | --- | --- |
| 正常 | 10 天 | 正式遊玩 |
| 測試 | 3 天（可調） | 快速測完整一生 |

年齡、季節、成長曲線都依「季」計算，因此切換倍率不影響生命階段的對應。

### 其他已確認規則

- 野外睡覺：隔天在原地開始新的一天，但恢復量比在巢穴睡覺少。
- 生命階段年齡：照「生命週期」一節的初始值。
- 飽食度歸零的懲罰：由開發端先訂初始值，之後依試玩調整。

### Phase 1 美術、音效、音樂

全部由 Claude 以程式生成的佔位素材製作，之後直接替換檔案，不需修改程式。

- 基準解析度 640×360，以整數倍放大（1920×1080 為 3 倍），保持像素清晰。
- 動物像素圖尺寸參考：小型動物 16～24 px、狼與鹿 32～48 px、灰熊 48～64 px。
- 動物動作：待機、移動、攻擊、倒下，每個 2～4 格；含幼體與成體。
- 區域地圖：森林四區可點擊，含溪流、採集物叢、巢穴標記，依季節換色（冬季覆雪）。
- 介面：狀態列、行動選單、圖示（中毒、受傷、飢餓等）、時段與季節顯示。
- 音效與音樂：程式合成的腳步、撲咬、熊吼等音效，以及簡單的氛圍音樂。
- 素材命名與尺寸規格在 Phase 1 定案，寫入 `assets/` 下的說明檔。

### 3D 視覺測試場景

- 位置：`prototypes/visual_test/`，與遊戲邏輯完全獨立。
- 內容：森林西部的 3D 小場景（基本幾何形狀＋程式生成的像素材質），放一隻狼的像素貼圖（Sprite3D，面向攝影機），固定攝影機角度。
- 效果：WorldEnvironment 的景深、光暈、霧氣，加上動態光源。
- 目的：確認正式版風格在 Godot 4 的可行性與大致觀感，不追求美術品質。

## 生命週期

一生分為三個階段，每個階段解鎖不同的選擇；年齡界線為初始值，之後依試玩調整。

| 階段 | 年齡（初始值） | 可做的事 | 素質傾向 |
| --- | --- | --- | --- |
| 次成年期 | 8 個月～約 2 歲 | 意外脫離狼群、選擇巢穴、每日狩獵、遷移巢穴 | 成長最快，經驗值加成高 |
| 成年期 | 約 2～6 歲 | 狩獵、遷移，以及三選一：與母狼配對組建狼群、挑戰其他狼群頭狼、繼續獨居 | 約 3～5 歲達巔峰 |
| 老年期 | 約 6 歲以上 | 獨居則持續狩獵；在狼群中可能被挑戰，可選擇應戰或放棄並退出狼群 | 速度、體力下滑，技巧仍可維持最高 |

Phase 1 的成年期不含社會選項。

**壽命**：北美灰狼平均 3～8 年。遊戲內不設固定壽命，由健康值、年齡、傷勢、飲食與長期飢餓共同決定老化速度與死亡風險，健康越好活越久。

**結局**：狼死亡即結束，可能原因包括老死、餓死、狩獵或打鬥致死、挑戰失敗被咬死、被人類獵殺、獵犬攻擊、傷病或嚴重傷勢。結束時顯示一生回顧，詳見「一生回顧」。

## 時間系統

一年 4 季、一季 10 天（測試模式可縮短）、一天 5 個時段、一個時段 4 回合；最後一天結束即進入下一季。

換算：一季 200 回合、一年 800 回合。為避免重複感，行動依內容消耗不同回合數，讓每個時段通常只有一兩個真正的決策。

### 行動回合消耗（初始值）

| 行動 | 消耗 |
| --- | --- |
| 尋找獵物蹤跡 | 1 回合，可能找到或找不到 |
| 找尋適合睡覺的地方 | 1 回合，可能找到或找不到 |
| 短暫休息 | 2 回合，小幅回復體力 |
| 睡覺 | 3 回合，大幅回復血量與體力 |
| 同一張大地圖內區域間移動 | 1 回合 |
| 跨大地圖移動 | 1～4 回合，依地圖組合（見「移動回合」），消耗體力（Phase 2） |
| 跨大地圖並指定區域 | 跨地圖回合數 + 1（Phase 2） |
| 遷移巢穴 | 1 個時段以上，視距離（Phase 2） |
| 狩獵 | 1～3 回合，視獵物規模 |
| 採集（漿果、藍莓、蘑菇、蜂巢） | 1 回合 |

另提供快轉功能，例如「休息到黃昏」一鍵完成。

### 時段特性

| 時段 | 特性 |
| --- | --- |
| 清晨 | 鹿類最活躍，狩獵加成高 |
| 白天 | 人類與牧場守衛最活躍，視野最好，獵物警覺高 |
| 黃昏 | 鹿類活躍，狩獵加成高 |
| 深夜 | 視線差、獵物警覺低；部分競爭動物出沒 |
| 凌晨 | 最寒冷，體力消耗較高；適合休息 |

### 季節特性

| 季節 | 特性 |
| --- | --- |
| 春 | 幼獸出生，容易獵捕但母獸護幼；繁殖季，狼群產下幼狼；灰熊結束冬眠 |
| 夏 | 食物最充足，漿果、藍莓、蜂巢出現；熊類活躍 |
| 秋 | 蘑菇出現；鹿類進入發情期，雄性具攻擊性；部分獵物開始遷徙 |
| 冬 | 獵物虛弱但數量少，飢餓壓力最大；灰熊冬眠；白尾鹿聚集到森林北部避寒；野牛、馬鹿季節性遷徙，是遷移巢穴的主要理由 |

## 狼的素質

狼有五項能力值與三項狀態值；能力值決定狩獵與打鬥表現，狀態值驅動每日生存壓力與壽命。

### 能力值

| 素質 | 作用 |
| --- | --- |
| 血量 | 短期生命值；打鬥中能承受多少傷害，受傷下降，休息與睡眠回復 |
| 體力 | 行動資源；影響狩獵效率與地圖移動，耗盡時無法追擊或遷移 |
| 速度 | 影響追擊與逃跑成功率 |
| 力量 | 影響撲倒、壓制與打鬥傷害，對大型獵物特別重要 |
| 技巧 | 影響潛近、找弱點、閃避反擊的成功率 |

### 狀態值

| 狀態 | 作用 |
| --- | --- |
| 飽食度 | 每個時段下降，是「今天必須出門狩獵」的核心壓力；過低開始扣血量與健康值 |
| 健康值 | 長期值，決定老化速度、壽命與患病風險；與血量分開計算 |
| 年齡 | 決定生命階段與能力成長曲線 |

**健康值的影響因素**：飲食品質（大型獵物營養高、獵物種類多樣、偶爾補充漿果）會提升；長期飢餓、未痊癒的舊傷、中毒、年齡增長會降低。

### 狀態效果

| 效果 | 來源 | 影響 |
| --- | --- | --- |
| 輕傷 | 狩獵、打鬥、蜜蜂螫傷 | 扣血量，休息可回復 |
| 重傷 | 狩獵、打鬥 | 暫時降低速度或力量，需數天休養；未痊癒持續降低健康值 |
| 中毒 | 蘑菇 | 數天內體力恢復減半、健康值每日小降，自然痊癒 |
| 飢餓 | 飽食度過低 | 見「初始數值建議」 |

### 成長曲線

- 次成年期：成長最快，成功狩獵與打鬥都會累積經驗。
- 成年期：約 3～5 歲達巔峰。
- 老年期：速度與體力逐漸下滑，力量緩降，技巧可維持最高，靠經驗而非蠻力。

## 每日流程與區域系統

每天從巢穴所在的大地圖開始（或前一晚野外睡覺的地點），移動分兩層決策：「去哪張地圖」與「去哪個區域」。遊戲開局時，次成年的狼因意外脫離狼群，先選擇巢穴位置（Phase 1 為森林四區之一）。

1. 新的一天從巢穴或前一晚睡覺的地點開始。
2. 在區域地圖上點選要前往的區域（1 回合）；Phase 2 起可跨大地圖移動。
3. 在區域內選擇固定行動，期間可能觸發隨機遭遇。
4. 遭遇獵物可進入狩獵回合制；遭遇競爭動物或人類則選擇戰鬥、撤退或逃跑。
5. 時段與天數依消耗推進；一季最後一天結束進入下一季。

### 區域內固定行動

- 尋找獵物蹤跡：可能找到蹤跡，也可能一無所獲。
- 採集：該區域與季節有採集物時可選。
- 移動：前往同一張地圖的其他區域（Phase 2 起可前往其他大地圖）。
- 找尋適合睡覺的地方：可能找到或找不到，不是任何地方都能好好睡。
- 短暫休息：小幅回復體力。
- 睡覺：大幅回復血量與體力；野外睡覺恢復量較巢穴少。

### 隨機遭遇

| 類型 | 事件 | 玩家選擇 |
| --- | --- | --- |
| 獵物 | 遭遇獵物 | 是否狩獵；狩獵即進入狩獵回合制 |
| 競爭動物 | 遭遇競爭動物（示威） | 戰鬥、撤退 |
| 競爭動物 | 競爭動物搶奪獵物 | 戰鬥、撤退、放棄獵物 |
| 競爭動物 | 競爭動物直接攻擊 | 戰鬥、逃跑 |
| 人類 | 發現獵人／獵犬蹤跡（警告） | 離開該區域或避開危險 |
| 人類 | 遭遇獵人 | 高危險事件，選項待定 |
| 人類 | 遭遇獵犬 | 戰鬥或逃跑 |
| 人類 | 遭遇獵犬＋獵人 | 最高危險的遭遇之一，選項待定 |

成年後大地圖額外出現社會相關選項，例如尋找配偶、挑戰其他狼群、帶領狼群出獵（Phase 3）。

## 狩獵回合制

狩獵採策略判定加畫面演出：分四個階段，每回合選一個行動，結果由雙方素質、地形、時段與隨機性共同判定。

| 階段 | 目標 | 可選行動（提案） | 主要相關素質 |
| --- | --- | --- | --- |
| 1. 發現 | 確認獵物位置與狀態 | 觀察（得知獵物體力、是否受傷、是否有護幼成體）、選定目標 | 技巧 |
| 2. 潛近 | 在被發現前縮短距離 | 伏低前進、繞到下風處、等待時機 | 技巧、體力 |
| 3. 追擊 | 追上並逼近獵物 | 衝刺、繞到側面、驅趕到不利地形 | 速度、體力 |
| 4. 搏鬥 | 制伏獵物 | 撲咬後腿、咬喉、壓制、閃避反擊 | 力量、技巧、血量 |

- 每個階段都可以選擇放棄；獵物被驚動會逃跑，大型獵物與野豬會反擊。
- 獵物也有自己的數值：警覺、體力、速度、反擊力；每回合追擊都會消耗雙方體力。
- 小型獵物（野兔、狐狸）的流程可以縮短，例如略過潛近或搏鬥只需一回合。
- 群獵時可指派隊友從不同方向包抄、輪流追擊消耗獵物體力（Phase 3）。
- 狩獵成功不等於安全：可能引來競爭動物搶食，需要選擇守住或放棄獵物逃跑。Phase 1 只有灰熊會搶食。

## 社會系統（Phase 3）

成年後可選擇組建家庭、奪取狼群或繼續獨居；老年期則面臨被年輕狼挑戰。

### 組建家庭

- 與獨居母狼配對，成立自己的狼群。
- 春季產下幼狼，幼狼成長後成為狼群成員，繼承父母部分素質。
- 狼群成員有各自的素質與個性，可一起群獵，大型獵物因此成為可行目標。

### 挑戰頭狼

- 挑戰其他狼群的頭狼，勝利即成為該狼群領袖。
- 挑戰使用類似搏鬥階段的回合制，可能受傷，失敗可能被趕走或咬死。

### 老年被挑戰

- 在狼群中的老狼可能被年輕狼挑戰，可選擇應戰或直接放棄並退出狼群。
- 應戰失敗：可能被咬死（遊戲結束）或被逐出狼群轉為獨居。
- 獨居的老狼不會被挑戰，持續每日狩獵。

## 受傷、死亡與人類獵捕

### 受傷

- 輕傷：扣血量，休息可回復。
- 重傷：暫時降低速度或力量等能力值，需要數天休養；未痊癒會持續降低健康值。
- 血量歸零即死亡。

### 人類獵捕（Phase 4）

- 在牧場狩獵後，觸發機率提升（數值待定）；連續在牧場狩獵，機率累積。
- 觸發後人類帶槍與獵犬在接下來數天搜索附近地圖。
- 應對方式（提案）：躲回巢穴、遷移到遠處地圖、避開白天行動；與獵犬遭遇時逃跑，必要時戰鬥。
- 被槍擊可能直接死亡或重傷。

## 一生回顧

死亡後顯示這隻狼的一生故事，而不是單純的 Game Over。Phase 1 先記錄資料並以簡單文字畫面顯示，正式呈現方式於 Phase 4 決定。

- 活了多久、曾經生活過哪些地圖與區域、遷移次數
- 獵物紀錄與最大獵物
- 配偶、後代數量、狼群成員
- 是否當過頭狼、維持多久
- 受過哪些重大傷勢
- 死亡原因
