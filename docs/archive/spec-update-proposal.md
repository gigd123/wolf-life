## B. 建議（實作時「先這樣做」的做法，寫進 SPEC 才算定案）

完整清單在 `progress.md`「已採用的做法」，這裡只挑和 SPEC 文字直接衝突的四項：

- **B1. 成年期的成長倍率**：SPEC「生命階段倍率」寫成年 ×1，實作是 ×0.7（×1 時 3 歲前就到上限的 95%，×0.7 約 4 歲，符合「約 3～5 歲到達巔峰」）。建議把表格的「×1」改成「約 ×0.7」。
- **B2. 狩獵的搏鬥沒有改成對峙 → 交鋒**：SPEC 寫狩獵的搏鬥也套用戰鬥規則；實作保留咬後腿、直取咽喉、閃避等待，只把受傷部位、重傷、瀕危、戰死改用同一套規則。理由是獵物的目標是逃走，不是「放棄」。建議在「戰鬥模式」寫明。
- **B3. 外貌用佔位圖**：SPEC「外貌」與美術表寫「正式素材之前先用程式處理（放大、調灰）」，實際已有成年、老年的佔位圖。建議改成「有佔位圖就用，沒有才用程式處理」。
- **B4. 苔原的事件與 1.6 驗收**：1.6 的驗收只提到灰熊、陌生灰狼與大火。建議在試玩指南加一句：「苔原：住過一個冬天，至少遇到一次暴風雪或苔原狼」。這一項是新增的驗收項目，請決定要不要加。
