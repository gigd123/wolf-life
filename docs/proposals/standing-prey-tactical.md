# 提案：會站定的大型獵物接進戰術地圖（公馬鹿、駝鹿、野牛）

2026-10-20 Claude Code 起草，使用者還沒選。接在 Phase 2d（馬鹿、騾鹿、馴鹿）之後；Phase 2d 的問題 4 決定「公馬鹿先維持選單式，等駝鹿、野牛的站定規則一起做」。

## 現況

- 選單式狩獵已經有「站定」（`HuntSystem` 的 reaction `stand`）：公馬鹿健康的五成、駝鹿約五成會站定；站定時只能「冒險攻擊」（被反擊的機率 × 1.5）或放棄。
- 戰術地圖已經有「角度」（撲咬從後方 +0.2、側面 +0.1、正面 0）、被踢、咬住後的招式（壓倒、咬喉、咬後腿、死咬拖住）、鹿群、母鹿護幼。
- 戰術地圖裡的鹿只有「沒察覺／起疑／逃跑」三種狀態，站定（`stand`）只在被逼到角落時出現。

## 生態依據（`ecology-reference.md`「駝鹿」「Phase 2 的新地圖與動物」）

- 駝鹿：Isle Royale 站定的 36 頭全部活下來（狼都放棄），逃跑的 41 頭被殺 5 頭；**讓牠跑才有機會**。強壯的多半站住，老、衰弱的比較容易逃。沒及早發現狼時乾脆站著對抗。逃跑中也會突然回頭衝撞。四個方向都能踢，後腳能踢斷肋骨。狼先咬臀部、後腿。
- 公馬鹿：用角和前蹄；繁殖期後的冬末體力耗盡，比較好抓。
- 野牛：單狼獵成年野牛幾乎不可能（黃石要 9～13 隻狼）；單狼的機會是落單的小牛、老弱、陷在深雪裡的；母牛、公牛會擋在小牛前面，小牛會逃進水裡。

## 要使用者決定的問題

### 1. 站定在戰術地圖上怎麼玩

- **A. 對峙＋逼牠跑**：站定的獵物停下來、一直轉身面向你；你可以「繞」（找側面、後方的角度）、「佯攻」（逼近又退開，可能讓牠轉身跑、也可能讓牠衝過來）、或放棄。站定的健康獵物正面撲幾乎一定被踢；讓牠跑起來，就回到現在的追逐。
  - 感受：最像真的狼「測試」駝鹿，對峙很緊張，決策是「要不要、怎麼逼牠跑」。
  - 代價：新增一個動作（佯攻）和一個狀態（站定時轉身、太近時衝撞）；畫面要多一個按鈕。
- **B. 只用現有的角度規則（建議）**：站定的獵物停下來、每回合轉身面向你；你繞到側面、後方再撲（現有的角度加減），從正面撲被踢的機率很高。站定幾回合後（或你逼近、離開）牠可能改成逃跑。
  - 感受：位置的解謎（繞到牠身後），規則和現在一樣，不用學新東西。
  - 代價：小；但少了「主動逼牠跑」的手段，健康站定的獵物多半就是放棄。
- **C. 站定時回到選單**：只有牠逃跑時用戰術地圖，站定時跳回現在的選單（冒險攻擊或放棄）。
  - 感受：前後兩套操作，不連貫。
  - 代價：最小。

### 2. 先做哪幾種

- **A. 駝鹿＋公馬鹿（建議）**：兩種都是「站定 vs 逃跑」的典型，駝鹿生態資料最多；野牛留到 Phase 3 群獵（單狼幾乎獵不到成年野牛）。
- **B. 三種一起做**：野牛只做小牛與落單的老弱（母牛、公牛會擋在小牛前面）。
- **C. 只做駝鹿**：先試站定規則好不好玩，再決定其他兩種。

### 3. 健康的站定獵物要多難

- **A. 照生態：幾乎打不下來（建議）**：健康的站定駝鹿單狼成功率個位數；靠「找會跑的那一頭」（老弱的比較常逃）和放棄。
- **B. 遊戲性：難但有機會**：健康站定約一兩成，強狼、經驗多的狼更高。

## 通過標準（初始值，模擬驗收）

- 成功率對齊選單式 `hunt_levels`（駝鹿、公馬鹿；健康、虛弱分開）±5%。
- 健康的站定獵物：最好的打法多半是放棄或等牠跑；虛弱的、老的比較常逃。
- 被踢的傷比白尾鹿、母馬鹿重（駝鹿傷害 × 1.8 照選單式）。
- 一生模擬的挨餓、壽命符合一生壓力目標。

## Claude Code 的假設

- 駝鹿、公馬鹿用現有的地圖族（密林、林緣、溪邊；駝鹿在密林、倒木、深雪裡狼追不下去，用物種的地形代價表現，同 Phase 2d 的騾鹿）。
- 「分次狩獵」（咬傷沒殺死的駝鹿留在這一帶幾天、之後更好抓）是另一條規則，這份不做，之後可以單獨提。
