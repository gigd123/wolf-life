# 提案：旱獺、田鼠與地松鼠的「小撲」、悄悄叼走猞猁的雪兔

2026-10-22 Claude Code 整理。依據：使用者與 ChatGPT 的討論（黃石、落磯山脈的生態；資料來源為黃石國家公園管理局）。使用者決定（2026-10-22）：

- 旱獺做完整戰術場景；田鼠、地松鼠不做戰術場景，做探索時的「小撲」事件。
- 小撲給些微技巧成長，體力消耗低。
- 猞猁加情境 A（悄悄叼走）。

使用者同意這份提案後，Claude Code 才寫進 SPEC，再依順序實作。第 2 版（2026-10-22）：補上「戰術回合／遊戲回合」的說明，旱獺改成最多 1 個遊戲回合；使用者要先給 ChatGPT 看。第 3 版（2026-10-22）：納入 ChatGPT 的意見——旱獺的成功率分三種記、25%／75% 改成模擬的目標區間、加「位置有沒有用」的驗證；小撲的 10% 是每次探索的總機率；猞猁的受傷只在失敗時、失敗的描述照地形變化；驗收分兩層。

## 換算基準與用詞

- 遊戲裡飽食度 1 約 0.1 公斤肉；成年狼一個時段消耗飽食度 6；一隻雪兔 12。
- 「回合」有兩種（2026-10-22 使用者問「旱獺、雪兔的回合會不會太少、沒有狩獵感」後補充）：

| | 意思 | 影響什麼 |
| --- | --- | --- |
| 戰術回合 | 戰術地圖上走一步、撲一下 | 狩獵感：要想幾步 |
| 遊戲回合 | 遊戲時間的一個時段（一天 5 個） | 肚子餓多少、一天能做幾件事 |

- 體力不是照戰術回合數扣，而是照用掉多少「喘」（衝刺、撲咬花得多，潛行幾乎不花）：每場扣的體力 鹿約 16、兔子約 12、選單式抓兔子約 10。

### 現在的雪兔、野兔（已實作，供對照）

- 戰術回合：開局 3～5 格；健康的成兔一場約 5～6 回合，虛弱的、小兔約 3～4 回合（使用者希望 3～5 回合，已經在這個範圍）。
- 遊戲回合：一場最多 1 個，和選單式一樣。
- 趴著不動、你很近才竄出、之字形跑；咬住後幾乎一定到手。

## 一、黃腹旱獺（完整戰術場景）

### 生態

- 體重 1.6～5 公斤。開闊草地、高山草甸、碎石坡，靠近岩塊。
- 在岩石下挖洞，用岩石當觀察點。會發出尖銳的警戒叫聲。
- 冬眠約 8 個月；炎熱乾燥時也可能短暫夏眠。

### 規則

- **出現的地方**：高山草甸、岩壁峽谷（碎石坡）、苔原北部的岩地。
- **季節**：
  - 春季後半到秋季前半才有。
  - 冬季完全沒有：冬眠。
  - 在牠的區域冬天探索時，看得到「洞口被雪封住」這類線索，讓玩家知道不是運氣不好，而是牠們在冬眠。
- **地圖**：新的戰術地圖版面「岩坡草甸」（3 張）。草地上散著岩塊與碎石，有 2～4 個洞口。
  - 「地圖族」在程式裡只是一組戰術地圖的版面（同河狸的水塘、大角羊的峽谷），不是新的世界地圖、區域或探索內容；旱獺出現在現有的山地、苔原區域，遇到時開這種戰術地圖。
  - 新地形「洞口」：旱獺一鑽進洞就算逃掉（「牠一溜煙鑽進岩縫下的洞」）。狼可以站在洞口上，但進不去。
- **開局**：
  - 旱獺離洞近（1～2 格）或遠（4～7 格），沿用河狸、大角羊的寫法。
  - 狼在 5～8 格外，比鹿（10～13 格）近，比兔子（3～5 格）遠。
  - 預期一場約 5～8 個戰術回合：先潛近、判斷路線，牠衝向洞口時攔截。比兔子多想幾步，又不會像鹿那樣 10 回合以上。
- **行為**：
  - 比狼慢，牠的優勢是離洞近、在岩石邊。
  - 視力好、會警戒。
  - 被發現就直奔最近的洞。
  - 碎石坡上牠比狼好走（沿用大角羊）。
- **咬住後**：牠會咬回來（傷 2～6），但壓倒、咬喉都容易。
- **代價**：遊戲時間最多 1 個遊戲回合，和兔子一樣（第一版寫 2 個，2026-10-22 改：肉量 22 不到 4 個時段的消耗，花 2 個遊戲回合會讓划算程度被時間吃掉一大半）。體力預估約 12（靠潛近、埋伏，衝刺少）。
- **肉量**：飽食度 22，約雪兔的 2 倍。一次吃完，不分段。
- **幼獺**：夏季，小一號，飽食度 10。
- **目標成功率**：模擬的目標區間，不是寫死的機率（一般的狼）：
  - 離洞近約 25%、遠約 75%，平均約五成。
  - 未成年的狼約四成。
- **成功率分三種記**（模擬與試玩紀錄）：
  - 投入後的成功率：真的撲出去之後抓到的比例。
  - 遭遇的成功率：所有遇到的旱獺裡，最後抓到的比例（含放棄）。
  - 每次成功的平均代價：體力、遊戲時間、受傷。
- **位置有沒有用（驗證）**：「會選位置的打法」（繞到牠和洞之間、借岩石遮蔽）要明顯比「直線衝過去」好。差不多的話，代表只是擲骰子：回頭調地形、警戒與洞口位置，不是調機率。
- **先不做**：群體與警戒叫聲。先做單隻、一個主要洞口，群體留到之後。

## 二、田鼠與地松鼠的「小撲」（探索事件，不進戰術地圖）

### 生態

- **田鼠**：30～90 公克。草甸、草原、河岸。全年活動，冬季在雪下的通道裡活動。狼會聽聲音、跳起來往雪裡撲。
- **地松鼠**：200～280 公克。開闊草地、山地草甸，要能挖洞。春夏活動，最早七月中就冬眠。
- **金背地松鼠**：森林空地、岩石區、草甸邊緣。當成地松鼠在森林的版本，用同一個事件，不另外做一種。

### 規則

- **何時出現**：每次探索先擲一次「遇不遇到小動物」（總機率，初始值約 10%），遇到了再依地形、季節決定是哪一種；不是每種各擲 10%（那樣三種加起來會變成約 27%）。

| 動物 | 季節 | 地形 |
| --- | --- | --- |
| 田鼠 | 全年 | 空地、草原、丘陵、林緣、高山草甸、開闊苔原 |
| 地松鼠 | 春季、夏季前半 | 草原、丘陵、高山草甸 |
| 金背地松鼠 | 春季、夏季前半 | 林中空地、碎石坡 |

- **畫面**：一段描述，兩個選項：「撲過去」或「不理牠」。
  - 田鼠：草叢晃動；冬季是雪下的窸窣聲。
  - 地松鼠：牠站起來張望。
- **撲過去**：
  - 成功率（初始值）：田鼠 50%，冬季在雪下 40%，感知高的狼加成。地松鼠 40%，看技巧與速度。
  - 成功時飽食度：田鼠 1（一小口），地松鼠 2。
  - 體力 −2（探索是 −6），不額外花時段。
  - 技巧成長：成功約狩獵撲中一次的三分之一，失敗更少；同一天重複的效果遞減，沿用現有的「重複練習遞減」。
  - 失敗：牠鑽回草叢或洞裡，只有一句描述。
  - 畫面寫明是「一小口」，不讓人誤以為是有效的食物來源（例如「你嚼了兩口就沒了」）。
- **定位**：不是食物來源，是小狼的練習與世界的細節。給的肉遠少於花掉的時間；成長也很小，不會取代真正的狩獵。
- **照常過日子**：自動玩家遇到時，未滿 2 歲、體力足夠（≥ 30）才撲（練習），成年後不理。

## 三、悄悄叼走猞猁的雪兔（猞猁的情境 A）

### 現在的設定

- 在有猞猁的區域探索時，有小機率遇到猞猁；一半的機會牠正咬著剛抓到的雪兔。
- 可以選「上前搶下牠的雪兔」，進入戰鬥；趕走牠，雪兔就歸你。

### 新增

- 多一個選項「等牠分心，悄悄靠近叼走」。
- 成功率（初始值）：25% 加上感知與技巧的加成。未成年的狼約 35%～45%，成年約 50%～60%。
- 成功：叼走雪兔（飽食度 12），猞猁跳上樹，不打架。
- 失敗：
  - 牠帶著雪兔離開，描述照地形變化：鑽進密林、躲進岩縫、跳上樹（不是每次都上樹）。
  - 只有失敗時才有 10% 的機會被牠回頭抓一下（傷 3～8，比打一場輕）；所以每次嘗試被抓傷的機率約 4%～6%。
- 試玩紀錄記下：遇到有雪兔的猞猁時，選「悄悄叼走」「正面搶」「離開」的比例，以及從猞猁拿到的食物。三者一起才看得出它會不會變成太可靠的食物來源。
- 和「正面搶」的取捨：悄悄叼走風險低但成功率不高；正面搶要打一場，贏了一定拿到。

## 四、驗收（兩層）

| 功能 | 功能驗收 | 遊戲體驗驗收 |
| --- | --- | --- |
| 旱獺 | 洞穴逃脫、季節、地形與狩獵流程正常；成功率三種口徑都在目標區間 | 玩家會因洞口位置改變策略，而不是只看成功率；會選位置的打法明顯比直衝好 |
| 小撲 | 季節、地形、總機率、技巧成長、體力正常 | 帶來探索的回饋，不變成無聊的重複點擊、不變成刷成長 |
| 猞猁悄悄叼走 | 成功、失敗、受傷、食物取得正常；失敗描述照地形 | 玩家會在悄悄叼走與正面搶之間做不同選擇 |

回歸測試要確認事件裡的物種、圖、文字、結果一致（過去出錯過的就是這類：翻譯鍵、動物名稱與圖錯置）。

## 五、實作順序

1. 旱獺：先做單隻、單一主要洞口，沿用現有的地圖系統；先驗證位置有沒有用，再補季節與區域分布。
2. 田鼠與地松鼠的小撲：探索事件、季節與地形、技巧成長、照常過日子。
3. 猞猁的悄悄叼走。

每步做完跑對應的模擬、回歸測試、更新 progress，再 commit。最後跑一次一生模擬，比較修改前後未成年狼的挨餓、死亡、食物來源比例、狩獵次數與技巧成長，確認改善不是把生存變得太容易。

原則（ChatGPT）：讓小狼比較容易活下來，不是讓小狼變強；牠還是一隻弱小的狼，只是世界裡有更多可以利用的機會。

## Claude Code 的假設（請確認）

- 旱獺一場約 5～8 個戰術回合、最多 1 個遊戲回合。
- 旱獺目標成功率「平均約五成」：沒有選單式可以對齊，用的是「比雪兔難、比白尾鹿容易」的位置。
- 小撲的出現率 10%、成功率、技巧成長「狩獵撲中一次的三分之一」都是初始值。
- 旱獺冬眠時用「洞口被雪封住」的線索讓玩家知道，不是單純遇不到。
