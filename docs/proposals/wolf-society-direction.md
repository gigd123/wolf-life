# 狼群系統與中後期玩法：方向評估（2026-10-16）

使用者與 ChatGPT 討論後提出的問題（苔原互動豐富、黑狼與年輕的狼只有戰鬥與退讓，中後期常固定待在苔原），Claude Code 檢視現有規格與實作後的評估。**使用者同意方向 A：Phase 3 先做「別的狼會自己發展」（最小可玩版本：黑狼的一生，只做森林），再做玩家自己的家庭。** 最小可玩版本的提案另外寫，確認後才實作。

## 一、現況

### 已存在（程式裡有）

| 角色 | 玩家能做的 | 牠自己的變化 |
| --- | --- | --- |
| 黑狼 | 遠觀、跟蹤評估強弱、避開、對峙、打、示弱、讓出或爭地盤、從標記去找牠 | 每季變老；被趕走會換一區；記得你輸過或示弱過幾次 |
| 年輕的狼（只在你老年） | 對峙、打、讓 | 你打贏牠，牠下次更強、來得慢；你讓牠，牠更快再來 |
| 苔原狼 | 靠近、等待、跟著、回應嚎叫、一起狩獵或在旁看、分食、幫忙守巢、圍攻狼獾；關係有敵視、警戒、熟悉、友善 | 每年生幼狼，幼狼長大後會離群；四處遊走；巢穴會受威脅；沒有你也會自己狩獵 |

苔原狼和黑狼的差異在三點：
1. **關係會累積**：苔原狼的關係會開啟或關閉不同的選項；黑狼只有「誰比較強」這一條軸線。
2. **有沒有自己的生活**：苔原狼的幼狼年年出生、長大、離開，玩家看得到；黑狼只會變老。
3. **互動能不能雙贏**：苔原狼可以分食、互相幫忙；黑狼的互動都是零和。

### 合理推測（有資料支持，但還沒用試玩驗證）

- 黑狼的故事在你 3～4 歲就結束了：一生模擬裡 4 歲單挑黑狼勝率 99%，打贏後牠不再驅趕你，而年輕的狼要等你 6 歲老年才出現。森林在 3～6 歲沒有狼的動態，正好對上驗收清單上「壯年最可能變無聊」那一項。
- 中後期重複的其他原因：
  - 成年後幾乎沒有生存壓力：一生模擬裡成年、老年每年挨餓 0 天，狩獵成功率 74～77%；
  - 照常過日子很好用，可以快轉跳過大部分日子；
  - 年況會改變獵物，但很少改變玩家的決策。

### 還沒做（`docs/spec-phase3-draft.md`，待使用者確認後才寫入 SPEC）

- 每張地圖 1～2 個 AI 狼群，會逐年增減；
- 黑狼在你 3 歲後有機會成家，成為森林的鄰群，而且帶著你們過去的紀錄；
- 撞上鄰群、鄰群試探你的領域、加入失去繁殖公狼的狼群；
- 配對、育幼、成員、群獵、多對多戰鬥。

草稿原本的順序是先配對（第 2 步）、後鄰群（第 4 步）。

## 二、評估

1. **互動單一是不是中後期重複的重要原因？** 是，而且時間點吻合：森林的狼互動剛好在壯年期中斷。但成年後沒有生存壓力、照常過日子可以快轉也要一起考慮，狼群系統單獨解決不了「吃得太飽」。
2. **其他狼也成家，最小需要什麼？** 三個條件：
   - **玩家看得到變化**：狼嚎變成合嚎、幾隻狼的足跡與標記、季節卡片、遇見牠的家族；
   - **變化會影響決策**：牠們的區域獵物被分走、危險變高，但殘骸是撿食的機會；邊界成了要不要爭的地方；
   - **過去的紀錄會延續**：牠記得你打贏過或示弱過，影響牠的狼群怎麼對你。
3. **要不要模擬所有狼？** 不用。比照現在苔原狼與黑狼的做法，每次換季時更新一次粗略的狀態（有沒有伴侶、數量、領域、強度、今年的幼狼），再依狀態產生看得到的徵兆。
4. **怎麼避免只想待苔原？** 每張地圖的狼帶來不同種類的決策，而不是互動一樣多：

   | 地圖 | 狼的處境 | 主要的決策 |
   | --- | --- | --- |
   | 苔原（現有） | 遷徙、不守領域 | 合作與信任 |
   | 森林 | 黑狼從獨居到成家，佔據領域 | 爭地、迴避、撿牠們的殘骸 |
   | 草原 | 兩個狼群爭野牛 | 在兩群的邊界之間找縫隙，或選邊站 |
   | 山地 | 狼少、地廣，美洲獅是競爭者 | 獨居的自由與孤立 |

## 三、分階段

**最小可玩版本：黑狼的一生（只做森林）**
- **狀態**：獨居 → 有伴侶 → 有狼群（春天生幼狼）→ 擴張一區 → 黑狼老去、死亡或被取代 → 狼群解散，或換新的繁殖公狼。每次換季時更新。
- **徵兆**：只用現有管道。
- **互動**：沿用避開、跟蹤、對峙、打、讓；新增「撿牠們狼群的殘骸」（有被發現的風險）、「爭一塊邊界」；牠的狼群依過去的紀錄決定態度。
- **對生存的影響**：牠們佔的區域獵物被分走、危險升高，但可以撿殘骸；你的地盤標記淡掉時，牠們會來試探。
- 沿用現有的資料結構：NPC 狼、紀錄、地盤標記、苔原狼的繁殖季。
- **驗證**：
  - 假設：壯年期待在森林的玩家，每一季都會遇到新局勢，而且會改變做法；
  - 驗證方式：試玩紀錄的指標（各季節遇到的事件種類、照常過日子被打斷的原因、選擇的分布）＋使用者玩一段 3～6 歲；
  - 通過標準：在提案時訂，例如「壯年每季至少一次和狼群有關、需要做決定的事」「願意留在森林」。

**後續擴充**（依 Phase 3 草稿）：每張地圖的鄰群（草原兩群、山地一群）→ 配對與家庭 → 群獵與多對多戰鬥 → 加入既有狼群。

**目前不值得投入**：每隻狼逐一模擬移動、狼群戰爭的細節（只要結果與徵兆）、結盟與併群、鄰群一般成員的個體資料、超過 3～4 隻的即時戰鬥畫面。

**另外處理**：成年後沒有生存壓力。鄰群佔走獵物多的區域本身會製造壓力，先做完最小可玩版本再看。
