# 討論資料：單狼與苔原狼一起狩獵的成功率（戰術地圖）

2026-10-22 Claude Code 整理，給使用者和 ChatGPT 討論難度用。只是資料與問題，還沒有決定要怎麼改。

## 一、為什麼要討論

- 使用者試玩苔原狼一起狩獵的原型後發現：有沒有同伴，對**慢的狼**差非常多，原本幾乎抓不到的獵物也有機會抓到。
- 使用者對單狼的想法：
  - 單狼抓**幼體**，即使不是快狼，也要有不小的機會。
  - 抓**成體**，如果不是快狼、對方又沒受傷或太老，就不容易抓；但要看是哪種動物。
- 前一輪的模擬顯示有同伴時整體偏容易（馴鹿群 87%、健康駝鹿 30%，提案原本的目標是馴鹿 50～65%、健康駝鹿 15～25%）。

## 二、數據怎麼來的

- 工具：`tools/sim/tactical_ally_matrix.gd`（戰術地圖的規則，和主遊戲同一套）。
- 狼：原型的三種能力。對應到主遊戲是 Claude Code 的推估（主遊戲能力的基礎上限 60、最高 100）：

  | 原型 | 速度／技巧／力量／感知／耐力 | 大約對應主遊戲 |
  | --- | --- | --- |
  | 慢 | 40／45／45／45／80 | 1 歲左右的小狼 |
  | 普通 | 60／55／55／55／80 | 一般的成年狼 |
  | 快 | 85／60／60／60／80 | 巔峰的強狼 |

- 同伴：2 隻苔原狼（1 隻驅趕、1 隻追擊），能力 速度 66、技巧 56、力量 62、感知 56、耐力 80。
- 成功率是「已經決定出手之後」獵到的比例，而且取**最好的打法**：
  - 單狼：猛追、耐力追、潛近截角、伏擊四種取最好的。
  - 有同伴：潛近、一起猛追、等驅趕三種取最好的。
  - 真人通常打不到這麼好；每格 30～60 場，誤差約 ±8 個百分點；取最好的那一種會稍微偏高。
- 成體：單隻、秋季（成群的動物也放單隻，所以看不出「從一群裡挑最弱的」）。
- 幼體：夏季。白尾鹿、騾鹿、馬鹿、馴鹿、駝鹿、大角羊是「母親（普通體況）＋幼體」，母親會護幼（馴鹿不護）；野牛是整群 8 隻成牛＋2 隻小牛，成牛會擋；叉角羚的幼體是落單的。
- 苔原狼目前的規則（實驗中）：
  - 驅趕：繞到獵物另一側再衝出去，把獵物往你這邊趕；你藏著時撲有埋伏加成 +25%。
  - 追擊：跟著你，獵物跑了就追，追上會咬一口或咬住拖住（獵物停下來）。
  - 苔原狼咬住時你撲上去 +30%、被踢減半。
  - 你咬住時，旁邊有苔原狼一起咬著：壓倒、咬喉的成功率和單狼一樣，但招式的喘只要一半（1 隻）或 3 成（2 隻），獵物也比較難掙脫。
  - 你選「死咬拖住」的那一回合，旁邊的苔原狼會試著把獵物拖倒（比你自己壓倒低一些）。
  - 獵物累到快跑不動時，苔原狼自己也可能把牠拖倒。

## 四、看得出來的事（Claude Code 的整理）

1. **慢的狼加成最大**：健康的白尾鹿 7% → 48%、健康的馴鹿 13% → 77%、普通的馬鹿 22% → 72%。快的狼本來就高，加成小。也就是說，同伴幾乎抹平了能力差距。
2. **野牛是最誇張的**：單狼幾乎都是 0～5%，有 2 隻苔原狼就變成 30～92%，牛群裡的小牛 3% → 92%。生態上獵野牛要 9～13 隻狼才到頂，3 隻狼應該還是很難。
3. **健康的成體在有同伴時太容易**：普通的狼對健康的白尾鹿、馬鹿、馴鹿都到 60～77%。
4. **單狼抓幼體大多已經很高**：普通的狼 82～100%，慢的狼 47～87%；只有野牛小牛（成牛會擋）單狼幾乎抓不到，大角羊的小羊約六成（峭壁）。
5. **單狼抓成體**：普通的狼對「普通體況」的成體 38～70%（叉角羚 10%），對健康的 8～40%。快的狼對普通體況的成體多半 75～87%。
6. **大角羊、叉角羚的同伴加成小**：峭壁、速度讓同伴也追不上，比較合理。
7. **有些同伴反而略低**（大角羊的小羊、公羊）：大多在誤差內，但也可能是同伴在峭壁地形把獵物驚走。

## 六、要討論的問題

1. **單狼的基準**：使用者說「幼體要有不小的機會」「成體不是快狼就不容易，要看動物」。現在的單狼數字（第三節左邊）符不符合？哪些動物太高或太低？例如：
   - 普通的狼對普通體況的白尾鹿 57%、馴鹿 70%、馬鹿 55%，算不算「不容易」？
   - 慢的狼抓幼體 47～87%，夠不夠「不小的機會」？野牛小牛單狼 3～20% 合不合理？
2. **同伴的加成應該怎麼算**：
   - A. 加一個固定的量（例如 +10～20 個百分點）。
   - B. 乘一個倍數（例如約 1.5 倍），慢的狼加得少、快的狼加得多。
   - C. 讓同伴主要補「追得上」的部分（把獵物追累、拖住），但壓倒、咬喉還是看你自己的能力；慢的狼仍然吃虧。
   - D. 依動物決定：鹿、馴鹿加成明顯；駝鹿、野牛要更多狼才有用（2 隻苔原狼仍然很難）；大角羊、叉角羚幾乎沒用。
3. **慢的狼和同伴**：同伴幾乎抹平能力差距，這是好事（小狼跟著狼群學、活下來）還是壞事（能力的成長變得不重要）？
4. **野牛**：2～3 隻狼要把野牛（尤其是牛群裡的小牛）壓到多低？
5. **之後要接進主遊戲的話**：和苔原狼一起狩獵目前是選單式加成；如果改成戰術地圖，成功率的目標要用哪一個版本？

## 七、查證結果（2026-10-22，ChatGPT 的回饋之後）

ChatGPT 的回饋（使用者轉貼）：單狼局部調整、不全面降低；同伴以 C（主要幫追逐、拖住）為核心，結合 D（依物種）；慢的狼和同伴可以縮小差距、不能完全抹平；野牛優先修正；戰術狩獵用階段的機制決定結果；速度、力量、技巧的影響要分開看。依這些問題查了三件事：

1. **野牛小牛為什麼 3% → 92%**（普通的狼，60 場）：
   - 獵到的 45～54 場裡，大部分是苔原狼拖倒、一起扭倒，或你死咬拖住時苔原狼扭倒；你自己撲小牛只中 13%，而且你每場平均被成牛踢掉 52～68 血。
   - 原因不是公式重複計算（戰術地圖沒有單一的成功率公式，結果是規則跑出來的），而是**牛群護幼、成牛擋在小牛旁邊，只看你的位置**：成牛只衝向、擋住、踢你；苔原狼靠近小牛時成牛不理，苔原狼咬小牛也沒有「旁邊有成牛」的扣分、不會被踢。等於苔原狼繞過了野牛最主要的防禦。駝鹿、白尾鹿等母親護幼也一樣。
2. **大角羊小羊的反向變化**（60% → 57%）：多跑到 150 場是 53% → 62%，是誤差。
3. **速度是不是主導**（只改一項能力，其他照普通的狼；單狼 → 有同伴）：

   | 獵物 | 普通 | 只有速度 40 | 只有速度 85 | 技巧、力量、感知 45 | 技巧、力量、感知 70 |
   | --- | --- | --- | --- | --- | --- |
   | 白尾鹿・健康 | 38% → 67% | 12% → 48% | 55% → 73% | 23% → 63% | 40% → 62% |
   | 馬鹿（母）・普通 | 55% → 92% | 30% → 75% | 75% → 97% | 50% → 88% | 60% → 98% |
   | 駝鹿・普通 | 38% → 52% | 13% → 40% | 55% → 80% | 32% → 47% | 53% → 65% |

   - 單狼時速度的影響最大（速度 40 → 85：12% → 55%），技巧、力量、感知小一些（23% → 40%）。
   - **有同伴時，技巧、力量幾乎不影響結果**（白尾鹿 63% 對 62%），因為收尾大多是苔原狼做的（拖倒、扭倒）。這正是「同伴取代個體能力」的問題。速度在有同伴時仍有影響，但變小。
