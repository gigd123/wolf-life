## Phase 2k：戰術戰鬥接進主遊戲

### 目標

- 和灰熊、美洲獅、黑熊、其他狼的衝突，從選單式回合改成格子地圖上的戰術戰鬥：看預告、選位置、決定搶、守、退。
- 「打不贏，但能靠判斷搶到一點肉再脫身」成為主遊戲裡真實的選擇；狼對狼的衝突照狼的習性，多半是示威、壓制與退讓，很少打到死。
- 一次失誤不會直接死；**受了重傷還硬撐**才會。

### 範圍

| 改成戰術戰鬥 | 維持選單式（這個階段不動） |
| --- | --- |
| 灰熊：來搶你的殘骸、從熊口搶肉、灰熊藏食被撞見、直接遭遇、巢穴附近 | 紅狐、郊狼、猞猁、狼獾（體型小、多半很快結束）【假設】 |
| 美洲獅：藏屍、伏擊、直接遭遇 | 牧場的家畜、獵狼人（Phase 4a 的流程） |
| 黑熊：來搶殘骸、遭遇 | |
| 狼：黑狼（陌生的狼）、年輕挑戰者——一對一；苔原狼（一對）、鄰群——多隻 | |

### 戰場

- 16×10 格（同原型）。地形依**所在的區域與季節**產生：森林多樹與倒木、山地有岩台與峭壁、草原開闊、苔原少樹【假設：沿用戰術狩獵的地圖產生方式，切一塊 16×10，再依情境放殘骸、大石頭、樹】。
- 起始位置依情境：來搶的對手從邊緣進場、在殘骸上吃的對手在殘骸旁、伏擊時美洲獅貼著你（照原型：先挨一下，30% 在地圖上開場）。
- 你的伴侶跟著你時一起進場（可以下指令：自動、牽制、叼肉、退開）；子女與其他成員這個階段不進場【假設】。

### 你的狼

- 血量、速度、力量、技巧、感知照主遊戲的狼；喘的上限依體力【假設：體力低時喘的上限 ×0.7】。
- 開打時已經是重傷：直接算「已經重傷」（見下方「被打倒與死亡」）。
- 老年：照主遊戲的衰退（能力值本來就會降，不另外加規則）。

### 被打倒與死亡（使用者選 C）

- **重傷線**：血量降到上限的 30%【假設】以下時，畫面標「重傷」並提示撤退；這一戰結束時套用主遊戲的重傷（部位、天數照現有的傷勢規則）。
- **還沒重傷就被打到 0**（例如一下子被打很重）：停在 1，被打倒、撤出戰場，算重傷，**不會死**。
- **已經重傷（這一戰裡過了重傷線，或開打時就是重傷）還留在場上，被打到 0**：死亡（死因照對手，例如「被灰熊打死」）。
- 撤出戰場（走到邊緣選「撤退」）一定成功【原型規則】；叼著大塊肉時走得比較慢。

### 結果怎麼回到主遊戲

- **肉**：帶出戰場的段數 → 照這具殘骸每段的肉量加飽食度（吃不下的部分照現有規則留在旁邊或藏起來）。對手離開後殘骸留下剩的段數，照現有的殘骸規則（回到殘骸、被吃掉、腐壞）。
- **傷**：依這一戰被打中的情況套用輕傷／重傷（部位、天數照現有的傷勢規則）；伴侶受的傷記在伴侶身上。
- **時間與體力**：回合數換算成遊戲時間與體力（照戰術狩獵的換算）【假設】。
- **打贏的定義**：把對手打傷趕走（對手因血量而離開）＝打贏，照現有的「第一次打贏」卡片與潛力加成；對手失去興趣離開、你撤退＝沒有勝負。
- **知識**：戰鬥裡看到對手出手會記住（原型的「見過幾次」），存進主遊戲的知識；之後遇到同一種對手時預告看得比較清楚。

### 黑熊（新）

- 生態依據（記述）：黑熊比灰熊小、比較常退讓，會爬樹；在殘骸旁常虛張聲勢。
- 抽象：沿用灰熊的 AI，血量與傷害約灰熊的 0.6【假設】，比較早放棄；受傷或被圍時可能爬上樹＝離開戰鬥（同美洲獅）。

### 狼對狼（新）

- 生態依據（研究／記述）：狼與狼的衝突多半是示威、追趕、壓制與退讓；外來的狼常被趕走，真的咬死多半發生在領域衝突、或一方被圍。
- 新的動作【假設，原型裡沒有】：
  - **示威**：豎毛低吼，不前進；讓對方的耐心掉得比較快（不想打的對手會退）。
  - **壓制**：從側面或背後撲上去壓住，成功時對方多半示弱。
  - **示弱**（雙方都能用）：趴低、退開；示弱之後對方多半停手。對方示弱時你可以選放牠走或追擊（照現有的選單式規則）。
- 對手的 AI：依實力差距、是不是在自己的領域、有沒有殘骸、帶不帶家人決定要壓過來、示威還是退讓；年輕挑戰者每次來都更壯（照現有規則）。
- **多隻對手**（苔原狼一對、鄰群 2～3 隻）：每隻各自預告；牠們會試著繞到你兩側。你的伴侶在場時可以下指令。

### 交給本能與自動玩家

- 戰鬥畫面有「交給本能」（照原型的自動規則打完）。
- 自動玩家（照常過日子、模擬）用同一套自動規則。

### 不做（這個階段）

- 子女與其他成員一起進場的完整狼群戰鬥；狐狸、郊狼、猞猁、狼獾的戰術版；守巢、圍樹的完整規則。

### 驗收

1. 灰熊、美洲獅、黑熊、狼的衝突都在格子地圖上打完，結果正確回到主遊戲（肉、傷、時間、死亡）。
2. 一生模擬：死於戰鬥的比例、每年重傷次數和改版前差不多（±30%）【假設】；壽命仍在 9～11 歲。
3. 灰熊、美洲獅的通過標準照原型（第一次試叼 40～60%、不利局勢每次試叼低於 15%、擊退灰熊約 5% 以下）。
4. 狼對狼：正常成長的狼對黑狼的勝率照現有標準（2 歲約四成、3 歲八成多、4 歲幾乎都贏），多半以一方示弱結束，不是打到死。
5. 試玩：輸了說得出原因；「重傷了還硬撐」時知道自己在冒險。

### 實作順序（一次一步，每步都能測）

1. 主遊戲的戰鬥接口：依區域產生戰場、你的狼與伴侶、結果送回主遊戲（肉、傷、時間、被打倒與死亡）；先接**灰熊與美洲獅**的所有情境，取代選單式；自動玩家；回歸測試。
2. 知識：戰鬥裡學到的存進主遊戲的知識，預告與機率顯示跟著變。
3. 黑熊：AI、數值、情境。
4. 狼對狼一對一：示威、壓制、示弱，黑狼與年輕挑戰者的情境、放牠走／追擊、打贏的成長。
5. 多隻對手：苔原狼一對、鄰群；伴侶在場。
6. 主遊戲裡的 HD-2D 畫面（共用 `HD2DBoard`）、一生模擬校準、試玩清單。

### 與現有規則的關係

- 取代：上述對手的選單式戰鬥（`Combat.gd` 留給狐狸、郊狼、猞猁、狼獾）。
- 不變：戰鬥之前的事件（線索、選擇要不要靠近、灰熊藏食的觀察）照現有流程，只有「打起來」那一段換成戰術戰鬥。
