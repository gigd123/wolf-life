# 提案：所有狩獵都改成戰術場景（田鼠、地松鼠的小撲除外）

2026-10-24 Claude Code 整理，第 1 版。依據：使用者（2026-10-24）「我希望所有的狩獵都改成戰術場景，不然現在有時候戰術、有時候選單式狩獵，有點混亂，只有土松鼠、田鼠那種維持選單」。同一天使用者選了苔原狼一起狩獵的方案 B（`tundra-joint-in-game.md`，假設照建議）。之前的評估在 `all-tactical-and-meat.md`（2026-10-22 決定：三個特殊入口先維持選單；這次改成也要做）。使用者選定之前不寫規格、不實作。

## 一、還走選單式的入口

| 入口 | 動物 | 現在 |
| --- | --- | --- |
| 和苔原狼一起狩獵 | 馴鹿、駝鹿 | 選單式（苔原狼的幫忙是加成）→ 已選 B |
| 獵物靠近（休息時） | 雪兔，白尾鹿、馴鹿、騾鹿的幼鹿 | 一撲定勝負的事件，接選單式 |
| 躲在草裡的幼鹿 | 鹿類的幼鹿（開局就躲著） | 選單式，要靠感知搜尋 |
| 受傷的個體 | 所有動物（野牛例外） | 選單式 |
| 紅狐 | 紅狐 | 選單式（戰術地圖沒有牠） |
| 牧場的家畜 | 牛犢、一歲牛、成牛、羊 | 選單式（Phase 4a 寫「家畜跑不快，先走選單」） |
| 小撲、悄悄叼走猞猁的雪兔、鮭魚 | 田鼠、地松鼠；猞猁；鮭魚 | 事件或自己的模式，**維持不變** |

## 二、不太影響玩法、照一個做法的

- **受傷的個體**：走戰術地圖（同野牛）。受傷 = 逃跑格數少、比較快累、咬住後比較難掙脫，照選單式受傷的加減換算，校準到選單式的成功率。
- **紅狐**：新物種，短版地圖（同雪兔：開局近、跑出 8 格跟丟），比雪兔快一點、會鑽進灌木（類似旱獺的洞口，用現有的灌木地形）、咬住後會回咬；俯視小圖。校準到選單式的成功率。
- **選單的邏輯不刪**：田鼠、地松鼠照用；其他入口的選單按鈕隱藏（`tactical_eligible` 全部打開），留著當模擬的對照。

## 三、要決定的（各有 2 個做法）

### 1. 獵物靠近（休息時撲抓）

| | a. 短版戰術場景（建議） | b. 一般開局，只是距離近 |
| --- | --- | --- |
| 做法 | 開局獵物在 2～3 格、還沒察覺，你一兩步就能撲；撲中就咬住，撲空就變一般追逐 | 照一般的戰術開局，獵物在 4～6 格 |
| 遊玩感受 | 保留「突然出現在眼前」的緊張感，一場很短 | 和一般狩獵沒有差別，這個事件的特色沒了 |
| 代價 | 小 | 很小 |

### 2. 躲在草裡的幼鹿

| | a. 有「大概在哪」的範圍（建議） | b. 直接看得到位置 |
| --- | --- | --- |
| 做法 | 地圖上標一塊 3×3 的草叢「牠大概在這一帶」；走到 2 格內或觀察一次才看得到確切位置；被發現前牠趴著不動，你很近才竄出（同雪兔的趴著不動） | 開局就看得到牠，趴著不動，很近才竄出 |
| 遊玩感受 | 保留「搜尋」：要冒險靠近，還是先觀察；感知有用 | 比較單純，「躲著」只剩「不會先跑」 |
| 代價 | 中（新的「看不見的目標」規則與畫法） | 小 |

### 3. 牧場的家畜

| | a. 先用現有的地圖（建議） | b. 牧場專屬的地圖 |
| --- | --- | --- |
| 做法 | 放牧地用開闊草原的地圖、屋舍與畜欄用空地的地圖；牛用野牛的站定規則（成牛護犢、會衝撞），比野牛慢、比較不耐跑；羊擠成一群、跑不快。牧場的反應照現在：戰術場景結束後，獵到加注意、被發現（走到潛近以後）算被看到 | 放牧地加柵欄（狼鑽得過、牛過不去）、畜欄的羊被柵欄圍住、狗在幾個回合後吠叫，牧羊人出現直接接巡查遭遇 |
| 遊玩感受 | 家畜和野生獵物的差別在「容易抓、但人會記住」 | 牧場本身變成一個有地形的戰術場面，在牧場打獵更有「闖進人的地方」的感覺 |
| 代價 | 小～中 | 大（新地形、柵欄規則、狗與人在戰術地圖上；Phase 4a SPEC 要大改） |

建議先做 a；b 之後要的話，等牧場的試玩回饋再決定。

## 四、順序（約 7 步）

1～4. 苔原狼一起狩獵接進主遊戲（方案 B 的 4 步）。
5. 受傷的個體、獵物靠近（短版）。
6. 躲在草裡的幼鹿、紅狐。
7. 牧場的家畜；所有入口的選單按鈕隱藏；一生模擬（`life_pressure`、`ranch_life`）、回歸測試、事件結局矩陣、試玩清單。

## 五、驗證

| 項目 | 方式 | 標準（初始值） |
| --- | --- | --- |
| 每種新進戰術地圖的動物或入口，成功率和選單式差不多 | 各自的校準模擬（同之前每種動物的做法） | 和選單式差 10 個百分點以內（家畜照 Phase 4a 的驗算：成年狼 牛犢約 83%、一歲牛 66%、成牛 17%、羊 85%） |
| 一生的壓力不變 | `life_pressure`（30 隻）、`ranch_life` | 每年挨餓和現在差不超過約 ±20%（現在：成年約 3.6～4.6、老年約 6～9 天） |
| 遊玩時間 | 估算（`tactical_action_count`） | 小獵物、獵物靠近一場不超過約 30 秒；全部加起來每個遊戲天的操作時間多不超過約三成 |
| 不再混亂 | 試玩 | 除了小撲，看到「狩獵」都進戰術地圖 |

## 六、要使用者決定的

1. 獵物靠近：a／b（建議 a）。
2. 躲在草裡的幼鹿：a／b（建議 a）。
3. 牧場的家畜：a／b（建議 a）。
4. 順序：先做苔原狼（B）再做其他，還是反過來（建議先做苔原狼，因為已經定好了）。

另外，Phase 4a 的 SPEC 寫著「家畜先走選單式」，選定之後要一起改（改法另外給你看）。
