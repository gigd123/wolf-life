# 提案：馬鹿、騾鹿、馴鹿接進戰術地圖（草稿）

2026-10-20 Claude Code 起草。接在 Phase 2c（白尾鹿）之後；SPEC 2c 寫「之後：馬鹿、騾鹿、馴鹿（另外排）」。
駝鹿、野牛（站著反擊）、大角羊（逃上崖壁）、叉角羚（太快、主要伏擊幼獸）不在這份，另外提案。

使用者的狀況（2026-10-20）：最近比較忙，不一定有時間慢慢試玩。所以這份的每一步都設計成**可以用模擬驗收**，使用者最後只要試玩看手感；要決定的只有下面 4 個問題。

## 目標

- 白尾鹿以外的鹿類也用戰術地圖狩獵，而且**三種打起來不一樣**：
  - 馬鹿：大、會踢，健康的幾乎撲不倒，要靠拖垮；成群。
  - 騾鹿：平地好追，讓牠跳上岩坡就追不到了，要在牠上坡前截住。
  - 馴鹿：開闊的苔原上很難潛近，比狼快，靠鹿群裡掉隊的那一隻；會涉水甩掉狼。
- 成功率對齊現在的選單式狩獵（`hunt_levels` 的各物種數字），一生的挨餓、壽命不要變。

## 生態、抽象、體驗（設計支柱第五節的檢查）

| | 生態依據（`ecology-reference.md`） | 遊戲的抽象 | 玩家的決策 |
| --- | --- | --- | --- |
| 馬鹿 | 比狼容易累，長距離跟隨有效；所有馬鹿用前蹄踢；成大群、警戒高 | 逃跑格數後段掉得快（已有 `species.elk`）、撲倒難、常被踢；咬後腿拖垮（K3 已有） | 冒險撲咬還是跟著耗；要不要冒被踢的風險 |
| 騾鹿 | 平地跑不快，被追時四腳彈跳往上坡、岩坡跑；崎嶇地形狼不利、平地有利（主遊戲 `terrain_chase` 已是這個方向） | 岩坡格對騾鹿不減速、對狼照舊 +2；逃跑時偏向岩坡 | 在牠上坡前截住，還是繞到坡上面堵 |
| 馴鹿 | 健康成鹿比狼快、短程追不到；狼先試探鹿群找掉隊的；涉水過河幾乎不受影響、狼被大幅拖慢；成功率對群體遠高於單隻 | 開闊地圖、少掩蔽；逃跑格數高；河對馴鹿不減速、對狼 +2 | 挑誰、什麼時候出手；別把牠趕向河 |

「真實但沒有決策」的檢查：馬鹿的「跟著耗」、騾鹿的「坡」、馴鹿的「河」都會改變玩家要往哪裡走，不只是數字。

## 要使用者決定的問題

### 1. 馬鹿、馴鹿的鹿群怎麼放進戰術地圖

- **A. 真的鹿群**：地圖上 4～8 隻（照主遊戲的鹿群大小縮），觀察後標出最弱的一隻，你點一隻當目標；一隻驚整群跑、衝進去會散開（鹿群版原型 E～H 的規則）。
  - 感受：最像真的狼「試探鹿群」，每場都在挑。
  - 代價：要校準的情況多；畫面上鹿多、比較擠；鹿群版原型（K2）你還沒試玩過，手感未確認。
- **B. 一個目標＋旁邊幾隻**（建議）：目標照主遊戲現在的流程決定（觀察鹿群找出跑得慢的那一隻），地圖上另外放 2～3 隻同伴，只負責「一隻驚、全部驚」和擋路，不能撲。
  - 感受：和白尾鹿一樣好上手，但潛近時要顧到好幾雙眼睛。
  - 代價：少了「在地圖上挑哪一隻」的決策；之後要升級成 A 時，畫面與規則都能沿用。
- **C. 只有一隻**：鹿群只在主遊戲層用數值表現。最簡單，但馬鹿、馴鹿和白尾鹿差別變小。

### 2. 騾鹿的彈跳逃跑

- **A. 物種的地形代價**（建議）：騾鹿在岩坡格（地圖上的 `l`）不減速，狼照樣 +2；逃跑的目的地偏向岩坡。山地新增一族「岩坡」地圖（大片岩坡、坡下有草甸）。
  - 感受：平地上追得到，讓牠上了坡就沒了；地形判斷變成關鍵。
  - 代價：多一條規則「每種動物在各種地形的代價可以不同」（問題 3 的河也會用到）。
- **B. 只改數值**：逃跑格數、撲咬加減照騾鹿調，地形對所有動物一樣。最簡單，但騾鹿打起來和白尾鹿差不多。

### 3. 馴鹿與河

- **A. 加水格**（建議，和問題 2 的 A 共用同一條規則）：河谷地圖有一條河（新的地形字元與地塊）；馴鹿涉水不減速，狼 +2。
  - 感受：要避免把牠趕向河，或在河邊等牠。
  - 代價：新的地塊圖；白尾鹿遇到河時照一般地形的代價（白尾鹿也會游泳，但先不做）。
- **B. 先不做**：河谷照現在用柳叢地圖表示。生態上馴鹿最大的特色之一會少掉。

### 4. 會站定的公鹿（公馬鹿）

- **A. 先維持選單式**（建議）：公馬鹿（健康的五成會站定用角對峙）照舊走選單；母鹿、小鹿走戰術地圖。等駝鹿、野牛的「站定」規則一起做。
- **B. 公馬鹿也進戰術地圖，但不站定**：只用數值表現（更難撲倒、踢得更重）。少了站定，和真實差距較大。

## 通過標準（初始值，都用模擬驗收）

- 成功率：一般的狼、強狼對健康／虛弱的成鹿，最好的打法和現在選單式的 `hunt_levels` 差 ±5% 以內（現在：成年能力 60 對健康成鹿 馴鹿 40%、馬鹿 40%；巔峰 54%、47%；騾鹿依地形另外量）。
- 三種的差別看得出來：同一隻狼，騾鹿在草甸地圖明顯比岩坡地圖好抓；馴鹿在開闊地圖潛近明顯比白尾鹿難；馬鹿被踢的次數明顯比白尾鹿多。
- 「交給本能」比最好的打法低約一成；一場 6～15 個回合（`tactical_action_count` 估計 2 分鐘內）。
- 一生模擬（`life_pressure`）的挨餓、壽命和 Phase 2c 第 5 步的結果差 ±20% 以內。

## SPEC 草稿（照建議 1B、2A、3A、4A 寫；使用者選了別的再改）

### Phase 2d：馬鹿、騾鹿、馴鹿接進戰術地圖

- 母馬鹿、小馬鹿、騾鹿（成鹿、公鹿、幼鹿）、馴鹿（成鹿、幼鹿）選「狩獵」時進戰術地圖；公馬鹿照舊走選單（站定的規則之後和駝鹿、野牛一起做）。受傷的個體、躲在草裡的幼鹿照舊走選單。
- 鹿群（馬鹿、馴鹿、冬季的騾鹿）：目標照主遊戲的流程決定；地圖上另外放 2～3 隻同伴，一隻驚整群跑，同伴會擋路，不能撲。
- 物種的地形代價：各物種在各種地形的移動代價可以不同（`tactical_hunt.json` 的 `species.*.terrain_cost`）。騾鹿在岩坡不減速、逃跑偏向岩坡；馴鹿涉水不減速。狼的代價照舊（岩坡、水 +2）。
- 地圖：新增三族——岩坡（山地的碎石坡、岩壁、岩地）、苔原（開闊、幾乎沒有掩蔽、視野遠）、河谷（一條河、兩岸零星柳叢），各 2～3 張。高山草甸照開闊地。
- 數值：馬鹿沿用原型的 `species.elk`；騾鹿、馴鹿新增 `species.mule_deer`、`species.caribou`（逃跑格數、撲咬加減、踢、咬住後的加減、肉的段數），初始值由校準模擬決定。
- 圖：騾鹿（大耳朵、黑尾尖）、馴鹿（淺色脖子、角）的俯視小圖；水、岩坡的地塊（佔位，程式畫）。
- 其他照 Phase 2c（交給本能、觀察、放棄、時間與體力、年齡減成只扣撲咬、結果接回主遊戲）。

### 實作順序

1. 馬鹿：母鹿、小鹿接進主遊戲（`species.elk` 已有），加同伴；校準對齊 `hunt_levels`。
2. 物種的地形代價、岩坡地圖族、騾鹿（數值、圖、逃向岩坡）；校準。
3. 苔原、河谷地圖族、水格、馴鹿（數值、圖、涉水）；校準。
4. 一生模擬、回歸測試、試玩清單。

## Claude Code 的假設（要使用者知道）

- 選單式 `hunt_levels` 的數字當作對齊目標，假設那些數字是你接受的難度。
- 「同伴不能撲」假設你不在意每場都挑目標；若試玩鹿群版原型（K2）覺得挑目標好玩，再升級成問題 1 的 A。
- 水和岩坡只影響移動代價，不影響撲咬機率（在水裡撲咬會不會更難，先不做）。
- 這份不改白尾鹿的任何數值。
