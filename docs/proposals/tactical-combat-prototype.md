# 戰術戰鬥原型規格（草稿，2026-11-04）

依使用者的決定（下面第零節）寫的**原型規格**（2026-11-04 使用者確認第十三節，並補充搶食的物種與叼肉的大小）。原型獨立於主遊戲（同戰術狩獵原型的做法），確認好玩後才接進主遊戲、寫進 SPEC。標【假設】的是 Claude Code 先訂的初始做法或數值，原型裡會用模擬與試玩調整。

前面的討論：`tactical-combat.md`（方案 A～D）、`tactical-combat-b-eval.md`（B 的評估）。

## 零、使用者的決定（2026-11-04，和 ChatGPT 討論後）

| 問題 | 決定 |
| --- | --- |
| 方案 | **B 的架構，分階段做**（不先做 D 再改） |
| 結算方式 | 原型兩種都做、可以切換比較（同步結算／預告後輪流）；正式方向以**同步結算**為主 |
| 機率顯示 | 知識低顯示範圍、高顯示精確數字；知識再低也至少看得出風險高低。知識只影響「看得多準」，不影響實際機率 |
| 伴侶 | 第一階段加入**簡化的合作**：牽制、叼肉、依危險撤退，玩家可以下簡單指令 |
| 家族知識 | 只在資料上預留欄位（類別、來源），不做傳承 |
| 演出 | 原型用圖示、文字、預告範圍、簡單的結算動畫，不做姿勢動畫 |
| 動作庫 | 物種共用動作庫，但**每種動物只能用牠做得到的動作**（例如狼不能爬樹） |

**目標（使用者）**：玩家能透過自己的判斷，改變看起來不利的局勢。例如單狼遇到灰熊，不只是看到「勝率 5%」就逃，而是利用地形、距離、角度、灰熊的注意力與食物的位置，找到叼走一小塊肉、安全撤退的機會。

## 一、假設、驗證方式、通過標準

- **假設**：預告＋同步結算＋站位，會讓玩家依局勢改變打法；「取得一點食物後安全撤退」成為單狼對灰熊時真實可行、但有風險的選擇；知識高的狼明顯比較少被假動作騙。
- **驗證方式**：
  1. 原型的固定情境（第九節），兩種結算方式。
  2. 固定打法的模擬，每種 200 場以上、三種狼（新手、普通、老練）：一直正面咬、一直繞後、搶了就跑、一直閃、什麼都不做守在食物旁、看到預告就照預告閃。
  3. 使用者試玩。
- **通過標準【假設，試玩後調】**：
  1. 沒有一種固定打法在所有情境都最好；每個情境至少兩種打法各有道理。
  2. 單狼對成年灰熊：擊退的機率不高於現在的選單式（約 5% 以下）；但「叼到至少一段肉並撤退」在有利的局勢（灰熊在吃、你在牠背後、有退路）約 40～60%，在不利的局勢（牠面對你、背後是峭壁）低於 15%。
  3. 有伴侶時，「一隻牽制、一隻叼肉」比單狼多拿到肉，但受傷的風險也被分到伴侶身上（看得出取捨）。
  4. 知識高的狼被假動作騙到（照預告閃開卻被打中，或為了假衝放棄食物）的比例，比知識低的少一半以上。
  5. 一場的回合數：灰熊 6～15 回合，美洲獅 4～10 回合；「交給本能」可以自動打完。
  6. 同步與輪流兩種模式都能玩完；試玩後使用者選一種當正式方向。
  7. 玩家輸了說得出原因（站錯位置、貪了第二塊肉、看錯預告）。

## 三、回合流程

### 同步結算（正式方向）

1. **表態**：對手照 AI 選好這回合的動作與目標範圍（例如「揮掌：正面三格」）。畫面依資訊等級顯示預告（第六節）。
2. **玩家決策**：一段移動＋一個主要動作（第四節）。伴侶照指令決定。
3. **結算**：
   1. **移動**：雙方同時移動。同一格只能站一隻；搶同一格時速度快的先到，另一隻停在前一格【假設】。
   2. **變卦**：對手有一定機率在這時改成別的動作（假動作、臨時撤退），機率依物種與局勢。
   3. **動作**：照先後出手（沿用 Phase 1.9 的先後：速度、動作種類、距離）。對手的攻擊打「範圍」：移動後還在範圍裡的才會被打中。狼的咬、撲打「目標」：出手時目標不在攻擊距離內就撲空。
   4. 先出手的打中，可能打斷後出手的（沿用現在的打斷規則）。
4. 播放事件序列，進下一回合。

### 預告後輪流（比較用）

1. 表態（同上）。
2. 玩家的移動與動作**立刻結算**。
3. 對手照表態出手；出手前可以朝最近的威脅轉一次（最多 45°），再照變卦機率決定是否改變動作。

兩種模式共用同一套地圖、動作、AI、數值，只有流程不同；原型可以隨時切換。

## 四、狼的動作與行動成本

**每回合：一段移動＋一個主要動作。**

- **移動**：小跑距離內不花喘，超過就是衝刺、花喘（同狩獵）。跳上大石頭算移動（花一點喘）。
- **主要動作**（擇一）：

| 動作 | 條件 | 效果 |
| --- | --- | --- |
| 咬 | 目標在旁邊（1 格） | 傷害；從後方、側面機率高，正面低且容易被反擊 |
| 撲 | 2 格內、花喘 | 傷害較高；移動後再撲機率較低 |
| 騷擾 | 旁邊 | 咬一下就退一格：傷害低、主要耗對手的體力與耐心 |
| 叼一塊 | 站在殘骸旁 | 帶走 1 段肉；對手面向別處或在吃時機率高，面對你時低、而且會被反擊 |
| 撕一條腿／整個叼走 | 站在殘骸旁 | 大殘骸撕下一條後腿（2～3 段）、小殘骸（野兔、幼鹿）整個叼走；要多花力氣，機率比叼一塊低、被反擊的風險高（沿用現在「整個叼走」的規則） |
| 守住 | 站在殘骸旁 | 對手要吃或叼肉時要先過你：牠這回合吃不到；你被攻擊的機率高 |
| 威嚇 | 3 格內 | 嚇退／僵持／激怒（沿用現在的三段） |
| 閃避 | — | 這回合不攻擊；被打中的機率大降，可以多退一格（花喘） |
| 觀察 | — | 這回合不攻擊；下一回合的預告與機率顯示高一級 |
| 撤退 | 站在地圖邊緣 | 離開戰鬥（帶著叼到的肉） |

- **喘**是戰鬥裡的短期資源（衝刺、撲、閃避都花），喘用完只能小跑、不能撲；**體力**是結束時一次結算（同狩獵）。
- **叼著肉時**，移動依肉的大小變慢（使用者，2026-11-04）：

| 叼著的 | 例子 | 移動 |
| --- | --- | --- |
| 小 | 野兔大小、一小塊肉 | 不變 |
| 中 | 從大殘骸叼的一段 | 少 1 格 |
| 大 | 一條後腿、一整隻幼鹿 | 少 2 格，也不能衝刺 |

  叼著肉不能咬、撲；要打就先放下（放下不花動作，肉留在那一格，別的動物可以撿走）【假設】。

## 五、對手：共用的動作庫＋物種能用的動作

動作庫（每個動作有：範圍、預備時間、出手後的空檔、傷害、預告的樣子）：

| 動作 | 範圍 | 能用的物種 |
| --- | --- | --- |
| 揮掌 | 正面 3 格（左前、前、右前） | 灰熊、美洲獅、（黑熊） |
| 衝撞 | 正前方一直線 3 格，停在第一個撞到的東西前 | 灰熊、（黑熊） |
| 假衝 | 預告和衝撞一樣，衝 1～2 格就停 | 灰熊、（黑熊） |
| 撲擊 | 3 格內選一格，連同旁邊一格 | 美洲獅、狼 |
| 咬 | 正前方 1 格 | 美洲獅、狼、灰熊 |
| 轉身 | 面向改變（灰熊每回合 45°，美洲獅、狼任意） | 全部 |
| 移動、後退 | — | 全部 |
| 吃 | 在殘骸旁，殘骸少 1 段 | 全部 |
| 守食物 | 站在殘骸旁面向威脅，出手範圍變大 | 灰熊、美洲獅、狼 |
| 背靠岩壁 | 移到岩壁旁，背後不會被攻擊 | 灰熊、美洲獅 |
| 爬樹 | 走到夠大的樹旁，下一回合上樹（第一階段＝離開戰鬥，殘骸留下） | 美洲獅、（黑熊）；狼、灰熊不能 |
| 逃跑 | 往地圖邊緣跑，出去就結束 | 全部 |

（括號裡的是第二階段的物種。）

物種資料（`data/tactical_combat.json`）：能用哪些動作、各自的基本權重、轉身速度、移動速度、追擊的耐力、變卦機率、預告的清楚程度、放棄的條件（血量、體力、利害）、個性範圍。

- **灰熊**：轉身慢（45°）、正面極危險、揮掌與衝撞傷害高；守食物時常假衝（變卦機率高）；注意力在誰身上就面向誰；血量很高，通常不是被打跑，而是「覺得不值得」才走。
- **美洲獅**：轉身快、撲擊範圍大、預告模糊；不想為了食物拚命，受傷或被兩隻狼圍住時常上樹或逃跑。

**AI**：每回合替能用的動作打分（距離、角度、自己的血量與體力、利害、對方幾隻、誰剛咬了牠、附近有沒有樹或岩壁、殘骸還剩多少），加一點隨機選一個。**注意力**：牠面向「最近咬牠的」或「最靠近殘骸的」那隻【假設】，這是玩家和伴侶分工的關鍵，畫面上看得到牠面向誰。

## 六、預告與資訊等級

每回合的預告依**資訊等級**顯示。資訊等級＝行為知識（這種動物的這個動作見過幾次）＋感知，距離遠、視線被擋、夜晚降一級；「觀察」升一級。

| 等級 | 預告 | 範圍顯示 | 假動作 |
| --- | --- | --- | --- |
| 模糊 | 「牠在蓄勢」 | 不顯示範圍，只標出牠的正面 | 看不出 |
| 部分 | 「牠要攻擊」 | 顯示可能的範圍（揮掌或衝撞的聯集） | 看不出 |
| 明確 | 「抬起前掌，要揮掌」 | 顯示這個動作的範圍 | 偶爾提示「可能是假動作」 |
| 熟悉 | 同明確 | 同明確 | 常提示「可能是假動作」 |

**機率顯示**（狼的每個動作的按鈕上）：

| 知識 | 顯示 |
| --- | --- |
| 沒見過 | 風險「高／中／低」＋很寬的範圍（例如「約 20～60%」） |
| 見過一點 | 範圍（「約 30～50%」） |
| 有經驗 | 約略數字（「約 40%」，以 5 為單位） |
| 熟悉 | 精確數字（43%） |

實際機率只由位置、角度、喘、體力、對手狀態決定；知識只改變顯示。

**原型裡的知識**：情境開始時選「新手／有經驗／老練」，對應每個動作的知識等級 0～3。原型也會照「看到這個動作出手」累積，方便試玩時感受學習（不存檔）。資料欄位預留 `category`（習性、實戰、地方）與 `source`（自己、家族）。

## 七、殘骸（搶食）

- 殘骸佔一格，有段數（馬鹿約 6 段）【假設】。
- 對手「吃」一次少 1 段；狼「叼一塊」成功帶走 1 段，撤出地圖就算你的。
- 叼一塊的機率：對手在吃、面向別處 → 高；對手面向你、在旁邊 → 低，而且會先被揮掌或咬。
- 結局：守住殘骸（對手走了）、叼到幾段後撤退、殘骸被吃光或佔住、受傷撤退、被打倒（原型裡不會死，記為「被打倒」）。

## 八、伴侶的簡化合作

- 一隻伴侶，玩家每回合可以給一個指令（不給就照上一個）：
  - **牽制**：站在和你不同的一側，對手面向別處時騷擾，吸引注意力。
  - **叼肉**：從對手背後的方向接近殘骸，有機會就叼一塊、往地圖邊緣撤。
  - **退開**：退到對手的範圍外。
  - **自動**：依局勢選上面三種。
- 伴侶血量低於四成會自己退開。
- 伴侶的動作也用同一套動作與機率；伴侶被打中、受傷都會顯示。

## 九、情境

1. **灰熊來搶你的馬鹿**：你在殘骸旁，灰熊從邊緣走來。
2. **灰熊趴在殘骸上吃**：你從遠處開始，殘骸旁有幾棵樹和一塊大石頭。
3. **開闊地撞上灰熊**：沒有殘骸，距離 5 格；灰熊可能假衝。
4. **美洲獅守著藏起來的鹿**：旁邊有大樹與岩壁。
5. **美洲獅伏擊**：在旁邊開場，牠先出手（沿用現在「先挨一下」的規則，有 30% 機會在地圖上開場、讓你有一回合反應）【假設】。
6. **情境 1＋伴侶**。
7. **情境 2＋伴侶**。

每個情境可選：結算方式（同步／輪流）、狼（新手、普通、老練的能力）、知識（新手、有經驗、老練）、有沒有伴侶（情境 6、7）。

## 十、畫面（原型）

- 沿用狩獵原型的 2D 俯視格子。
- 對手：面向箭頭、預告圖示＋一行文字、範圍上色（明確＝實色，部分＝淡色、虛線）。
- 狼：可以移動的格子、主要動作的按鈕（機率依第六節顯示）、喘與血量。
- 伴侶：位置、指令按鈕。
- 殘骸：段數。
- 結算後依序播放：誰移動、誰先出手、打中沒有、「牠改變了動作」。
- 右欄紀錄、按鈕：重新開始、換情境、切換結算方式、交給本能（自動打完）。

## 十一、模擬

`tools/sim/tactical_combat_sim.gd`：每個情境 × 固定打法 × 狼 × 知識 × 結算方式，各 200 場，輸出：叼到的段數、擊退率、受傷、回合數、被假動作騙到的比例、伴侶受傷。用來檢查第一節的通過標準。

## 十二、時程【假設】

- 共用工具函式抽出、邏輯（流程、動作、AI、殘骸、伴侶、資訊等級）、數值：約 1.5 週。
- 原型畫面：約 1 週。
- 模擬與調整：約 0.5～1 週。
- 第一階段原型合計約 3～3.5 週，做完先給使用者試玩，再決定第二階段與接進主遊戲。

## 十三、要使用者確認的

（2026-11-04 使用者全部確認）

1. 範圍與情境：可以。之後其他動物也會有搶食、守食的情境 → 框架做成通用的（第二節）。
2. 叼著肉：看肉的大小，大的少 1～2 格、小的不太影響 → 第四節的表。
3. 美洲獅上樹第一階段＝離開：可以。
4. 伏擊先挨一下、30% 在地圖上開場：可以。
5. 原型裡被打倒不會死：可以。

## 十四、實作順序（一次一步，每步都能測）

1. 共用工具抽出（地圖、移動成本、可到的格子、角度、喘），狼和對手的資料、`data/tactical_combat.json`、殘骸。
2. 回合流程：表態、玩家的移動＋動作、同步結算（移動 → 變卦 → 先後 → 範圍判定 → 打斷）、預告後輪流；結束條件。
3. 動作庫與兩種對手的 AI（灰熊、美洲獅）、注意力、背靠岩壁、上樹。
4. 資訊等級與機率顯示、觀察、知識累積（原型內）。
5. 伴侶的簡化合作。
6. 原型畫面。
7. 模擬與調整，給使用者試玩。
