- 戰術狩獵的方向保留：難度提高了，但比較有趣、作業感下降，會想一直狩獵、想看其他動物的版本。

- 先改善資訊與辨識（2026-10-22 已修：撲咬機率與因素完整顯示、幼獸畫小一號、滑鼠停在鹿上寫出是哪一隻），不因為難就簡化核心玩法。
- 一次只調一個變數，才看得出是哪一項改善了體驗。

## 三、要決定的事

### 1. 先區分「能力不夠」和「還不熟」（Claude Code 建議先做）

在試玩紀錄裡多記幾項，下次試玩就看得出來，不改玩法：

- 每次撲咬時，畫面上的命中率，以及那一回合能選到的最高命中率（差很多 = 位置沒選好，是熟練度）；
- 交給本能的次數與結果；
- 每場戰術狩獵在哪一步結束（被發現、追不上、撲空、被甩開、被踢、自己放棄）。

如果未滿 1 歲時「能選到的最高命中率」本身就很低，是能力問題；如果常常比最高值低很多，是熟練度問題，用提示或教學解決比改數值好。

### 2. 未滿 1 歲太挫折（等第 1 項的數據再決定也可以）

生態：狼 8～10 個月還跟著家族，10～12 個月才開始參與大型獵物的狩獵，1～2 歲離群自立。遊戲 8 個月就獨自生活，本來就比真實難。

- **A. 改成從 1 歲開始（離群的年紀）**：挫折感大減、最貼近生態；代價是未滿 1 歲的內容（第一次獵到、1 歲卡片、幼年文案）要刪或改，能力起點往上調，成長弧線變短。
- **B. 維持 8 個月，給小狼「先吃小的」的路**：未滿 1 歲時雪兔、殘骸比較好找；追大鹿時提示「以你現在的體型很難」。保留從小長大的弧線；挫折感降多少要試玩。
- **C. 維持 8 個月，提高 1～2 歲的成長倍率**（ChatGPT 整理的方案 B）：數據不太支持——1～2 歲出手後已經 73%，而且它幫不到未滿 1 歲那一段；也會壓縮成年後的成長空間。

Claude Code 的建議：先做第 1 項的紀錄，同時做 B（改動小、可逆）；再試玩一輪，還是太挫折再考慮 A。

### 3. 一季的天數（目前 10 天）

加長一季（例如 15 天）＝一年多 50% 的行動，等於成長變快、整場變長（這次約 0.7 分鐘一天，9 年約 4 小時 → 約 6 小時），季節事件、動物數量、藏食物的新鮮天數都要重看。和第 2 項效果重疊。建議先不動。

### 4. 野牛的難度（2026-10-22 使用者決定：用 Claude Code 建議的數字）

使用者：有牛群在時，老弱的成牛或小牛對單狼本來就很難，一般的狼 10% 都合理；運氣好遇到落單的，成功率才提高。使用者先提了一組數字，Claude Code 對照生態後建議調低幾格，使用者採用調整後的版本：

| 情況 | 一般的狼 目標 | 快的狼 目標 | 現在（一般／快，最好的打法） |
| --- | --- | --- | --- |
| 牛群裡的小牛 | 10% | 20～25% | 58～63%／72～77%（太容易） |
| 牛群裡老弱的成牛 | 10% | 20～25% | 3～10%／15～27%（已經差不多） |
| 落單的小牛，旁邊沒有成牛 | 40% | 50% | 還沒有這種情況 |
| 落單的小牛，只有母牛在旁邊 | 25～30% | 35～40% | 還沒有這種情況 |
| 落單、受傷或老弱的成牛 | 15% | 20～25% | 單隻虛弱 3～18%／22～33%；受傷的個體目前走選單 |

調整的理由：

- 只有母牛在旁的小牛比完全落單的低：母野牛護幼很兇，比母鹿危險得多（原本 40%／50%）。
- 落單的受傷、老弱成牛降低（原本 受傷 25%／40%、老弱 30%／35%）：成年野牛 450～900 公斤，單狼即使對上受傷、老弱的也很難制伏；選單式老弱的目前是 1%／17%。一頭成年野牛是 6 段肉、飽食度 300（白尾鹿的近 4 倍），三成的機會是很大的「中獎」。
- 受傷和老弱用同一個目標：原本一般的狼打受傷的比老弱的難、快的狼卻相反，順序不一致。
- 快的狼只比一般的狼多約一成：野牛站定時速度幫不上忙，靠的是力量和技巧。

要補的規則（Claude Code 的假設，請確認）：

- **落單的野牛**：目前野牛一律成群。改成遇到野牛時約 20% 是落單的：一頭公牛（生態上公牛常獨行；健康的照樣站定，打不下來）、老弱的一頭、或一對母子（產仔季）。比例是初始值。
- **牛群護小牛更強**：小牛被追時往最近的成牛身邊跑（擠進牛群中間）；成牛擋在旁邊的減成加大。目標是牛群裡的小牛約一成。
- **受傷的野牛**：主遊戲裡受傷的個體（之前被咬傷逃掉的）改走戰術地圖，帶著傷（跑得慢）出場。

### 5. 更多動物進戰術地圖

依「打法有沒有不一樣」排序（Claude Code 的看法）：

1. **河狸**（使用者的構想）：地圖一定有水，分淺水、深水兩種地形。淺水：河狸稍快、狼稍慢，狼還是比較快；深水：河狸很快、狼很慢，追不上。河狸離水近或遠每場不同，要潛到牠和水之間、或趁牠離水遠時偷襲；咬住後幾乎甩不掉。現有規則只要多一種地形「深水」和河狸的地形代價。
2. **叉角羚**：最快的獵物，開闊地追不上，只能伏擊或找掉隊的幼羚。
3. **大角羊**：峭壁上很穩，狼上不去；要在牠下到草地時截住（沿用岩坡）。
4. **雪兔**：一天遇好幾次，進戰術地圖會拖慢節奏；建議維持選單式，或做成 2～3 回合的短版。

每種一個小步驟，各自校準到選單式的成功率。

## 四、建議的順序

1. 試玩紀錄加「能力 vs 熟練度」的指標（不改玩法）。
2. 野牛：落單的情況、牛群護小牛、受傷的走戰術地圖，校準到第 4 項的表（目標已決定，規則的假設待確認）。
3. 未滿 1 歲：方案 B（先吃小的）。
4. 試玩一輪，看指標與挫折感。
5. 河狸進戰術地圖（深水、淺水）。
6. 之後再看起始年齡、一季天數。
