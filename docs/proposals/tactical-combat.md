# 戰鬥的戰術場景（提案，2026-11-04）

使用者想把和灰熊、美洲獅、黑熊等動物的戰鬥，也做成像戰術狩獵那樣的場景。這份提案給 3 個方案，請使用者選（使用者會和 ChatGPT 一起討論，所以第一節先交代現況）。標【假設】的是 Claude Code 的推測，還沒驗證。

## 一、現況（給沒看過程式的人）

**戰鬥模式（選單式，Phase 1.6～1.9）**
- 對手：灰熊、黑熊、美洲獅、黑狼與鄰群的狼、苔原狼、狼獾、紅狐、郊狼、猞猁、牧場的獵犬。
- 兩個階段：
  - **對峙**：威嚇（嚇退／僵持／激怒）、試探（看出牠是堅定還是動搖）、先咬、退讓。
  - **交手**：咬、撲、閃、騷擾（耗對手體力）、撤退、讓出或放棄獵物、示弱。
- 每個選項顯示成功率和受傷風險。對手血量或體力低於門檻就放棄。「利害」影響對手多拚命：搶獵物、護幼時更晚放棄。
- Phase 1.9 把每回合做成動畫：先後、打中、打斷，速度快的常先咬到。
- 伴侶、子女、友善的苔原狼在戰鬥裡只是「機率幫咬一口」，不能指揮。

**戰術狩獵（格子地圖，Phase 2c～2i，已全面接進主遊戲）**
- 俯視格子地圖，地形會影響行動：密林、倒木、岩坡、河、峭壁、洞口。
- 有警覺值，靠視線、聲音、氣味累積。喘（短距離衝刺的本錢）和體力是兩種不同的消耗。
- 可以撲咬，咬住後選壓倒、咬喉、死咬拖住。
- **會站定的大型獵物**（公馬鹿、駝鹿、野牛）：面對你，每回合只轉 45°，正面 2 格內會撞你，從側面、後方撲才有機會。
- 同伴有角色：驅趕、追擊、埋伏，在地圖上各自行動。

**落差**
狩獵是讀地形、走位；戰鬥是選單。到了 Phase 3，戰鬥多了很多「好幾隻一起」的場面，現在都被壓成機率：狼群撞上鄰群、守巢、灰熊藏食、牧場獵犬。

## 二、生態依據（摘要，可信度同 `ecology-reference.md`）

- 狼對付熊、美洲獅：很少正面硬咬，主要是包圍、從後方咬後腿或臀部，熊一轉身就跳開，換另一隻上（**記述**，黃石的觀察）。單狼對成年灰熊幾乎沒有勝算（**記述**）。
- 灰熊：短距離衝刺很快，但轉身、追擊不持久；常常是虛張聲勢的衝撞（bluff charge），衝到一半停下（**記述**）。
- 美洲獅：伏擊者，被圍時會爬樹、背靠岩壁；不想為了一具屍體拚命（**記述**）。
- 黑熊：比灰熊膽小，常爬樹躲狼（**記述**）。
- 狼對狼：領域衝突是狼最主要的非人為死因之一；數量決定勝負，常常追上落單的那隻（**研究**，黃石）。

## 三、方案

### A. 站位與脫身（混合式）

**做法**：戰鬥開始時進入小型戰術地圖，大約 12×8 格，地形照當地。地圖上決定**站位**，交手的結果還是用現有的戰鬥規則算。

- 對手像「會站定的獵物」一樣面對你、會轉身；牠的正面是危險區（灰熊衝撞、美洲獅撲擊的範圍）。
- 你每回合移動，或在貼近時選現有的行動（咬、撲、騷擾、威嚇……），成功率加上位置的修正：側面、後方加成，正面減成。
- 撤退改成真的「跑出地圖邊緣」。樹、岩壁、河會擋路，也可以拿來脫身：美洲獅不下水，灰熊在密林裡轉身慢。
- 伴侶、子女照群獵的角色站位（騷擾、牽制），不再只是機率。

- **遊玩感受**：「繞到牠背後咬一口，牠轉過來就退」，和狩獵是同一套手感。
- **多了的決策**：要不要先退到有樹的地方再打？從哪一側上？什麼時候該跑、往哪裡跑？
- **失敗的樣子**：被逼到死角、正面被撞。事後說得出「我站錯位置」。
- **代價**：中等，約 1～1.5 週。站定獵物的轉身、正面危險區、地形、同伴角色都可以沿用；交手的機率規則不用重做，所以平衡風險低。
- **對其他系統**：所有戰鬥都會變長【假設：一場多 2～4 個操作】。小對手（狐狸、郊狼）可以維持選單式。
- **【假設】**：站位的修正約 ±15～25 個百分點，就足以讓走位有意義，又不會讓選單式的數值全部失效。

### B. 全戰術戰鬥

**做法**：拿掉選單式戰鬥，每回合在格子上「移動 + 動作」，所有規則重寫成戰術版：

- 動作有距離和方向：咬、撲、閃、騷擾。
- 每種對手有自己的 AI：
  - 灰熊：衝撞、揮掌，會虛張聲勢。
  - 美洲獅：撲擊、爬樹、背靠岩壁。
  - 黑熊：爬樹。
  - 狼：繞圈、包抄落單的。
- 血量、喘、體力都在地圖上即時顯示。

- **遊玩感受**：最有臨場感，最像一場真的打鬥；每種動物打起來都不一樣。
- **多了的決策**：同 A，再加上每一步的時機（牠揮掌後的空檔、衝撞後轉身慢）。
- **失敗的樣子**：最透明，每一下怎麼被打中都看得到。
- **代價**：最大，約 3～5 週。戰鬥的數值、勝率、所有回歸測試和一生模擬的基準都要重訂；Phase 1.9 的動畫演出大半用不到。
- **風險**：
  - 長戰鬥會拖，灰熊現在就十幾回合。
  - 自動玩家要重寫戰鬥 AI。
  - 容易出現「卡位就穩贏」這類漏洞。
  - 數值大改，前面校準好的壽命、餓死都可能跑掉。

### C. 只有群戰進戰術地圖

**做法**：一對一照舊用選單式（加上 Phase 1.9 的動畫）；**有好幾隻在場的衝突**才進戰術地圖：

- 狼群撞上鄰群、「撲上去打」：你們幾隻對牠們幾隻。
- 守巢：熊、美洲獅、郊狼靠近時，你和留守的伴侶擋在洞口。
- 狼群和熊搶屍體，就是灰熊藏食提案的 C：一起騷擾，把熊耗走。
- 牧場的獵犬：幾隻狗加上騎馬的人。

規則沿用群獵：同伴有角色，你操作自己；對手照 A 的方式站定、轉身、正面危險。

- **遊玩感受**：狼群的價值最明顯，「帶著家人包圍一頭熊」「兩群狼在邊界對峙」很有畫面。符合生態：狼對熊、狼對狼的勝負本來就看數量和包圍。
- **多了的決策**：帶誰去、誰牽制誰、什麼時候撤。
- **代價**：中高，約 2 週。要寫多個對手同時行動，這是 Phase 1.9 明確延後的「多隻對手同時行動的大型戰鬥」。
- **風險**：
  - 單狼的戰鬥體驗不變；如果使用者想要的是「我一隻狼和灰熊周旋」，C 沒有給。
  - 群戰的平衡和 Phase 3 鄰群、守巢的數值綁在一起，要重跑一生模擬。

## 四、比較

| | A 站位與脫身 | B 全戰術 | C 只有群戰 |
| --- | --- | --- | --- |
| 單狼對灰熊、美洲獅 | 有，重點是走位和脫身 | 有，最完整 | 沒有（照舊選單） |
| 狼群、守巢、鄰群 | 同伴有站位，但仍是一對一 | 有 | 有，重點 |
| 和狩獵的一致性 | 高 | 最高 | 群戰高、單挑不一致 |
| 工作量 | 1～1.5 週 | 3～5 週 | 約 2 週 |
| 平衡風險 | 低（交手規則不變） | 高（全部重訂） | 中（群戰相關的數值） |
| 可以分階段 | 可以，之後再加 C | 很難 | 可以，之後再加 A |

## 五、建議

**先做 A 的最小可玩版本，之後視試玩結果再加 C。** B 的好處大部分 A + C 都拿得到，代價和風險卻大得多。

最小可玩版本只做兩種對手：**灰熊和美洲獅**。牠們的打法差最多：灰熊正面衝撞、在密林轉身慢；美洲獅撲擊、會上樹或背靠岩壁。先在原型場景（同戰術狩獵原型的做法）試玩，成立了再接進主遊戲、擴充到黑熊、狼。

## 六、驗證（照設計支柱「新系統的檢驗問題」）

- **假設**：在戰鬥裡加上站位與地形，玩家會因為局勢不同而走不同的位置；勝率仍然由能力和判斷決定，而不是由「找到一個卡位點」決定。
- **驗證方式**：
  1. 原型場景，加上模擬的固定打法：一直正面打、一直繞後、先退到樹邊再打、開場就跑。每種 200 場以上，用不同能力的狼。
  2. 使用者試玩幾場灰熊、美洲獅。
- **通過標準【假設，待使用者確認】**：
  - 沒有一種固定打法在所有地形、所有對手都是最好的；至少有兩種打法各有最適合的情境。
  - 繞到側面、後方比一直正面打，勝率高 15～30 個百分點（有意義，但不是穩贏）。
  - 單狼對成年灰熊的勝率不超過現在的數字（生態上單狼幾乎贏不了），差別在於「跑得掉」的比例變高。
  - 一場戰鬥的操作次數：灰熊 8～15 次、美洲獅 5～10 次；有「交給本能」可以自動打完。
  - 玩家輸了說得出原因：站錯位置、跑錯方向、太貪。

## 七、要使用者決定的

1. 選 A、B 或 C（或 A 先做、之後加 C）。
2. 小對手（紅狐、郊狼、猞猁、狼獾）要不要也進戰術地圖，還是維持選單式？Claude Code 建議維持選單式，比較快。
3. 戰術戰鬥要不要有「交給本能」，一鍵自動打完（狩獵已經有）？
4. 被突襲的情境（美洲獅伏擊、灰熊藏食衝出來）：先挨一下再進地圖（和現在一樣），還是在地圖上開場、讓玩家有一回合反應？
