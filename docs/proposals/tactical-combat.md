# 戰鬥的戰術場景（提案，2026-11-04）

使用者想把和灰熊、美洲獅、黑熊等動物的戰鬥，也做成像戰術狩獵那樣的場景。這份提案給 4 個方案，請使用者選（使用者會和 ChatGPT 一起討論，所以第一節先交代現況）。A～C 是第一版；使用者看過後提出三個想要的情境（見「三之一」），Claude Code 補了方案 D，並整理各種戰鬥（一般遭遇、狼對狼、群戰）在 B 和 D 怎麼處理（見「三之三」）。標【假設】的是 Claude Code 的推測，還沒驗證。

## 一、現況（給沒看過程式的人）

**戰鬥模式（選單式，Phase 1.6～1.9）**
- 對手：灰熊、黑熊、美洲獅、黑狼與鄰群的狼、苔原狼、狼獾、紅狐、郊狼、猞猁、牧場的獵犬。
- 兩個階段：
  - **對峙**：威嚇（嚇退／僵持／激怒）、試探（看出牠是堅定還是動搖）、先咬、退讓。
  - **交手**：咬、撲、閃、騷擾（耗對手體力）、撤退、讓出或放棄獵物、示弱。
- 每個選項顯示成功率和受傷風險。對手血量或體力低於門檻就放棄。「利害」影響對手多拚命：搶獵物、護幼時更晚放棄。
- Phase 1.9 把每回合做成動畫：先後、打中、打斷，速度快的常先咬到。
- 伴侶、子女、友善的苔原狼在戰鬥裡只是「機率幫咬一口」，不能指揮。

**戰術狩獵（格子地圖，Phase 2c～2i，已全面接進主遊戲）**
- 俯視格子地圖，地形會影響行動：密林、倒木、岩坡、河、峭壁、洞口。
- 有警覺值，靠視線、聲音、氣味累積。喘（短距離衝刺的本錢）和體力是兩種不同的消耗。
- 可以撲咬，咬住後選壓倒、咬喉、死咬拖住。
- **會站定的大型獵物**（公馬鹿、駝鹿、野牛）：面對你，每回合只轉 45°，正面 2 格內會撞你，從側面、後方撲才有機會。
- 同伴有角色：驅趕、追擊、埋伏，在地圖上各自行動。

**落差**
狩獵是讀地形、走位；戰鬥是選單。到了 Phase 3，戰鬥多了很多「好幾隻一起」的場面，現在都被壓成機率：狼群撞上鄰群、守巢、灰熊藏食、牧場獵犬。

## 二、生態依據（摘要，可信度同 `ecology-reference.md`）

- 狼對付熊、美洲獅：很少正面硬咬，主要是包圍、從後方咬後腿或臀部，熊一轉身就跳開，換另一隻上（**記述**，黃石的觀察）。單狼對成年灰熊幾乎沒有勝算（**記述**）。
- 灰熊：短距離衝刺很快，但轉身、追擊不持久；常常是虛張聲勢的衝撞（bluff charge），衝到一半停下（**記述**）。
- 美洲獅：伏擊者，被圍時會爬樹、背靠岩壁；不想為了一具屍體拚命（**記述**）。
- 黑熊：比灰熊膽小，常爬樹躲狼（**記述**）。
- 狼對狼：領域衝突是狼最主要的非人為死因之一；數量決定勝負，常常追上落單的那隻（**研究**，黃石）。一對一時多半是對峙、姿勢威嚇，真的打起來是咬頸、咬腿、壓制；一方示弱或逃跑就結束（**記述**）。
- 爬樹：美洲獅被狼群或獵犬追時會爬樹，追的一方守在樹下，有時等不到就離開（**記述**；獵人用獵犬「把美洲獅追上樹」是常見做法）。黑熊也常爬樹躲狼（**記述**）。**成年灰熊幾乎不爬樹**，被圍時背靠岩壁、站定反擊（**記述**）。
- 搶食：灰熊在殘骸旁「幾乎總是贏」；狼群會輪流騷擾、趁熊轉身時咬一塊（**記述**，`ecology-reference.md` 灰熊一節）。

## 三、方案

### 三之一、使用者想要的情境（2026-11-04）

1. **搶食**：對方站在食物上時，可以繞著牠找機會攻擊，或伺機搶肉；有狼群時，其他狼也能做一樣的事。對方來搶時，可以選擇攻擊、守在食物旁、稍微退開看牠的反應，或咬一塊就撤。
2. **圍剿與地形**：美洲獅或灰熊被圍時會利用地形，例如爬上大石頭或大樹。美洲獅爬上樹後，樹的大小決定牠能待多久；狼群可以圍著樹（耗時間和體力），樹小的話牠可能掉下來，就有機會攻擊，但也可能等很久等不到。
3. **角度與動作**：繞著對手，從不同角度用不同的動作攻擊或閃避，像戰術狩獵一樣顯示機率。


### A. 站位與脫身（混合式）

**做法**：戰鬥開始時進入小型戰術地圖，大約 12×8 格，地形照當地。地圖上決定**站位**，交手的結果還是用現有的戰鬥規則算。

- 對手像「會站定的獵物」一樣面對你、會轉身；牠的正面是危險區（灰熊衝撞、美洲獅撲擊的範圍）。
- 你每回合移動，或在貼近時選現有的行動（咬、撲、騷擾、威嚇……），成功率加上位置的修正：側面、後方加成，正面減成。
- 撤退改成真的「跑出地圖邊緣」。樹、岩壁、河會擋路，也可以拿來脫身：美洲獅不下水，灰熊在密林裡轉身慢。
- 伴侶、子女照群獵的角色站位（騷擾、牽制），不再只是機率。

- **遊玩感受**：「繞到牠背後咬一口，牠轉過來就退」，和狩獵是同一套手感。
- **多了的決策**：要不要先退到有樹的地方再打？從哪一側上？什麼時候該跑、往哪裡跑？
- **失敗的樣子**：被逼到死角、正面被撞。事後說得出「我站錯位置」。
- **代價**：中等，約 1～1.5 週。站定獵物的轉身、正面危險區、地形、同伴角色都可以沿用；交手的機率規則不用重做，所以平衡風險低。
- **對其他系統**：所有戰鬥都會變長【假設：一場多 2～4 個操作】。小對手（狐狸、郊狼）可以維持選單式。
- **【假設】**：站位的修正約 ±15～25 個百分點，就足以讓走位有意義，又不會讓選單式的數值全部失效。

### B. 全戰術戰鬥

**做法**：拿掉選單式戰鬥，每回合在格子上「移動 + 動作」，所有規則重寫成戰術版：

- 動作有距離和方向：咬、撲、閃、騷擾。
- 每種對手有自己的 AI：
  - 灰熊：衝撞、揮掌，會虛張聲勢。
  - 美洲獅：撲擊、爬樹、背靠岩壁。
  - 黑熊：爬樹。
  - 狼：繞圈、包抄落單的。
- 血量、喘、體力都在地圖上即時顯示。

- **遊玩感受**：最有臨場感，最像一場真的打鬥；每種動物打起來都不一樣。
- **多了的決策**：同 A，再加上每一步的時機（牠揮掌後的空檔、衝撞後轉身慢）。
- **失敗的樣子**：最透明，每一下怎麼被打中都看得到。
- **代價**：最大，約 3～5 週。戰鬥的數值、勝率、所有回歸測試和一生模擬的基準都要重訂；Phase 1.9 的動畫演出大半用不到。
- **風險**：
  - 長戰鬥會拖，灰熊現在就十幾回合。
  - 自動玩家要重寫戰鬥 AI。
  - 容易出現「卡位就穩贏」這類漏洞。
  - 數值大改，前面校準好的壽命、餓死都可能跑掉。

### C. 只有群戰進戰術地圖

**做法**：一對一照舊用選單式（加上 Phase 1.9 的動畫）；**有好幾隻在場的衝突**才進戰術地圖：

- 狼群撞上鄰群、「撲上去打」：你們幾隻對牠們幾隻。
- 守巢：熊、美洲獅、郊狼靠近時，你和留守的伴侶擋在洞口。
- 狼群和熊搶屍體，就是灰熊藏食提案的 C：一起騷擾，把熊耗走。
- 牧場的獵犬：幾隻狗加上騎馬的人。

規則沿用群獵：同伴有角色，你操作自己；對手照 A 的方式站定、轉身、正面危險。

- **遊玩感受**：狼群的價值最明顯，「帶著家人包圍一頭熊」「兩群狼在邊界對峙」很有畫面。符合生態：狼對熊、狼對狼的勝負本來就看數量和包圍。
- **多了的決策**：帶誰去、誰牽制誰、什麼時候撤。
- **代價**：中高，約 2 週。要寫多個對手同時行動，這是 Phase 1.9 明確延後的「多隻對手同時行動的大型戰鬥」。
- **風險**：
  - 單狼的戰鬥體驗不變；如果使用者想要的是「我一隻狼和灰熊周旋」，C 沒有給。
  - 群戰的平衡和 Phase 3 鄰群、守巢的數值綁在一起，要重跑一生模擬。

### D. 一對一走位 → 群戰與地形，分兩階段（2026-11-04 補，對應「三之一」）

A 和 C 合起來，再補上「地圖上的食物」和「對手會利用地形」。**交手的機率規則（咬、撲、騷擾的成功率、受傷）沿用現在的戰鬥模式**，地圖決定的是位置、角度、距離、地形帶來的加減成與能做的動作。

**第一階段：一對一**
- 戰鬥在戰術地圖上進行，地形照當地。對手有面向、會轉身；正面是危險區，側面、後方比較有機會。每個動作的按鈕顯示機率和因素（同戰術狩獵）。
- 對手的轉身速度依物種：灰熊、駝鹿類大型動物轉得慢，美洲獅、狼轉得快（所以單挑同類時，角度的優勢比較小，要靠時機和地形）【假設】。
- **地圖上的食物（殘骸）**：
  - 對方守著時：繞過去攻擊，或趁牠面向別處時「叼一塊」（現在「咬一塊就跑／整個叼走」的地圖版）。
  - 對方來搶時：攻擊、守在食物旁（牠要先過你這關）、退開幾格觀望（牠可能只吃一點就走，也可能整個佔住）、咬一塊撤退。
- **撤退**是真的跑出地圖邊緣；樹、岩石、河會擋路，也可以拿來脫身（美洲獅不下水、灰熊在密林轉身慢）【假設】。
- **狼跳上大石頭**：可以避開一兩回合的攻擊，但熊、美洲獅也上得去，不能一直躲【假設】。
- 先做灰熊、美洲獅，接著黑熊、狼（黑狼、年輕的挑戰者、鄰群帶頭的公狼、苔原狼）。

**第二階段：群戰與地形避難**
- 伴侶、子女、友善的苔原狼在地圖上照群獵的角色行動：繞到另一側牽制、趁對手轉身時叼肉、包抄、保護落單的。
- 多隻對手同時行動：鄰群、獵犬、帶著幼熊的母熊。
- **避難處**：樹和岩石有大小。
  - 美洲獅、黑熊會爬上撐得住牠的樹；灰熊不爬樹，改成背靠岩壁、站定。
  - 樹越小，牠待得越短，也越可能掉下來或跳下來逃。
  - 狼群可以「圍住」：每回合耗時間和體力，有機會等到牠下來（攻擊或趕走），也可能白等；也可以放棄，帶走食物就好。
- 守巢：你和留守的狼擋在洞口，幼狼在洞裡。

- **遊玩感受**：一對一時是「繞到背後咬一口、牠轉過來就退」「趁熊轉身叼一塊」；狼群時是「誰牽制、誰叼肉、要不要圍著樹等」。
- **多了的決策**：從哪個角度上、什麼時候叼了就跑、退開觀望還是守著、要不要花時間圍樹、帶誰去。
- **失敗的樣子**：被逼到死角、正面被撞、圍樹圍到天黑一無所獲、為了一塊肉讓子女受傷。事後說得出原因。
- **代價**：第一階段約 1.5～2 週，第二階段約 2 週；合起來接近 B。
- **和 B 的差別**：交手的機率沿用現在的規則，前面校準好的勝率、壽命不太會跑掉；每一階段做完都能試玩，不好玩可以早點停。
- **風險**：
  - 規則有兩層（地圖的位置＋原本的交手機率），要讓按鈕上的因素寫得清楚，不然玩家看不懂機率從哪來。
  - 第二階段的群戰和 Phase 3 的鄰群、守巢數值綁在一起，要重跑一生模擬。

## 五、建議

**（2026-11-04 更新）建議 D。** 使用者想要的三個情境 D 都做得到；B 也做得到，多出來的是「每個動作依角度不同、對手的每一步都要讀」，代價是交手規則全部重寫、前面校準好的勝率和壽命要重訂，而且很難分階段試玩。D 的第一階段做完就能判斷「戰鬥進地圖」好不好玩，不好玩可以停在那裡；好玩但覺得動作太少，再往 B 的方向加動作。

第一階段的最小可玩版本只做兩種對手：**灰熊和美洲獅**（打法差最多），加上**搶食**（食物在地圖上）。先在原型場景（同戰術狩獵原型的做法）試玩，成立了再接進主遊戲、擴充到黑熊、狼，再做第二階段。

（第一版的建議是「先做 A，之後加 C」；D 就是這個建議加上使用者的三個情境。）

## 六、驗證（照設計支柱「新系統的檢驗問題」）

- **假設**：在戰鬥裡加上站位與地形，玩家會因為局勢不同而走不同的位置；勝率仍然由能力和判斷決定，而不是由「找到一個卡位點」決定。
- **驗證方式**：
  1. 原型場景，加上模擬的固定打法：一直正面打、一直繞後、先退到樹邊再打、開場就跑。每種 200 場以上，用不同能力的狼。
  2. 使用者試玩幾場灰熊、美洲獅。
- **通過標準【假設，待使用者確認】**：
  - 沒有一種固定打法在所有地形、所有對手都是最好的；至少有兩種打法各有最適合的情境。
  - 繞到側面、後方比一直正面打，勝率高 15～30 個百分點（有意義，但不是穩贏）。
  - 單狼對成年灰熊的勝率不超過現在的數字（生態上單狼幾乎贏不了），差別在於「跑得掉」的比例變高。
  - 一場戰鬥的操作次數：灰熊 8～15 次、美洲獅 5～10 次；有「交給本能」可以自動打完。
  - 玩家輸了說得出原因：站錯位置、跑錯方向、太貪。

## 七、要使用者決定的

1. 選 A、B、C 或 D。
2. 小對手（紅狐、郊狼、猞猁、狼獾）要不要也進戰術地圖，還是維持選單式？Claude Code 建議維持選單式，比較快。
3. 戰術戰鬥要不要有「交給本能」，一鍵自動打完（狩獵已經有）？
4. 被突襲的情境（美洲獅伏擊、灰熊藏食衝出來）：先挨一下再進地圖（和現在一樣），還是在地圖上開場、讓玩家有一回合反應？
5. （D）狼對狼一對一要不要進地圖，還是第一階段只做熊、美洲獅，狼等第二階段和群戰一起？
6. （D 第二階段）圍樹的上限：狼群最多圍多久（例如一個時段）就自動放棄，避免玩家無限等？
