# 提案：苔原狼一起狩獵接進主遊戲的戰術地圖

2026-10-24 Claude Code 整理，第 1 版。依據：使用者選 B（2026-10-24）「把 K4 的戰術版本接進主遊戲」。原型與校準見 `tundra-joint-tactical.md`、`pack-hunt-difficulty-data.md`（方案 2、B 之後的數字）。使用者選定之前不寫規格、不實作。

## 一、現況

- 主遊戲的苔原狼一起狩獵是 1.8 第 9 步的**選單式**：
  - 探索時撞見「苔原狼在狩獵」（熟悉以上），選「加入」→ 選單式狩獵，幫忙是改條件（鹿群：替你試探、逼出弱者；駝鹿：牽制、反擊減少）。
  - 關係友善時，你自己出手獵牠們會獵的動物，每次 30% 牠們「跟上來」幫忙。
- 不一致（Phase 2c、2d 之後就有）：
  1. 自動玩家、照常過日子選「加入」時走戰術地圖，但戰術地圖不讀苔原狼的幫忙，等於自己獵。
  2. 「跟上來」的 30%，如果獵物是鹿類（走戰術地圖），幫忙沒有作用。
- 原型（K4）已經有：同伴的兩種角色（驅趕、追擊）、獵物對多隻狼的反應（往遠離狼群的方向跑、被趕往你這邊時伏擊 +25%）、互相圍攻（牠們咬住你可以撲上去、你咬住牠們會圍過來）、死咬拖住時牠們試著扭倒、一起咬著時省喘、護幼與鹿群防衛也對牠們、`pack_help`（野牛、駝鹿難收尾）、`chase_help`（鹿類 × 0.4）。這些都在 `TacticalHunt` 裡，主遊戲沒有用到。

## 二、要決定的：苔原狼什麼時候出現在戰術地圖上

| | A. 只接「加入」 | B. 「加入」與「跟上來」都接（建議） | C. B ＋ 簡單指令 |
| --- | --- | --- | --- |
| 撞見苔原狼在狩獵、選加入 | 戰術地圖：獵物已經在逃、苔原狼在追（開局就是追擊階段） | 同 A | 同 A |
| 友善時跟上來（30%） | 維持選單式的加成；鹿類走戰術地圖時沒有幫忙（不一致 2 留著） | 戰術地圖：一般開局，苔原狼幾個回合後從你身後出現，角色自動分（驅趕／追擊） | 同 B |
| 你能做的 | 照原型：配合牠們的位置（等驅趕、牠們咬住時撲上去、死咬拖住讓牠們扭倒） | 同 A | 多兩個按鈕「等等」「趕」：叫驅趕的那隻先別衝、或現在就衝 |
| 遊玩感受 | 只有撞見時才有群獵；平常還是獨狼 | 和苔原狼關係好之後，平常的狩獵偶爾會多兩個幫手，關係的價值看得到 | 比較能照自己的步調，但多一層操作；原型沒有試過 |
| 代價 | 約 3 步 | 約 4 步 | 約 5 步，指令要先在原型試 |
| 對其他系統 | 苔原的食物變多一點 | 同 A，再多一點（友善的苔原狼很少：要經過熟悉才會友善） | 同 B |

兩種情況都修掉不一致 1（自動玩家、照常過日子加入時也有苔原狼）。

## 三、各方案共通的規則（Claude Code 的假設，標【假設】的可以改）

- **哪些獵物**：照現在「苔原狼會獵」的清單（`balance.npc_wolves.tundra_wolf.interaction.joint.prey`：馴鹿、駝鹿，兩種都已經走戰術地圖）；幼體照現在的規則（跟上來不算幼體）。
- **幾隻上場**：【假設】最多 2 隻（原型只校準過 2 隻；苔原狼群最多 10 隻，多的「在附近」不上場）。只有 1 隻成狼時就 1 隻。
- **角色**：【假設】第一隻追擊、第二隻驅趕（原型 K～N 的設定）；加入時兩隻都從追擊開始（牠們本來就在追）。
- **難度**：照原型方案 2、B 的數值，不再加成（有同伴大約多 10～30 個百分點；野牛、健康駝鹿仍然很難）。選單式原本的苔原狼加成在戰術地圖上不用。
- **分肉**：照現在的規則（一起獵到 = 和苔原狼分著吃，`shared`）；牠們撲倒、扭倒算一起獵到。
- **苔原狼會不會受傷**：【假設】不會（原型的簡化）；被母鹿、野牛趕開照原型。
- **關係**：一起獵到照現在的紀錄（`_tundra_record`），關係變化不變。
- **交給本能、自動玩家、照常過日子**：用原型已經有的本能（等驅趕、撲向被咬住的獵物、該死咬拖住時拖住）。
- **畫面**：原型的同伴圖、角色點（藍驅趕、橘追擊）、虛線、右下角的同伴狀態照搬；開場一行說明（「兩隻苔原狼已經在追了」／「身後傳來腳步聲，那兩隻苔原狼跟上來了」）。

## 四、驗證方式與通過標準

| 項目 | 方式 | 標準（初始值） |
| --- | --- | --- |
| 主遊戲的開法和原型一致 | `tactical_ally_sim`、`tactical_ally_matrix` 改用主遊戲的開法（`GameState.start_tactical`）重跑 | 和原型方案 B 之後的數字差 5 個百分點以內 |
| 苔原的一生不會變太容易 | `life_pressure DENS_ONLY=tundra_south`（有、沒有這個改動對照） | 成年每年挨餓下降不超過約 1 天；苔原的食物裡馴鹿的比例變化記下來 |
| 自動玩家加入時真的有苔原狼 | 回歸測試 | 加入 → 戰術地圖上有 1～2 隻同伴；跟上來（B）→ 幾個回合後出現 |
| 試玩 | 試玩清單 | 看得懂牠們在做什麼、不會覺得被牠們搶走主導權、操作量不超過單狼 1.5 倍 |

## 五、實作順序（以 B 為例，約 4 步）

1. 主遊戲開場：`start_tactical` 帶苔原狼（加入：開局追擊；跟上來：幾回合後出現）、上場隻數、開場說明、結算（一起獵到、分肉、紀錄）；修不一致 1、2。
2. 畫面與本能：主遊戲的戰術畫面顯示同伴（原型的畫法）；交給本能、自動玩家、照常過日子。
3. 模擬與校準：主遊戲開法的 `tactical_ally_sim`／`matrix`、苔原巢穴的一生模擬。
4. 回歸測試、事件結局矩陣、試玩清單。

1. A／B／C（建議 B）。
