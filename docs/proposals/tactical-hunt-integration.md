# 提案：戰術狩獵接進主遊戲（2026-10-20）

使用者試玩戰術狩獵原型（`prototypes/tactical_hunt/`）覺得不錯，選「A 接進主遊戲 ＋ B 先對齊成功率」。這份是 A 的提案：列出會影響玩法、要使用者選的規則，選定後才寫 SPEC。標【假設】的是 Claude Code 的推測。B 的結果在第七節。

## 一、目標

- 中大型獵物的狩獵，從現在的選單（觀察 → 潛近 → 追擊 → 撲咬 → 制伏）換成戰術地圖：讀風向、地形、鹿的動向，自己決定何時潛近、何時衝、從哪個角度撲。
- 核心樂趣「讀懂自然、預判獵物」從選單上的機率，變成看得到的局面。
- Phase 2b 的規則（試探與放棄、體況、年齡、吃撐、晨昏、成功率目標）照樣成立。

**假設**：在主遊戲裡用戰術地圖狩獵，玩家會更常改變打法（看風向、地形挑時機），而且每次出獵的時間仍可以接受。

**驗證方式**：
- 模擬：戰術狩獵的自動玩家代替選單式狩獵，一生模擬的挨餓、壽命、黑狼勝率維持在 Phase 2b 的範圍。
- 試玩：一場的回合數、真實花費的時間、放棄的比例、打法的分布（試玩紀錄）。

**通過標準（初始值）**：
- 一場 6～15 個戰術回合，玩家平均不超過 1～2 分鐘；
- 成功率對齊 Phase 2b（第七節）；
- 一生模擬的挨餓、壽命不超出 Phase 2b 第 5 步的結果 ±20%。

## 二、要你決定的規則

### 決定 1：什麼時候進戰術地圖

| 方案 | 內容 | 遊玩感受 | 代價 |
| --- | --- | --- | --- |
| A | 中大型獵物一律進戰術地圖 | 每次都要操作，最有「狩獵」的感覺 | 一生要打上百場，可能變成作業；快轉、照常過日子要另外處理 |
| **B（建議）** | 進戰術地圖，但多一個「交給本能」按鈕：用同一套規則，由自動玩家幫你打完，直接給結果 | 想操作的時候操作，不想的時候快轉，結果仍照同一套規則 | 自動玩家的打法要夠合理（模擬裡已有：潛近截角、伏擊、耐力追），而且比玩家自己打略差，才有操作的理由 |
| C | 保留現在的選單式狩獵當「快速狩獵」，戰術地圖是另一個選項 | 兩種都能選 | 兩套規則要分別平衡，成功率容易對不上 |

【假設】B 的「交給本能」成功率比玩家自己打低一點（約一成），玩家才有理由自己打。

### 決定 2：試探與放棄怎麼呈現

Phase 2b 要求「看出不是弱者就放棄」被理解成聰明的判斷。

| 方案 | 內容 | 代價 |
| --- | --- | --- |
| **A（建議）** | 沿用原型：「觀察」花一回合看出體況、縮小意圖範圍；「放棄」隨時可以按；放棄時寫出依據（沿用 Phase 2b 的 `hunt.give_up.*`） | 試探就是「靠近、讓牠跑幾步、看牠的步伐」，在地圖上自然發生 |
| B | 進地圖前先在選單試探一次（沿用現在的「試探」），再決定要不要進地圖 | 多一層選單，但可以先過濾掉不值得打的 |

### 決定 3：戰術地圖從哪裡來

| 方案 | 內容 | 代價 |
| --- | --- | --- |
| **A（建議）** | 每種地形（密林、林緣、開闊地、溪邊、倒木）手工做 2～3 張地圖，依遇到獵物的地形挑一張，起始位置與目的地隨機；風向沿用主遊戲 | 要做十幾張地圖，但每張都能控制好玩不好玩 |
| B | 程式依區域的地形比例隨機產生 | 變化最多，但可能產生不好玩的地圖 |

### 決定 4：先接哪些獵物

- **建議**：先接白尾鹿（原型已經有），試玩確認後依序加馬鹿（原型已有）、騾鹿、馴鹿（和白尾鹿相近，改數值即可）。
- 駝鹿、野牛會站著反擊，需要新規則；先維持選單式狩獵，另外提案。
- 小獵物（雪兔、河狸）維持快速流程（原型規格就這樣定）。

## 三、照現有規則對應（不需要決定，列出來讓你看）

| 主遊戲的規則 | 在戰術地圖裡 |
| --- | --- |
| 能力值（速度、技巧、力量、感知） | 直接用狼的能力值（原型的「普通」「快」只是測試用的設定） |
| 喘（爆發）與體力 | 喘的上限沿用 `burst`；吃撐時喘的上限 ×0.6、不能衝刺（Phase 2b 第 1 步） |
| 體況（健康、普通、虛弱） | 沿用主遊戲擲出的體況（Phase 2b 的比例）；第七節的加減 |
| 年齡（5 歲起） | 撲咬、壓倒、咬喉扣年齡減成（Phase 2b 第 3、5 步） |
| 晨昏 | 清晨、黃昏時鹿的警覺值漲得比較慢（等同潛近 +5%） |
| 雪況 | 深雪時鹿的逃跑格數 −1，狼不變（對應現在雪況對追擊的加成） |
| 時間 | 戰術回合 ÷ 5，進位，1～3 個遊戲回合（原型規格已定） |
| 體力 | 2 ＋ 用掉的喘 × 0.08，上限 18（原型規格已定） |
| 結果 | 獵到：殘骸照現在的段數；被踢：照原型的傷害，記成受傷；成長：照現在的「狩獵中的鍛鍊點」（每次衝刺、撲咬、壓倒算一步） |

## 四、實作順序（初估）

1. 把原型的邏輯（`TacticalHunt.gd`）搬到 `scripts/core/`，改成讀狼的能力值與主遊戲的狀態（體況、吃撐、晨昏、雪況、年齡），原型畫面照樣能用。
2. 主遊戲遇到白尾鹿時進戰術地圖；結果接回殘骸、受傷、成長、時間與體力。
3. 「交給本能」與自動玩家（照常過日子、一生模擬）。
4. 每種地形的地圖。
5. 一生模擬與試玩，對照通過標準。
6. 馬鹿、騾鹿、馴鹿。

## 五、不做的（這次）

- 駝鹿、野牛的戰術版（站著反擊）。
- 鹿群的長時間騷擾、「足跡帶著疲勞再追」。
- 戰鬥（灰熊、黑狼）的戰術版。

## 六、待補

- 戰術地圖的正式美術（目前是俯視色塊）。
- 畫面要能在主遊戲裡開關（目前是獨立場景）。

## 七、B：對齊 Phase 2b 的成功率（2026-10-20）

模擬：`bash tools/run_sim.sh tactical_calibrate 0 100`（單隻白尾鹿、情境 A～D，固定鹿的體況，四種策略：猛追／耐力追／潛近截角／伏擊，取每個情境最好的策略再平均；普通的狼 ≈ 主遊戲一般成年，快的狼 ≈ 強狼）。

**原因**：分階段統計發現，太簡單主要是因為健康的鹿逃到第 4 回合後格數就掉下來，狼小跑跟著也追得上，可以一直重撲；咬住之後鹿的體況幾乎沒有影響。

**調整**（`tuning.json` 的 `deer.flee_profile`、`deer.condition_mods`，照 Phase 2b「追擊看速度與獵物狀況、制伏看力量」）：
- 健康的成鹿：逃跑格數 3、6、6、5、4、3（原本 3、6、6、3、2），逃 5 回合才累到底（原本 3）；撲咬 −0.15、壓倒 −0.15、咬喉 −0.08、掙脫 +0.25。
- 普通：3、6、6、4、3、2，4 回合累到底；撲咬 −0.05、掙脫 +0.08。
- 虛弱：3、5、5、3、3（原本最後兩回合 2），4 回合累到底。
- 幼鹿不套用（鹿群版的幼鹿規則照舊）。看出體況之後，撲咬與咬住的機率旁會寫「牠很健康／牠很虛弱」。

| 最好策略的平均 | 調整前 | 調整後 | 目標 |
| --- | --- | --- | --- |
| 普通的狼 × 健康 | 67% | 32% | 25～35% |
| 普通的狼 × 普通 | 76% | 53% | — |
| 普通的狼 × 虛弱 | 91% | 79% | 50～80% |
| 快的狼 × 健康 | 88% | 54% | 45～55% |
| 快的狼 × 普通 | 89% | 79% | — |
| 快的狼 × 虛弱 | 94% | 92% | 50～80%（偏高） |

- 打法的差異還在：開闊地上風（情境 B）最難（普通的狼最多 4%），開闊地下風潛近截角最好，林緣、倒木旁伏擊或潛近都可以；快的狼在上風時猛追比潛近好。
- 快的狼對虛弱的鹿 92%：強狼抓虛弱的獵物本來就很準（選單式狩獵巔峰時是 79～90%），先不壓。
- 這是「最好的策略」；真人玩家的平均會低一些，接進主遊戲後用試玩紀錄對照。

## 八、使用者的決定（2026-10-20）

照建議：決定 1 選 B（戰術地圖＋「交給本能」）、決定 2 選 A（地圖上觀察與放棄）、決定 3 選 A（每種地形手工 2～3 張地圖）、決定 4 先接白尾鹿。

- 晨昏：清晨、黃昏鹿的警覺值漲得比較慢（等同潛近 +5%）。
- 雪況：深雪時鹿的逃跑格數 −1。
- 時間：戰術回合 ÷ 5，進位，1～3 個遊戲回合。
- 體力：2 ＋ 用掉的喘 × 0.08，上限 18。
- 結果：獵到 → 殘骸照現在的段數；被踢 → 受傷；成長 → 每次衝刺、撲咬、壓倒、咬喉算一步鍛鍊。
