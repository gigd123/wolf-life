# 評估：動態人類聚落與棲地變化（規劃用）

2026-10-22 Claude Code 整理。依據：使用者的提案〈動態人類聚落與棲地變化系統〉（2026-10-22）、`DESIGN.md`「時代背景」「人類系統（Phase 4）」、現有程式。目前只做規劃，不改規格、不實作。

## 一、和 DESIGN.md 的關係

- DESIGN 已經把人類放在 Phase 4：一套共用的「人類活動度 × 可達性」決定遇到獵人、陷阱、毒餌的風險；惡名昭彰的狼；很難達成的牧場撤離結局。
- **衝突一處**：DESIGN 的牧場是固定存在的第五張地圖（森林與草原之間，有移動時間表）；新提案是「狼 2～3 歲時、在不同的合適位置逐漸出現」。兩者要選一個（見第四節問題 1）。
- DESIGN 要求：人類的規則在實作前先查拓荒時代的資料（陷阱、毒餌、懸賞、獵狼人的季節與範圍），整理進 `ecology-reference.md`；苔原、北方森林是原住民與毛皮貿易者的範圍，要謹慎處理或不描寫。新提案和這兩點相容。

## 三、第一階段最小可行版本（建議範圍）

1. **牧場出現**：狼 2～3 歲時，換季擲一次（不是每局都有，例如 70%）；位置從候選區域裡挑（森林南部、草原丘陵、草原河岸林這類開闊又接近森林的；不選巢穴所在區、也不選你唯一熟悉的區域——確保還有地方去）。
2. **漸進**：出現後第一季只有線索（柵欄、牛的氣味、遠處的炊煙）；之後那一區有家畜可以獵。
3. **家畜**：很好獵（例如牛犢、羊），但每獵一次那一區的「注意」+1。
4. **人類的反應**：注意累積到門檻 → 接下來幾天那一區與相鄰區有獵犬、帶槍的人巡查（新的危險遭遇：逃、躲；被發現可能受傷或死），之後慢慢回落。
5. **地圖的差異**：可達性——山地低、苔原很低、森林與草原高；巡查只延伸到可達的區域。
6. **模擬**：一生模擬看各地圖停留比例、搬遷次數、被人類殺死的比例，事件前後比較。

不做：村落、陷阱與毒餌的種類、懸賞與惡名、牧場撤離、人類 AI。

## 四、要使用者決定的設計問題

1. 牧場是**新的一張地圖**（DESIGN 原本的設定，有自己的區域與移動時間）還是**疊在現有區域上**（某個區域變成「有牧場」，提案的做法）？我的看法：疊在現有區域上比較符合「熟悉的地方變了」，成本也低；但 DESIGN 要跟著改。
2. 第一版人類能不能**殺死**玩家？（DESIGN 的死因有「被人類獵殺」）。可以的話，要不要像灰熊一樣有明確的預警與逃走機會。
3. 牧場是不是**每局都會出現**？出現機率與時間窗口（2～3 歲）是否固定。
4. 家畜要**多容易、肉多少**：太容易會變成「去牧場吃飯」；太難就沒有誘惑。
5. 先查資料：拓荒時代的牧場、獵犬、獵狼人在季節與地區上的分布（DESIGN 要求先查證）。我可以先整理一份資料給你看。

## 五、和其他系統的先後關係

- **先後**：鮭魚洄流（季節性生態）→ 試玩回饋 → 人類第一階段（牧場）→ 陷阱、獵人、惡名（第二階段）→ 村落（第三階段）。
- 和狼群（Phase 3 正式版）：人類壓力會影響狼群領域，但第一階段只需要「區域的人類活動度」，不需要狼群。等狼群做好再接「狼群避開人類」。
- 和戰術狩獵：家畜可以先走選單式（很容易，沒有戰術的意義）；被巡查時的「躲」也先用選單。

## 六、成本與風險

- 成本：第一階段約 5～6 步，加上資料查證與一批新圖；比鮭魚洄流大。
- 風險：
  - 平衡：人類出現讓某些巢穴區變成不能住，一生模擬的挨餓與死亡會明顯變動，要重調。
  - 公平：要保證出現時你還有地方去（候選區域的條件）。
  - 題材：拓荒時代的獵狼與毒餌很殘酷，文案要照 `writing-guide.md` 拿捏；原住民的呈現依 DESIGN 謹慎處理。
