# 灰熊藏的獵物（提案，2026-11-04）

起因：10-30 試玩回饋 (6)「偷吃別的動物藏起來的獵物時，沒寫是誰藏的」。改文案時發現遊戲裡只有美洲獅會藏獵物；現實中灰熊也會。使用者要方案選擇。

## 生態（Claude Code 整理，待查證來源後補進 `ecology-reference.md`）

- 灰熊會把大型屍體（自己獵到、搶來或冬天凍死的）用土、枝葉、草蓋成一堆，分好幾天吃。**推論／常見記述**
- 牠常常就睡在附近，有時直接趴在土堆上，對靠近的動物很兇。北美人類被灰熊攻擊的情境裡，「撞上守著屍體的熊」是常見的一種。**記述**
- 春天最常見：剛出洞的熊很餓，冬天凍死的鹿、駝鹿、野牛多。秋天也有。**推論**
- 狼會趁熊不在時去吃，但在殘骸旁「灰熊幾乎總是贏」（`ecology-reference.md` 灰熊一節）。渡鴉、喜鵲常聚在附近，熊在的時候牠們比較不敢落地。**記述／推論**

## 和現有系統的關係

- 美洲獅藏食：探索時 `cache_chance` 發現 → 偷吃或離開；吃的時候每段 `return_chance` 25% 美洲獅回來（遭遇）。
- 灰熊搶食：你在吃東西時灰熊來搶（已有）；單狼幾乎搶不贏。
- 守巢的威脅、灰熊遠距目擊、灰熊路過：已有，不受影響。

## 方案

### A. 灰熊版的藏食（和美洲獅一樣）

發現 → 偷吃或離開；吃的時候熊可能回來，接到現有的「灰熊搶食」事件。

- 遊玩感受：多一種不用打獵的肉、多一種文案。決定很單純，看到就吃，熊回來就跑。
- 代價：最小，一天內做完。
- 風險：和美洲獅藏食幾乎一樣，玩家感覺不出差別；灰熊比美洲獅可怕得多，卻沒有反映出來。

### B. 熊可能還在附近：先判讀再決定（建議）

發現時熊不一定走了（假設：春天約一半、秋天約三成牠還在附近睡）。畫面寫看得到的跡象：

- 熊在：渡鴉停在高處不敢落地、新鮮的熊糞、旁邊的草被壓出一個大窩、風向對時直接聞到熊。
- 熊不在：渡鴉已經落在土堆上啄、腳印是昨天的。

選項：

- **觀察**：花一個時段，感知越高越準（看出熊在不在，或看出牠剛離開多久）。
- **偷吃**：熊在的話，吃第一段時牠就衝出來（單狼：受傷後逃開，或進入灰熊戰鬥）；熊不在的話，像美洲獅藏食一樣，每段有機會牠回來。
- **離開**。

- 遊玩感受：「餓了，要不要賭」。感知和觀察有用，風向有用（逆風靠近比較安全）。和設計支柱的「讀懂局面」一致。
- 代價：中等，約 1～2 天。新的發現畫面、跡象的文案（熊在／不在各 3～4 種，依季節和地形）、一個新的衝出來事件（接現有的灰熊戰鬥）、回歸測試。
- 對其他系統：多一個春天的食物來源，春天剛好是要餵幼狼的時候（Phase 3），可能讓養幼狼輕鬆一點，要模擬確認。
- Claude Code 的假設：熊在的比例、觀察的準確度、衝出來的傷害，都先用美洲獅和灰熊搶食的數值換算。

### C. B 加上狼群一起把熊耗走

B 的全部，另外熊趴在土堆上時，有伴侶或子女跟著的話多一個「一起騷擾，把牠耗走」：用現有戰鬥的騷擾（牽制），幾隻狼輪流，耗掉熊的耐心；成功就能吃到一大堆肉，失敗可能有一隻受傷。單狼不能選（生態：單狼幾乎贏不了）。

- 遊玩感受：狼群的價值更明顯，「帶著家人去搶熊的肉」是很有畫面的一刻。
- 代價：最大，約 3～4 天。多隻狼對一頭熊的騷擾要新寫（現在的戰鬥是你對一隻對手，同伴只是幫咬），要調難度、模擬。
- 風險：容易變成「狼群大了就穩贏」，和生態上「熊幾乎總是贏」衝突；需要讓失敗代價夠重。

## 建議

先做 **B**。成本適中，最能表現灰熊和美洲獅的差別（「熊可能還在」），也用到感知、風向、觀察這些現有系統。C 等 Phase 3 試玩後，看狼群打熊有沒有需求再加。

## 待使用者決定

1. 選 A、B 或 C。
2. 出現頻率：和美洲獅藏食差不多（在灰熊多的區域，春天約每 20 次探索一次），還是更少見？
3. 熊衝出來時，單狼是直接進戰鬥（可以選逃），還是先受一次傷再讓你選？
