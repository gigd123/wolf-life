# 食物太充足（方案，2026-11-05）

起因：2026-11-04 的試玩紀錄（Phase 2 版本、3.7 歲還活著、167 分鐘）。

## 一、看到的數字

| 指標 | 這次 | 上一份（2026-10-22，2.2 歲） |
| --- | --- | --- |
| 決策時是吃飽的（飽食度 ≥ 70） | 40／42 次（95%） | 30／67 次（45%） |
| 一生取得的食物 ÷ 需求（126 天 × 每天 30） | 約 6150 ÷ 3780 ≈ **1.6 倍** | — |
| 吃撐平均持續 | 5.3 個時段 | 6.0 |
| 被灰熊搶走、殘骸被吃掉 | 7 次、11 次 | — |

食物主要來自白尾鹿（約 1150）、馴鹿（約 1020）、馬鹿（約 800）、騾鹿、河狸、駝鹿；藏食物 18 次、吃回來 16 次。

要先說清楚的限制：

- **這是一份紀錄、一個玩家**。你偏謹慎、選的命中率接近最高（0.58／可選最高 0.61），比模擬的「平均打法」會打獵。
- **這份紀錄沒有 Phase 3**（沒有伴侶、子女的資料）。Phase 3 有「反芻餵小狼」，春夏會把多的食物用掉一部分；有了狼群之後，大型獵物也會被分掉。所以 Phase 3 版本的「多出來的食物」應該會比這次少，但不會全部吃掉（小狼只在育幼期需要）。
- 以前定過的方向（設計支柱、2026-10-15）：**成年獨狼不容易餓死，壓力要從別的地方來，不是硬把飢餓加重**。下面三個方案都照這個方向，不改「挨餓的懲罰」。

## 二、方案

### A. 每隻獵物吃得到的肉少一點（直接收緊）

- 做法：大型獵物（鹿、馴鹿、馬鹿、駝鹿）每段肉加的飽食度降一成五～兩成五，或段數少一段；小獵物不動。目標：一生取得 ÷ 需求從 1.6 降到約 1.2～1.3。
- 遊玩感受：出獵的頻率變高，「這幾天要不要冒險打一頭大的」比較常出現；但每次的決策本身不變。
- 代價：最簡單，但就是「多打幾次獵」，重複的狩獵變多、遊玩時間變長；森林、草原以外的地圖（苔原、山地）本來就比較餓，會一起變難，要分地圖調。
- 對其他系統：一生的挨餓天數、壽命要重新校準（life_pressure）；Phase 3 餵小狼會更吃緊。

### B. 肉留不住（殘骸流失得更快）

- 做法：飽食度與每段的肉量不動，但一頭大獵物**一次吃不完的部分更容易沒了**：殘骸放著過夜被吃掉、被搶的機率提高（烏鴉、郊狼、狐狸、灰熊、狼獾），天熱壞得更快；想留住就要藏、守、或吃撐留在旁邊。
- 遊玩感受：獵到大的之後要做選擇——吃撐留下來守（變慢、不能短衝、可能遇上灰熊）、叼一段去藏（有被挖的風險）、或放掉。「守食物」「和灰熊搶」變成常見的局面，正好接上之後的戰術戰鬥。
- 代價：要調整多種食腐動物的機率、文案（殘骸被吃掉的描述）；如果流失太兇，會覺得「獵到也白獵」。
- 對其他系統：和藏食物、灰熊藏食、戰術戰鬥的搶食與守食互相支援；挨餓天數會下降一些，但沒有 A 那麼直接。

### C. 食物不動，多出來的有地方用（儲備）

- 做法：吃撐以外，**飽食度長期高 → 累積「體脂（儲備）」**，冬天或挨餓時先消耗儲備；儲備高的好處（冬天少掉體力、受傷恢復快）讓「多打」有意義，但同時季節更明顯：秋天要囤、冬末會見底。Phase 3 的餵小狼、餵伴侶也從這裡出。
- 遊玩感受：食物多不再是「沒差」，而是「為冬天、為小狼準備」；壓力移到季節和家庭。
- 代價：新增一個狀態（要顯示、要解釋），數值要校準；**本身不會讓食物變少**，如果你覺得的是「太容易」，C 解決不了。
- 對其他系統：和 Phase 3 的育幼、冬季（北部冬季、山地冬季）連得最好；要寫進 SPEC 的新規則比較多。

## 三、建議【Claude Code 的判斷】

- 先 **B**：它不是硬加重飢餓，而是讓「獵到之後怎麼處理」變成決策，跟藏食物、灰熊、戰術戰鬥的搶食都接得起來；數值可以從輕開始。
- 如果 B 之後還是 1.4 倍以上，再小幅做 A（只動大型獵物）。
- C 比較適合等 Phase 3 的試玩紀錄出來再看（反芻餵小狼已經會用掉一部分）。

在決定之前，可以先做一件不影響遊戲的事：用 Phase 3 版本跑「平均打法」與「偏會打獵的打法」的一生模擬，看食物 ÷ 需求是多少，確認這次的 1.6 倍是玩家打得好、還是整體都太多。

## 四、要使用者決定的

1. 選 A、B、C，或組合（例如 B 再加輕微的 A）。
2. 要不要先跑上面那個模擬再決定。
