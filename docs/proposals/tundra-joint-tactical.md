# 提案：苔原狼一起狩獵進戰術地圖——當成微型的群體狩獵實驗

2026-10-22 Claude Code 整理，第 1 版。依據：使用者的問題（2026-10-22）「如果現在做了，不能當作是一個微型的群體狩獵實驗嗎？」。使用者選定之前不寫規格、不實作。

## 一、結論

可以，而且這樣定位比「把苔原狼接進戰術地圖」好：

- Phase 3 的狼群一定要多狼的戰術狩獵；現在用苔原狼（1～3 隻、由電腦控制、只在苔原）先做一個小實驗，可以提早知道「多狼一起追」好不好玩、要哪些規則，到 Phase 3 只要擴充。
- 風險在於戰術狩獵的程式處處假設只有一隻狼（獵物的警覺、逃跑方向、撲咬、咬住後的掙扎）。所以**先在原型場景做**（`prototypes/tactical_hunt`，戰術狩獵當初也是這樣開始），不動主遊戲正在試玩的校準；成立了再接進主遊戲的「和苔原狼一起狩獵」。

## 二、要驗證什麼（假設、驗證方式、通過標準）

| 假設 | 驗證方式 | 通過標準（初始值） |
| --- | --- | --- |
| 有同伴時打法不一樣：要配合牠們的位置（牠們從一側趕，你在另一側截） | 原型模擬：同一場面「單狼」「有同伴但你照單狼的打法」「配合同伴的打法」 | 配合的打法明顯比照單狼打好（例如 +15 個百分點以上）；照單狼打也比單狼好一點 |
| 同伴讓大型獵物變得可能，但不是穩贏 | 原型模擬：馴鹿群、駝鹿 | 和 1～2 隻苔原狼一起：馴鹿約 50～65%、健康的駝鹿 15～25%（現在選單式的苔原狼加成對照） |
| 玩家看得懂同伴在做什麼 | 試玩（原型場景） | 使用者說得出「牠們從那邊趕過來，我在這邊等」 |
| 操作量沒有變成負擔 | 試玩 | 一場的戰術回合數和單狼差不多（不超過 1.5 倍） |

## 三、範圍（三種）

| | A. 最小實驗（建議） | B. 加上簡單指令 | C. 完整狼群戰術 |
| --- | --- | --- | --- |
| 同伴 | 1～2 隻，電腦控制，兩種角色：**驅趕**（從獵物的另一側小跑過去，把獵物往你這邊趕）、**追擊**（獵物跑了就跟著追，累了的獵物牠也會撲） | A ＋ 你可以下「等」「趕」兩個指令 | 多隻、多種角色、輪流追、包圍 |
| 獵物的反應 | 逃離「最近的狼」與「狼的平均位置」；鹿群可能被分開 | 同 A | 更細（被包圍時站定） |
| 咬住後 | 同伴在附近時，壓倒、咬喉有加成（「牠咬住後腿」）；同伴也可能自己撲倒獵物 | 同 A | 同伴各自咬不同部位 |
| 成本 | 約 3 步（原型）：同伴的移動與角色；獵物對多隻狼的反應；模擬與試玩版 | 約 4 步 | Phase 3 |
| 對主遊戲 | 無（原型場景） | 無 | — |

## 四、要動到的程式

- `TacticalHunt` 已經有 `wolves` 陣列與「目前這隻」的寫法（`wi`），但只用過一隻。要補：警覺照每隻狼算、取最大；獵物逃跑時看最近的狼；撲咬、咬住只給你（玩家），同伴的撲倒另外結算；畫面畫出同伴與牠的意圖（往哪走）。
- 同伴的行動規則寫在新的 `TacticalAlly`（類似 `TacticalInstinct`，但只有兩種角色）。
- 原型場景加一個選項「有苔原狼同伴」；模擬工具加單狼／同伴的對照。

## 五、要使用者決定的

1. 範圍：A（最小實驗）／B（加指令）。我建議 A：先看「配合同伴的位置」本身有沒有意思，指令之後再說。
2. 先後：鮭魚洄流做完之後再做，還是穿插？我建議**鮭魚之後**——兩者都會改戰術地圖的共用程式，一次一個比較好找問題。
3. 實驗成立之後，要不要接進主遊戲的「和苔原狼一起狩獵」（目前是選單式，苔原狼的幫忙是加成）。這可以等原型試玩後再決定。

## 六、Claude Code 的假設

- 同伴只在你看得到的範圍行動，不會自己跑去獵別的。
- 獵物被同伴撲倒算「一起獵到」，分肉照現有的苔原狼規則。
- 同伴不會受傷、不會死（實驗階段簡化）。
