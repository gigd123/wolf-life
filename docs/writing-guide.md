# 文案風格指引

《狼之一生》所有遊戲內文字的寫作規則。Claude Code 撰寫或修改 `localization/strings_zh_TW.csv` 時，以本文件為準。

## 整體語氣

像在講一段正在發生、也正被記下的動物故事：沉穩、克制，帶一點悲憫，不煽情、不搞笑。參考西頓《動物記》的敘事感，但視角是玩家自己。

## 人稱

- 玩家的狼一律用「你」。
- 其他動物一律用「牠」，包括陌生灰狼。
- 不使用「我」，也不用「玩家」「角色」這類跳出故事的稱呼。

## 只寫狼知道的事

- 文字只能描述這隻狼感知到、知道的東西，和辨識、知識系統保持一致。
- 還沒辨識的動物，不寫出名稱：沒遇過灰熊之前，寫「一股陌生而危險的氣味」「巨大的爪痕」，不寫「灰熊」。
- 知識還在「似乎」階段時，用不確定的語氣：「這一帶的清晨，似乎常有鹿經過」。

## 用具體的自然細節

- 寫風、雪、氣味、足跡、聲音、光線，少用「很危險」「很美」「很可怕」這類形容詞。
- 好：「風在最後一刻轉了向，母鹿抬起頭，一躍而起。」
- 避免：「你的潛近失敗了，因為風向不利。」

## 數字留在介面上

- 成功率、能力值、飽食度等數字只出現在介面元素裡，不寫進敘事文字。
- 遊戲用語（成功率、經驗、回合、加成）不出現在敘事文字中；需要時用自然描述代替，例如「這幾天吃得很飽」而不是「飽食度高」。

## 傳說與誇飾

- 只用在陌生灰狼的傳說與一生回顧。
- 誇飾不能和實際數值矛盾；傳說的真假可以留白，讓玩家自己判斷。
- 1.6 沒有人類，不寫「人們」「有人說」。傳說改由其他動物的反應或敘述本身表現，例如「這一帶的狐狸，總是遠遠繞開那片松林」。

## 長度

| 類型 | 長度 |
| --- | --- |
| 行動紀錄 | 一句話，約 25 字以內 |
| 選項名稱 | 2～6 字 |
| 換日、睡覺結算的原因句 | 一句話 |
| 季節卡片 | 第一次 3～4 句；之後的精簡版 1～2 句 |
| 生命階段轉變卡片 | 2～4 句 |
| 一生回顧的生平 | 一段，3～6 句 |

## 範例

**行動紀錄**
> 你沿著溪流往東走去。
> 你在巢穴裡安穩地睡了一覺。
> 你伏低身子，一寸一寸地靠近。

**季節卡片（冬季，第一次）**
> 第一場雪落下後，森林安靜了下來。漿果早已不見，溪水邊結了一層薄冰。北部的雲杉林裡，鹿的足跡越來越多，牠們正往那裡聚集避寒。

**季節卡片（冬季，精簡版）**
> 雪又來了。鹿群再次往北方的雲杉林聚集。

**季節卡片（尚未辨識灰熊時）**
> 西部那股陌生而危險的氣味，不知何時淡了。

**睡覺結算的原因句**
> 這幾天吃得很飽，追擊又多，你的腿更有力了。

**換日摘要**
> 後腿的傷終於不再作痛。

**成年轉變**
> 你的腿變得修長，胸口窄而深，跑再久都不太喘。這一年的追逐，已經寫進你的身體裡。

**老年轉變**
> 你的口鼻開始泛白，追久了會喘。但你比以前更懂得，什麼時候不該追。

**陌生灰狼的傳說**
> 牠是盤踞在西部老林的那一隻。這一帶的狐狸遠遠就會繞開牠的氣味；據說牠曾從那股可怕氣味的主人爪下，奪回一頭鹿。沒有誰知道這是不是真的。

**一生回顧的生平**
> 你在冬天離開了出生的狼群。年輕時，你多次被灰熊奪走獵物，於是學會了在密林裡伏擊。三歲那年，你在林線和那隻黑狼對峙，最後低下了頭。七歲的冬天，你死於飢餓。
